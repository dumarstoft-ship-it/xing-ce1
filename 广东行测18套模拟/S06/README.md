## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；部分题另由第二人只看题面独立再做（1题），三方对照。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- 第31—90题由三人分块先盲解、再对照来源答案，60题全部一致。其中第56题（降水增加与鼠类）解题人盲解选D，对照来源后认同C；另请第二人盲做，也选C（把握中等），保留，解析写明D（天敌增加）为什么削弱效果不明确。言语15题选题人自做和第二人盲做都与来源答案一致。加量套没有安排第二人盲做其余判断推理和科推。
- 第50题题图中“主视图”误印为“主观图”，是图内文字，无法改，解析已提醒。
- 第72、74题题干没说按绝对数还是按比例比较，两种口径答案相同；第90题C项说“人均”，图表是“平均每万人”，照原卷，不影响作答。

## 难度

- 资料分析：读一眼就能判断3道、一步4道、两步11道、三步及以上2道（多步13道）；熟练考生连扫读材料约16.2分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步5道（两步4、三步及以上1），熟练考生约5.8分钟；近三年真题多步6—7道。
- 本套资料由M15的同一位解题人评（多步13道、约16.2分钟，与S05的约16.1分钟相当），他计步偏宽；按题池的统一评法，本套资料多步6道。数学多步5道。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。建议限时75分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：数学运算和差倍比方程5道（真题2—3★）；数学运算最值与构造0道（真题1★）；数学运算杂题0道（真题1—2）；图形推理规律类4道（真题2—3★）；图形推理空间类1道（真题2—3★）；图形推理拼合0道（真题1★）；逻辑判断翻译推理3道（真题0—2）；逻辑判断分析推理1道（真题2—3★）；逻辑判断真假推理1道（真题0）；逻辑判断削弱3道（真题1—2★）；逻辑判断前提假设1道（真题2—3★）；逻辑判断解释0道（真题2—3★）；逻辑判断归纳结论1道（真题0）；科学推理电学0道（真题1★）；科学推理地理0道（真题1★）；科学推理光热声及其他2道（真题0）；资料分析比较排序5道（真题3★）；资料分析现期量与简单计算0道（真题1—2★）；资料分析材料理解0道（真题2—5★）；资料分析平均数5道（真题0—1）。
