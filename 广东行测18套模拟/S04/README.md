## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；换入的题另由第二人只看题面盲做（1题），与来源答案一致。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- 第31—90题由三人分块先盲解、再对照来源答案，换题后60题全部一致；言语15题选题人自做和第二人盲做都与来源答案一致。加量套没有安排第二人盲做判断推理和科推，只有换入的第61题解题人此前看过那一页解析，另由第二人盲做，与来源答案一致。
- 原第61题（空调管理系统）解题人盲解选D，来源答案B，B、D都能解释，已换并列入“题目有问题”；原第55、59、63题与同套的题考点雷同而换，理由见“与原题不同的地方”。
- 资料第76—80题统计图的图题印作“2011年1季度—2014年4季度”，图中最后一组其实是2014年1季度，原卷如此；第76题问的就是2014年1季度，不影响作答。
- 第40题（射击概率）题干没写三人是否击中互不影响，按同类题的通常理解当作互不影响，答案唯一，照原卷印，没有补条件。第52题设问“下列条件必定为真的是”用词不太准确（选项是判断），不影响作答，照原卷印。
- 第28题取自江苏2025年卷，原卷有行末硬换行，排版时已合并。

## 难度

- 资料分析：读一眼就能判断4道、一步10道、两步5道、三步及以上1道（多步6道）；熟练考生连扫读材料约13.2分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步5道（两步3、三步及以上2），熟练考生约5.8分钟；近三年真题多步6—7道。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。建议限时75分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：数学运算最值与构造0道（真题1★）；数学运算浓度、容斥1道（真题0）；科学推理地理0道（真题1★）；科学推理光热声及其他1道（真题0）；资料分析材料理解1道（真题2—5★）；资料分析平均数2道（真题0—1）。
