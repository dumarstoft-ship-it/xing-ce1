## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；判断推理和科学推理另由第二人只看题面独立再做（25题），三方对照。换入的题另由第二人只看题面盲做（3题），与来源答案一致。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。
- 原第47、59、61题两名解题人各自盲解都与来源答案不同，原第43题（江苏卷）来源答案行印错，都已换，理由见“与原题不同的地方”。
- 第47题（立体图形，换入题）第二人把握中等：D项后排上层短块的错位比题干约小半格，若出题人以此为不同点，答案可能是D；但两人都按“A是题干的镜像，旋转得不到”判A，与来源答案和来源解析一致（来源标注全站正确率41%，易错项C），按A。
- 第33题（数推）解题人盲解选A，依据“9−4=5、5−2=3”只有一个等式，属于凑数；来源答案B的规律（小数部分公差8，整数部分是小数部分两位数字乘积的个位）四项都成立，用B。来源标注全站正确率43%，易错项A，是本套数推的难题。
- 第89题（资料）“变化量的大小”按变化数额的绝对值比较，科研减少约0.10亿元排在教育增加约0.09亿元之前，来源解析同；按带符号的增长量比会得B。B、C、D恰是A各交换一对相邻项，命题意图明确，保留原题，解析写明口径。
- 第62题（解释）第二人把握中等（D“占比不高”也能部分解释），两人都与来源答案一样选A。第67题（科推）B项“小于F”要默认动摩擦因数小于1，来源解析同。第90题B项判错的依据是2015年样本户数未给出，A、C、D都可验证为正确，答案唯一。
- 第81题表格年份从左到右是2014—2010年（倒序），原卷如此，是读表陷阱，不改。第86—90题折线图图题末尾有原卷带的Word段落标记“↵”，按原卷裁图印，不影响作答。第32题原卷是上下排的分数，题库转写成斜线，按原卷排成分数。

## 难度

- 资料分析：读一眼就能判断5道、一步8道、两步6道、三步及以上1道（多步7道）；熟练考生连扫读材料约13.8分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步6道（两步4、三步及以上2），熟练考生约6.8分钟；近三年真题多步6—7道。
- 本套按用户要求适当偏难（2026-11-25），取广东旧卷里较难的题。数学第40题（排列组合）一步但难；第42、43题是江苏省考A类卷的三步题。
- 数推、图推、科推按题池评级都是难2中3，解题人逐题评级略低（数推、科推各难1中3易1，图推难2中2易1）；逻辑题池评难的是第53、55、59题，解题人评为中或易。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。按考场时段计时90分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：数学运算浓度、容斥1道（真题0）；图形推理拼合0道（真题1★）；图形推理截面1道（真题0）；逻辑判断真假推理1道（真题0）；逻辑判断结构比较2道（真题3★）；科学推理生物0道（真题1★）；资料分析比较排序7道（真题3★）；资料分析比重1道（真题2—5★）；资料分析平均数3道（真题0—1）。
