## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；判断推理和科学推理另由第二人只看题面独立再做（25题），三方对照。换入的题另由第二人只看题面盲做（3题），与来源答案一致。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。
- 原第48题（六个表情图分两类）两名解题人各自盲解都与来源答案不同，原第58题设问所指不清，都已换，原题列入“题目有问题”；原第45、61题和第71—75题为难度、考点雷同而换。理由都见“与原题不同的地方”。换入的题解题人盲解（第58题）或第二人盲做（第48、58、61题）都与来源答案一致。
- 第50题（正四面体折叠）展开图里的三角凹形画得不对称，凭它判断不了方向，要按笑脸眼睛对着哪个角来判断，解析已提醒；答案B不受影响。
- 数推第34题、数学第39、43题取自江苏省考A类卷，三题的来源答案行与来源解析正文算出的答案都一致。
- 资料第86—90题材料说2015年粮食产量“下降2.3%”，按图中产量4.21、4.16万吨算约下降1.2%，原卷数据不一致；各题作答不受影响（第90题D项按增速正负判断，两种算法2015年都是下降）。

## 难度

- 资料分析：读一眼就能判断3道、一步9道、两步8道、三步及以上0道（多步8道）；熟练考生连扫读材料约14.2分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步7道（两步5、三步及以上2），熟练考生约7.2分钟；近三年真题多步6—7道。
- 本套按用户要求适当偏难（2026-11-25）。数学多步7道（两步5、三步2），第39、43题是江苏省考A类卷难题，第43题来源标注全站正确率14%；数推第34题也是江苏卷题。资料原定的2013年一卷时间利用表5题都是读表或一步，换成国考在线旅游收入表后多步8道。
- 数推、图推、科推按解题人评级：数推难1中3易1，图推难2中3，科推难1中4；逻辑评为难的3道（第51、62、63题），第51题来源标注全站正确率39%。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。按考场时段计时90分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：数学运算最值与构造0道（真题1★）；数学运算浓度、容斥1道（真题0）；资料分析比较排序5道（真题3★）；资料分析材料理解0道（真题2—5★）；资料分析图形选项2道（真题0—1）。
