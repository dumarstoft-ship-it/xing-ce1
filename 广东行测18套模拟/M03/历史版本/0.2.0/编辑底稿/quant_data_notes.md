## 选编判断

数量的5道数推分别是三项分组、隔项、分数还原、差数列递推、圆形数阵。10道运算覆盖“部分/其余”比例与整数约束、数位与车辆分配、利润和收入的转换、逆顺风、相似圆锥、工程换队、闰年周期、带启动条件的概率、集合交叠、指定人数的有标号分组。总体保留题源自身的难度，没有按答案字母配平或刻意补简单题。

数量来自9个季次：第19季4题，第27季3题，第25季2题，第22、23、29、30、31、32季各1题。选题扩散用于减少对某一份源卷的依赖，不作为以后各卷的硬性配额。

资料完整保留四组材料：

|本卷题号|源组|材料与训练价值|
|---|---|---|
|71—75|第19季第1组|广东超高清视频产业纯文字材料；保留文字检索和证据边界，再切换地区范围、累计增长和比较基期|
|76—80|第17季第3组|汽车制造业九列表；亏损面、同跨度年均增长、利润率方向、平均亏损额、全年与当月口径|

|86—90|第25季第2组|能源生产与消费双表；相近增量的增长率比较、增量倍数、饼图、年均量、综合判断|

资料第81—85题计算链较长，作用是形成取舍压力；前一文字组与后面的图形判断提供不同阅读和计算路径。不是每题都需要完整精算，解析同时指出可以缩短思考的关系。

## 实质改动与显示修复

- 第35题：源库仅保留四个圆的数字位置表，原图文件已缺失。按该表精确重建四圆数阵，生成`quant_data_number_grid.png`及SVG。数字与四象限位置未变，PNG已实际查看。它是据转写重建的图，不能声称和原PDF逐像素一致。
- 第43题：补明不同考生、首次与补考结果的独立性，设问明确“最终”恰好3人合格。补考门槛、所有概率和选项均未改。
- 第72题：把“错误的是”改为“不能推出的是”。8K数量与排名没有给出，只能说材料不支持，不能据缺失信息断言现实事实为假。
- 第73题：源题由“月产能不变”直接问实际年产量，缺少必要前提；新增“各月均按该产能满负荷生产”，并明确全年各月维持同一产能。数值和选项未改。
- 第80题：设问明确为“可以推出的有几项”。第③项缺月度数据，按不能推出处理，不说它在现实中必假。
- 第71—75题共用文字材料只做语义分段，第81—85题材料补明累计口径按自然年重启，1—2月为合计。四组材料所有原文字字符（除空白）、数值、单位、行列顺序均保留。
- 源库中部分TeX命令有双反斜杠，已在显示覆盖字段中恢复标准单反斜杠。原始`source_question`没有改写。

## 已做核验

运行：

```bash
python3 广东行测18套模拟/M03/编辑底稿/quant_data_check.py
```

脚本优先读取整卷`selection.json`，整卷尚未组装时读取`quant_data.json`。结果保存于`quant_data_check.json`。

已经逐题推导并将答案键与计算结果比较。整数题用有限枚举复核；第43题枚举首次与补考每一个允许结果，得到0.319488；第45题枚举7人到3园的全部指派，得到350。日期题分别计算平年、闰年3月30日的序号，确认只有闰年满足老张条件。

资料综合题核算全部数值断言，不只计算正确选项。第83题在累计量按整数、同比按一位小数的显示舍入边界下，单月同比可能约27.69%—28.90%，仍唯一最接近28.3%。第89题五年平均量为24053.4万吨标准煤；即使各输入整数存在通常舍入误差，也不会跨过24000的区间边界。

第85题四幅折线选项、第88题四幅饼图选项均实际查看；脚本另分别提取折线三点高低与粗略扇区占比，和材料的趋势、比例交叉核对。图形分析只作复核，不冒称恢复原图精确百分比。

所有35条原始题目对象均与当前源库逐对象相等；4组×5题的共用材料逐对象一致；数表的表头和单元格逐格未改。源库文件SHA-256、去重与旧材料检查见`quant_data_exposure.json`。

## 外审与排版应关注的点

第35题重建数阵请核对四象限；第41题工程应明确区分计划15天与实际17天、第42题周期以开始日为第1天、第43题补考启用条件均值得再独立算一次。第72/80题的措辞修复涉及“不能推出”与“已证伪”的区别。

汽车制造业材料有9列，列标题及亿元单位不可压得难以辨认；表内“—”表示未提供，不能补成0。空调累计表跨自然年，1—2月行不能拆成单月。能源双表必须保持“生产/消费”标题紧随表格。资料原柱折图多数只剩转写表，未与原PDF逐格视觉比对；打印时可以依据转写表制作清晰图表，但应如实记录重建来源。

`quant_data_make.py`仅是本模块首次生成记录，后续修改应以整卷`selection.json`为准，不要重跑生成脚本覆盖审核修订。
