## 一、共同目标与接手顺序

请判断每题能否清楚、唯一地作答，解析是否支持答案，整卷是否具有值得练的取舍压力。题源自然偏难可以保留，但不能以转写缺陷、隐含前提或勉强圆解制造难度。广东近年卷用于校准题型、设问和纸面体验，不构成把国考、江浙题源降难度的指令。

遵循[指月之指非月](../../协作原则_指月之指非月.md)：以下提示给出证据和风险，不限制独立判断。不要为答案分布、来源配额或简单题数量添加硬指标；也不要因编辑答案或源参考答案一致就停止质疑。

建议先只读取[题本_待审.md](题本_待审.md)和[题目.jsonl](题目.jsonl)，实际打开题图、图形选项并保存独立答案和不确定点，再读取答案、来源及下文的重点说明。若已看过某题答案，如实标明，不再将其称为隔离答案的盲解。

后续协作顺序：

1. **Claude独立复核。** 覆盖全卷题面、答案唯一性、解析、图表与整卷价值；程序只用于验证适合计算或枚举的部分。
2. **Claude反馈。** 在M03下记录独立答案、必须修改项、合理分歧、可选优化及依据；有争议保留推导，不为凑齐结论强行消除分歧。
3. **GPT回应与修订。** 逐项说明采纳、改造采纳或暂不采纳的理由，更新唯一底稿、版本和派生产物；新增或实质改动项交回增量复核。
4. **Claude复核改动并排版。** 内容问题处理后，沿用既有工具和指定字体制作打印版，逐页检查实际PDF，保留排版日志及底稿指纹。

### 第24题：语句填空的相对最优边界

当前答案D“经由公众的集体参与而被重塑”。内部作答与源参考答案一致，但B“不再由传统的权威新闻媒体所定义”在句义上与文意相关，不能当作逻辑矛盾项硬排。

现解析认为D同时收束“消息来源直接面向公众”与“互联网用户交叉验证”所带来的新机制，B主要重复旧权威不再独占的否定表述，因而D的语篇完整度更高。请独立判断该差距是否足以支撑“最恰当”，不要把“重复前文”变成任何填句题都通用的机械排除规则。如果B/D之间的竞争确实影响可靠作答，直接提出保留、微调或替换建议。相关细节见[言语复核报告](核验记录/verbal_independent_review.md)。

### 第50题：立体拼合须检查唯一性

当前答案D。最初模块核验只记录了D补成4×2×3长方体的见证，之后针对A项排除证据不足做了[专项补核](核验记录/q50_spatial_review.md)，按原图通常积木读法转录四选项坐标，枚举24个正旋转及总块数的全部整数边长组合。结果为A/B/C无可行拼合，D有4个整体旋转等价的见证；A甚至不能与图①无重叠共存。当前解析已补入B的27块体积排除和A避开高柱后必撞短柱的理由。

请先按原图确认每块立体的占位和可能旋转，尤其检查遮挡格转录，再检验A/B/C能否排除；不能只把人工转录坐标跑通当作原图正确。新证据见[坐标及枚举数据](核验记录/q50_spatial_review.json)和[可重跑脚本](核验记录/q50_spatial_review.py)。[早期判断说明](编辑底稿/reasoning_notes.md)及[模块核验](编辑底稿/reasoning_verification.json)仍保留当时只证明D可行的范围，不覆盖后来的补核。打印时也必须看清前后层棱线，避免版面压缩改变可判读性。

### 第69题：从源表重建的食物网

### 第70题：初稿A已纠为B，虚线是区域界

内部交叉复核发现初稿不只误填字母，还同时误读了山脊/山谷和倾斜指北针。**当前`selection.json`已改为B并整体重写解析**；[科学复核报告](核验记录/science_independent_review.md)仍保留“初稿A”的历史记录，不应再由旧记录反向覆盖当前答案。

指北针指向纸面右上，河流总体由右上高处流向左下低处，对应实际自北向南。②为山脊，③为山谷。甲村周围的闭合虚线在图例中表示**区域界**，并非等高线；村庄海拔判断应依据两侧实线等高线。请重新读图核验上述关系，打印时保留图例、指北针、等高线数值及虚实线的区别。

## 四、编辑底稿的权威关系

**只以`selection.json`作为当前内容修订起点。** `编辑底稿/`中的各模块JSON、生成脚本及笔记是初次选编过程记录，不得重新拼接覆盖整卷。模块笔记中“可直接并入”等历史表述不再授权覆盖当前底稿。已修改题面应同时检查覆盖字段、答案、解析、`edits`及核验状态，保留原始源对象用于追溯。

GPT处理审核意见后更新版本并运行：

```bash
python3 广东行测18套模拟/M03/build_m03.py
```

该命令从当前底稿生成题本、题目JSONL、解析、来源、选题记录和核验报告，并更新M03待审预留登记。数值复算可运行`编辑底稿/quant_data_check.py`，它优先读取整卷；判断模块的历史输出须先确认检查的是当前题面。不能通过改校验值或重跑旧生成器掩盖版本差异。
