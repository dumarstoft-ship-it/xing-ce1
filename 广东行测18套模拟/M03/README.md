## 答案是怎么核的

- **第31—90题**：模考题库没有答案，每题由一人独立解出并写解析，数量和资料用程序核算、能枚举的枚举；判断推理和科学推理另由第二人只看题面独立再做（27题），两遍对照。换入的江浙真题用来源答案并复算。
- **第16—30题**：用国考、江浙真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”），真题每年都有而本季缺的已补上。与真题范围有出入的类别：数学运算工程2道（真题1★）；逻辑判断削弱3道（真题1—2★）；逻辑判断结构比较2道（真题3★）；资料分析比较排序2道（真题3★）；资料分析倍数2道（真题0—1）；资料分析平均数2道（真题0—1）。

## 与原题不同的地方

- 第41题，调序换题：第18季数学运算没有最值与构造题、有一道容斥题（真题每年最值1道、近三年无容斥）：换下第42题（容斥），补入2025年浙江省考A类第57题（构造类最值）；排列组合题按真题题位放到第41题。
- 第49题，调序换题：第18季图形推理没有拼合题、有一道截面题（真题每年拼合1道、近三年无截面）：换下第49题（截面），补入2021年浙江省考A类第85题（立体拼合）。
- 第66题，调序换题：第18季科学推理没有电学题（真题每年1道），两道力学中的第67题调给M01（第16季缺力学）；电学题为编辑按真题常见的动态电路题新写。按真题题序排为化学、力学、地理、电学、生物。
- 第88题，调序换题：真题第89题三年都是比较排序：统计图组内第3、4题对调，使比较排序题在第89题。
- 第69题，原创：第18季科学推理没有电学题（真题每年1道），题库各季电学题都只有一道、没有富余，按真题常见的动态电路题编写。
- 第79题，改写设问：第18季资料分析没有增长量题（真题每年1—3道），平均数有3道，且有两道“有几个”式计数设问。第79题原问平均每吨回收金额超过5000元的年份个数，改为由文字材料推算2022年回收总重量的同比减少量，难度不低于原题。

资料分析中原卷的统计图没有入库，只有转写的数据，打印版按数据重画（图形样式为推定，数值与转写一致），见编排说明。
