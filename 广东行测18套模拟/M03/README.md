## 编辑与重建

**后续一切内容修订以[selection.json](selection.json)为准。** `编辑底稿/`中的模块JSON、笔记、生成脚本和核验输出属于选编过程记录。即使其中某个文件仍写着“可直接并入”，也只描述初次组装时的状态，不能再拼接覆盖当前`selection.json`，以免丢失整卷层面已处理的修订。内部复核报告保留它们实际检查的版本与历史结论，不能自动当成对后续改题的复核。

修改当前底稿、记录改动与版本后，从仓库根目录重建：

```bash
python3 广东行测18套模拟/M03/build_m03.py
python3 广东行测18套模拟/M03/核验记录/verify_delivery.py
```

构建脚本同步题本、题目JSONL、答案解析、来源登记、选题记录、核验报告及M03用题预留记录，不改原题库；交付检查器复算并检查来源、去重和重建一致性。涉及数值的修订可再运行[quant_data_check.py](编辑底稿/quant_data_check.py)，它优先读取当前整卷底稿；其他模块的历史核验应先确认输入范围再使用，不能仅重跑旧模块生成脚本来宣称当前版本通过。
