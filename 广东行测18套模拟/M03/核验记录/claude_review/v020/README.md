# M03 0.2.0增量复核证据

本目录是Claude对0.2.0改动的复核证据，结论见[增量复核](../../../Claude增量复核_v020.md)：

- `增量复核.json`：逐题结论与底稿指纹。
- `blind/`：两组审核进程看答案前写入的盲解原文件。
- 复核脚本（缺省读取仓库中M03当前文件，在脚本所在目录运行 `python3 -B <脚本名>`）：
  - `enum_matching.py`：第5、6、12、13题选项区分度枚举。
  - `q35_search.py`：第35题替代规律穷举。
  - `q35_print_check.py`：第35题按120mm实印时字形与线条的间距。
  - `blind_calc.py`：第35、43、69题计算。
  - `q67_geom.py`、`q67_pixcheck.py`：第67题新图几何、落点与轨迹核对。
  - `print_measure.py`：第67、68题实印尺寸测量。
- `q67_orig_src_new_side_by_side.png`：第67题原图、题库重绘图、0.2.0新图并排。
