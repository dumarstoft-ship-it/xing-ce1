## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- 第31—90题由三人分块先盲解、再对照来源答案，60题全部一致；言语15题选题人自做和第二人盲做都与来源答案一致。加量套没有安排第二人盲做判断推理和科推。
- 第64题（解释）解题人盲做选B，复核后按来源答案D：B只涉及本来就两样都买的老顾客，赠品本该拉动销量，反而加深矛盾；D说明同类优惠常有，这次促销已无吸引力。解析写明B错在哪里。
- 第77题所在材料正文“农药使用总量580万吨”与表中5.80万吨不符，按表改（5.80÷6.15−1＝−5.69%，正好对上“减少5.69%”）。

## 难度

- 资料分析：读一眼就能判断2道、一步12道、两步6道、三步及以上0道（多步6道）；熟练考生连扫读材料约10.4分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步2道（两步2、三步及以上0），熟练考生约4.1分钟；近三年真题多步6—7道。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。建议限时75分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：数学运算最值与构造0道（真题1★）；资料分析比较排序2道（真题3★）；资料分析增长量5道（真题1—3★）；资料分析材料理解1道（真题2—5★）；资料分析图形选项2道（真题0—1）。
