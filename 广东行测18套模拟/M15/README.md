## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；判断推理和科学推理另由第二人只看题面独立再做（25题），三方对照。换入的题另由第二人只看题面盲做（5题），与来源答案一致。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。
- 原第46题（九宫格涂色）、第55题（人类发展受制于自然资源）、第62题（结构比较）解题人和第二人各自盲解都与来源答案不同，已换，原题列入“题目有问题”；第62题换入的第一道（三段论，问“不一致”的一项）两人又都指出A、D两可，再换一次，这道也列入“题目有问题”。理由都见“与原题不同的地方”。
- 第54、64题不是因为答案换的：第62题换掉后解题人评本套逻辑没有难题，评为易的第54题换成真假推理（题池评难，解题人和第二人都评中）；原第63、64题同为“指出问题→提出对策”的结构比较，又排在一起，第64题换成由部分事例推出整体倾向的一道。换入的5题（第46、54、55、62、64题）解题人和第二人盲做都与来源答案一致。
- 资料原定GD2013-1-M3，其第100题图例单位印作“百分”，A项真假两可，整组不用（列入“题目有问题”），换成GD2013-1-M2。
- 第71、75题题干说按“上一年”社会平均工资定基数，表中只有同年数据，原卷如此，解析按同一行计算并写明；第74题选项是没有刻度的手绘曲线，只能看整体走势。第85题A项、第89题受原资料小数位数影响，严格说算不准，但另有选项明显对或错，答案不受影响，解析写明。
- 第49题题干原作“如左图所示”，本套题图中立体在上方，改为“如上图所示”（“立方体”照原卷）；第50题题图中有一块方块只与其余方块棱接，原图如此，不影响作答。第53题原卷题干里有一个PDF转出的不可见乱码字符，删去。
- 数推第33、35题、数学第40、43题取自江苏省考A类卷，四题的来源答案行与来源解析正文算出的答案都一致。

## 难度

- 资料分析：读一眼就能判断5道、一步6道、两步6道、三步及以上3道（多步9道）；熟练考生连扫读材料约13.8分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步6道（两步4、三步及以上2），熟练考生约7.6分钟；近三年真题多步6—7道。
- 本套按用户要求适当偏难（2026-11-25）。数学多步6道（第38、40题三步），第40、43题取自江苏省考A类卷，第41、42题是选调卷难题；数推第33、35题也取自江苏卷。本套资料的解题人计步和估秒偏宽，与M14、S05的评分人同一评法（多步9道、三步3道，约13.8分钟）；按题池的统一评法，本套资料多步8道。
- 数推、图推、科推按解题人评级：数推中3易2，图推难1中4（题池评难2中3），科推难1中3易1。逻辑解题人评中10道、易5道，没有评为难的：题池评难的4道（第53、54、62、63题）解题人都评为中，换入的第54题第二人也评中。广东逻辑剩下的难题主要是选调卷的结构比较，留给M16—M18。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。按考场时段计时90分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：数学运算和差倍比方程1道（真题2—3★）；数学运算浓度、容斥1道（真题0）；逻辑判断分析推理1道（真题2—3★）；逻辑判断真假推理1道（真题0）；逻辑判断解释1道（真题2—3★）；科学推理电学0道（真题1★）；科学推理地理0道（真题1★）；科学推理光热声及其他1道（真题0）；资料分析比较排序5道（真题3★）；资料分析比重1道（真题2—5★）；资料分析综合分析判断6道（真题2—5★）；资料分析材料理解0道（真题2—5★）；资料分析平均数2道（真题0—1）；资料分析资料分析／比值1道（真题—）；资料分析资料分析／计数1道（真题—）。
