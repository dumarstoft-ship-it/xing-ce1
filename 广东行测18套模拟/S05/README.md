# S05｜广东省考行测加量套（重编1.0.0）

加量套：2026-11-26至12-02每天的第二场，用事业编和省考旧卷剩下的题编（见[重编说明](../重编/README.md)“M09起怎么编”）。只出第16—90题，题号照真题位置，不出政治理论、常识判断；第31—90题以2022—2026年广东事业单位统考题为主，配广东省考旧卷和选调生考试卷里较易的题，资料有3组取自国考地市级卷（广东资料组不够，用户2026-11-20定用国考补），题型照2024—2026年真题分布，难度略低于主套，解析写得简短。建议限时75分钟（主套90分钟里约10分钟用在第1—15题），到点没做完就换一支颜色的笔做完。

## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- 第31—90题由三人分块先盲解、再对照来源答案，60题全部一致；言语15题选题人自做和第二人盲做都与来源答案一致（第25题第二人把握中等，与来源一样选D）。加量套没有安排第二人盲做判断推理和科推。
- 选题时第53题原定的事业编分析推理与前一天S04第53题同一模板（三人各作两项预测、各对一半），换成了另一道。
- 资料第71—75题统计图纵轴单位印作“户”，按数值应为“万户”；第81—85题图1、图2左轴原图没标单位（总流通人次是亿人次），图1右轴最下一格刻度印作“4”（应为0）。原卷如此，解析里已提醒，不影响作答。
- 第74题“电话用户数与上年差距最大的年份”，“差距”指总数与上年相比的变化量（不是移动与固定之差），解析写明；第38题问“可能为”，按题意只要有一种情况成立即可（另一种情况得4∶1，选项里没有）。

## 难度

- 资料分析：读一眼就能判断4道、一步8道、两步5道、三步及以上3道（多步8道）；熟练考生连扫读材料约16.1分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步5道（两步4、三步及以上1），熟练考生约5.9分钟；近三年真题多步6—7道。
- 本套资料换了一位解题人评（多步8道、约16.1分钟），他计步和估秒都比S03、S04的评分人宽；按题池的统一评法，本套资料多步6道（S04为5道）。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。建议限时75分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：数学运算最值与构造0道（真题1★）；数学运算浓度、容斥1道（真题0）；图形推理规律类4道（真题2—3★）；图形推理空间类1道（真题2—3★）；图形推理拼合0道（真题1★）；科学推理地理0道（真题1★）；科学推理光热声及其他1道（真题0）；资料分析比较排序4道（真题3★）；资料分析比重0道（真题2—5★）；资料分析材料理解1道（真题2—5★）；资料分析倍数2道（真题0—1）；资料分析平均数3道（真题0—1）。
