## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；判断推理和科学推理另由第二人只看题面独立再做（25题），三方对照。换入的题另由第二人只看题面盲做（1题），与来源答案一致。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。
- 第46题（图推）：两名解题人盲解都选B（抓的是“三角形有一边与梯形两底平行”的静态特征），来源答案A。按来源解析，梯形每次逆时针转90°、三角形每次顺时针转90°，只有A两条都符合；前三幅交点数为3、4、4，并无规律。按A，解析写明这个易错点。
- 第59题（解释，问“最不能解释”）：第二人选C，第一位解题人和来源答案为D。D说的是非实体店的数量，不涉及销售额；C说零售业整体销售额大增，分母变大，能解释占比下降。按D，解析写明C为什么仍能解释。
- 原第54题（前提假设）两名解题人各自独立选C，来源答案B，答案可商榷，已换题；换入的2023年县级卷第74题第二人盲做与来源答案一致。
- 第68题（电路）补“电源电压保持不变”：答案C要以此为前提，原卷没写。

## 难度

- 资料分析：读一眼就能判断1道、一步10道、两步8道、三步及以上1道（多步9道）；熟练考生连扫读材料约14.8分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步4道（两步2、三步及以上2），熟练考生约6.2分钟；近三年真题多步6—7道。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。按考场时段计时90分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：资料分析比较排序4道（真题3★）；资料分析现期量与简单计算0道（真题1—2★）；资料分析材料理解0道（真题2—5★）；资料分析倍数2道（真题0—1）。
