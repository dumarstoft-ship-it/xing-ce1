# 题型参照（广东2024—2026年真题）

用户要求各套模拟卷的题型与近年广东卷基本一致（2026-11-16）。本文件是对照用的参照，不是配额：

- **目的**：让考生练到真实的题型感觉和时间分配；
- **用法**：每套卷各部分里各类题的多少，大体落在下面的范围里；真题每年都有的题型，每套也要有；
- **不要做的**：一两道之差无妨，不为凑类型换掉好题，也不为改变类型而改写原题。

**数据**：取自 `广东/行测/2022-2026/` 的2024、2025、2026年三份卷子，由人逐题读题归类，真题和模拟卷用同一套分类。2022—2023年是100题的旧卷，结构不同（有类比推理，科推10—20题），只参考某类题怎么出，不用来定范围。

**说明**：

- 表中“范围”是三年里的最少到最多；★表示三年每年都有。
- 2026年是网友回忆版，没有答案。
- 分类有边界题时，按题目实质归类。逐题归类、五套模拟卷的对照和边界说明见 [题型对照/](题型对照/)：`comp_vq` 为言语、数量，`comp_js` 为判断、科推，`comp_pcd` 为政治、常识、资料。

**问法**：

- 每年都有古语名句匹配题（1—2道）和“必须坚持……”这类立场观点方法题（1—2道）。
- 三年都没有“某地/某企业”情境题，也没有依次对应、归类、时间排序题。

**题位与形式**：

- 第16—20题是逻辑填空，单空、多空混排；单空多为成语俗语；三空题每卷最多1道；逻辑填空每卷合计7—10个空。
- 第21题三年都是主旨意图。
- 每年末尾有一道6句排序，2024、2025年另有一道4句排序。
- 每年有1道以古语、诗句或名言作选项的题。

## 判断推理（46—65）

**图形推理（5道）**

- 规律类2—3道、空间类2—3道★。
- 拼合题每年1道★：立体拼合或平面拼合。
- 三视图、展开与折叠（含折纸剪纸）各0—1道；截面三年都没有。
- 第50题三年都是空间题。
- 形式：一组图1—2道，九宫格0—1道，分组0—2道，字符串三年都没有。

**逻辑判断（15道）**

| 类别 | 2024 | 2025 | 2026 | 范围 |
| --- | ---: | ---: | ---: | --- |
| 翻译推理 | 1 | 0 | 2 | 0—2 |
| 分析推理（排列、对应、匹配） | 2 | 3 | 2 | 2—3★ |
| 真假推理 | 0 | 0 | 0 | 0 |
| 削弱 | 2 | 2 | 1 | 1—2★ |
| 加强、支持 | 1 | 1 | 2 | 1—2★ |
| 前提假设 | 3 | 3 | 2 | 2—3★ |
| 论证缺陷、评价 | 0 | 1 | 0 | 0—1 |
| 解释 | 3 | 2 | 3 | 2—3★ |
| 结构比较（推理形式、论证结构） | 3 | 3 | 3 | 3★ |

形式逻辑合计3—4道。各类穿插排列，不成块。结构比较三年都是比较推理形式或论证结构，没有对话型。

## 资料分析（71—90）

**材料**

- 每年至少1组纯文字材料，都在前两组。
- 第4组三年都是“文字＋统计图”。
- 含统计图的组1—3组，含表格的组1—2组，纯表格至多1组。
- 每年正好2组广东或“G省”材料，在第1、3组。

**考点**

| 考点 | 范围 |
| --- | --- |
| 比较排序 | 每年3★，第89题三年都是 |
| 比重 | 2—5★ |
| 增长量 | 1—3★ |
| 现期量、简单计算 | 1—2★ |
| 综合分析判断 | 2—5★，每组第5题多为正误判断 |
| 材料理解（非计算，在纯文字组） | 2—5★ |
| 增长率 | 0—4 |
| 基期量、倍数、平均数 | 各0—1 |
| 图形选项题 | 0—1 |

单项计算题每年12—13道；“有几个、几项”式计数设问三年只出过1道。
