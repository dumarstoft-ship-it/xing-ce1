## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；部分题另由第二人只看题面独立再做（5题），三方对照。解题人此前核对别的套时看过答案页的题，另由一人只看题面独立再做（16题），与来源答案一致。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- 第31—90题由三人分块先盲解、再对照来源答案，60题全部一致；言语15题选题人自做和第二人盲做都与来源答案一致。
- 解题人此前核对S01、M10时看过答案页的16题（数量第32、35—40、42—44题，科推第69题，资料第86—90题）另由一人只看题面独立再做，都与来源答案一致；第46—50题（图推）解题人此前看过解析页，另由第二人只看题面独立再做，也都一致。第46题第二人把握中等：A、B都符合“每列一个黑块”，再看黑块位置，题干中格数为偶数的列黑块都在最下、为奇数的列都在正中，只有B符合，按B。
- 第72题题干原作“渔业增加值”，题目实际用的是材料里的“海洋渔业增加值”，已统一；第34题原卷是上下排的分数，按原卷排成分数。

## 难度

- 资料分析：读一眼就能判断3道、一步12道、两步5道、三步及以上0道（多步5道）；熟练考生连扫读材料约11.4分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步3道（两步3、三步及以上0），熟练考生约4.2分钟；近三年真题多步6—7道。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。建议限时75分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：资料分析比较排序5道（真题3★）；资料分析比重6道（真题2—5★）；资料分析现期量与简单计算3道（真题1—2★）；资料分析材料理解0道（真题2—5★）。
