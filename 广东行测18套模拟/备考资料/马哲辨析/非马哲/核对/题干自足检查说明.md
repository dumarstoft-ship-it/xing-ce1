# 政常题：题干是否自足的检查

网页上，用户作答时只看到**导语（lead）、设问（stem）和选项**（选项顺序会打乱）。“适用条件”（condition）、要点和逐项解析要等作答之后才显示。第一批的核对人做题时看得到条件栏，所以可能有这种题：答案唯一要靠条件栏里写的文件、年份、版本、日期或地域，题干本身没写。

你的任务：逐题检查，**只看导语、设问和选项能不能定出唯一答案**。

## 读什么

- 题目：`广东行测18套模拟/备考资料/马哲辨析/site/questions.json`，一行一道题。只看带 `"bank":"fm"` 的行，按任务给的模块（`module` 字段）筛选。这里是已经裁定修改后的版本，字段是：`lead`、`stem`、`opts`（每项 `text`、`correct`、`why`）、`answer`（判断题）、`fix`、`explain`、`condition`。
- 依据：底稿 `学习资料/政治理论常识/非马哲政治理论与广东常识训练底稿_2026-11-27.json` 的 `records`（`correct` 是标准答案依据）；Codex 原文证据 `学习资料/政治理论常识/协作核验/原文证据/*.md`。

## 怎么判

对每道题，先遮住 condition、explain 和各项 why，按考生身份做一遍：

1. 题干和导语有没有写明答案所依赖的文件（全称或可识别的简称）、年份、版本、日期、地域、主体？例如“依据2026年广东省政府工作报告”“截至2026年11月27日”“2025年修订的治安管理处罚法”。
2. 不写这些限定，会不会有另一个选项也说得通，或者判断题可对可错？
3. 只有会出现第2条的情况才需要改。题干已经够用的，不改；只是条件栏写得更细的，也不改。

## 怎么改

- 只改 `lead` 或 `stem`，把缺的限定补进去，改动越少越好，不改变考点和答案。
- 补进去的限定不能泄露答案：只写“依据哪份文件、哪个时点、哪个地域”，不写结论。
- 选项本身有歧义的，在 problem 里说明，不要改选项（我来改）。

## 交付

JSON 数组，存到任务给的路径，只列需要改的题：

```json
{"id": "F-GD-004-1", "problem": "答案依赖……，题干没写", "patch": {"stem": "改后的完整设问"}}
```

`patch` 里写改后的**完整**文本。不要改其他文件，不要 git 提交。完成后回报：查了多少题、改了多少、哪些题你拿不准。
