# 合并记录

把归类人的八份结果并成 `merged.json` 时做过的裁定和改动都记在这里。原题在 `真题/`，知识点以 `知识点目录.md` 为准，目录一句话看不清的地方查了 `题库/` 里那张卡的完整陈述。

## 一、口径

1. S1—S4 只有归类人 a 一份，直接采用，只做第五节的 units 抽查和第六节的命题位改名。
2. S5、S6 有 a、b 两份。逐题比较 domain、slot、units、analog_units、currency，顺带比了 in_scope、style、ask、my_answer。一致的沿用；不一致的打开原题裁定，结果见第三节。topic、trap 两段文字不参与比较，统一取 a 的写法。
3. 同年两张卷共用的题（原题 same_as 非空，另有第七节补记的三对）沿用被指向那道题的最终归类，weight 记 0。
4. units（直接命中）的口径：真题考的就是这张卡讲的那个知识点，即同一个概念、事件、条文或原理，问法和选项不必与卡上的句子相同。卡和题只是同属一个大话题、题眼落在卡没讲的另一件事上，算对不上，删掉。介于两者之间的（同一知识点，但学了这张卡仍答不出这道题）保留，另记进 `weak_units`，画像里的 `weighted_strong` 不计这部分。
5. analog_units（同位卡）的口径：真题考的是当年的时效内容（上年中央全会文件、当年两会、当年省高质量发展大会、新施行的法律、当年广东部署等），题库里装着2026年同一位置的内容，就记为同位卡。两人填的不同、但都属于同一位置的，取并集；与题目不在同一位置的删掉。题目内容长期有效、已有直接命中的，不再另记同位卡（时效题除外，时效题的直接命中卡同时也是今年的同位卡）。
6. currency 的口径：看这道题的知识现在是否仍然成立、仍可原样再考。出自当年讲话但内容是长期有效的理论表述，记“常青”；随年份过期的文件原文、会议、成就、事件记“当年时政”；新通过或新施行的法律政策记“近年新法新政”。
7. in_scope 统一按 domain 填：D1—D8 为 true，D9 以后为 false（见第七节）。

### 2. aggregate.py：弱命中从直接命中里分出来

依据是《复核意见》第三节和《复核意见_近三年》第二节的“连带影响”：原脚本只有覆盖率一处把“只有弱命中”的题单列，知识点个数、命题位下列的卡、前60名的排序、模块对照表、马哲模块分摊（frac_all、frac_d1、frac_recent）都把弱命中算在直接命中里，和画像文首的定义不一致，所以正文说古语题题库管不到，统计却把它们算进了覆盖。

现在统一成一个口径：直接命中 = units 去掉 weak_units；弱命中单独统计，不进直接命中的卡数、题数、加权、分摊和覆盖率。JSON 里的变化：

- slots 的 units 只含直接命中，另加 weak_units。
- unit_hits 只列有直接命中的卡，按直接命中的加权排名；同一张卡的弱命中记在 n_weak、weighted_weak。只有弱命中的卡另列在 weak_only_hits。原来的 weighted（含弱命中）和 weighted_strong 两个字段并成一个 weighted（只算直接命中）。
- module_share 各模块的 units_direct_hit、units_direct_hit_recent、按卡分摊的题数都只算直接命中，另加 units_only_weak；mazhe_inner 的分摊不让弱命中参加，命中的马哲卡全是弱命中的题不进分摊（近三年是 GD2026-Q007、GD2026-Q009）。
- “没被碰到的卡”定义为直接、弱、同位三样都没有。

为了让画像里新加的内容也有出处，脚本另加了几块，都只算直接命中：backtest（回测，对应《复核意见》第四节第3条）、bank_selectable（题库里可选的题，对应第五节第3条）、mazhe_priority（马哲卡按档次的命中）、unit_hits 的 timely_only（直接命中全部来自时效题，对应第五节第2条）、currency 下近三年各卷的时效题题号。脚本可以带一个输出路径重跑，不覆盖正式文件。
