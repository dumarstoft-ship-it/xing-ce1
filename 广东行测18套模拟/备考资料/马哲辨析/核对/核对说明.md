# 马哲辨析新题：盲做核对说明

你是核对人。出题人按 `../出题说明.md` 出了一批马哲辨析新题（仿广东省考真题的判断、单选、多选），要放进用户每天练习的网页。你的任务是**不看答案**独立做一遍，找出答案不唯一、表述有歧义或与教材口径不符的题。

## 规则

1. **只看盲做输入**：`blind_<编号>.json`（每题只有 id、type、lead、stem、options）。在写完盲做结果之前，不要打开 `../新题/` 下的任何文件，也不要看别的核对人的结果。
2. 可以查的：讲义马哲部分（`/home/user/xing-ce1/学习资料/政治理论常识/颜培天广东政治理论常识.pages.jsonl` 第38—44页）、底稿（`/home/user/xing-ce1/学习资料/政治理论常识/马哲概念辨析训练底稿.json`，概念卡的正确句、易错句、解释、条件）、你自己的马原知识（马工程《马克思主义基本原理》口径）。底稿里的卡是知识依据，不是这批题的答案。
3. 每题给出答案和理由：
   - 判断题：正确或错误；错误的写出错在哪。
   - 单选、多选：逐项写对错和理由。多选题答案按字母顺序连写（如 ACD）。
4. 标出问题（写在 doubt 里）：
   - 答案不唯一（两个选项都能选、某个选项可对可错）；
   - 依赖教材口径分歧或有争议的史实、名句；
   - 表述有歧义、主语或范围不清、错字；
   - 只靠绝对词或长短就能猜出答案（练不到概念）。
   没有问题就留空。
5. confidence 写0—1之间的数。

## 交付

写成JSON数组，存到任务给的路径（`核对/check_<你的编号>_<出题人编号>.json`），每题一条：

```json
{"id": "N-M3-001", "answer": "ACD", "confidence": 0.9, "reason": "A……；B……", "doubt": ""}
```

写完后回报：各批题数、你标了doubt的题和理由、你最拿不准的题。不要git提交。
