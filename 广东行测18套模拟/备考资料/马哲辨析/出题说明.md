# 马哲辨析新题：出题说明

用户要一个每天练马哲概念辨析的网页。底稿是 `学习资料/政治理论常识/马哲概念辨析训练底稿.json`（下称底稿）：7个模块、171张概念卡，每张卡有正确句、易错句、解释、条件与边界、例子、来源，另有342道判断题（就是每张卡的正确句和易错句）。底稿的易错句大多带“任何”“只要”“凡”这类绝对词，凭语感就能排除，所以要另出一批**仿广东真题**的新题，专练底稿想区分的概念。用户原话：“题目你可以自己出，尽可能让我训练到相关的概念，能做拓展最好了，可以仿照往年的真题那样出”。

## 先读

1. 底稿里你负责的模块：每张卡的 `correct_statement`、`incorrect_statement`、`explanation`、`necessary_conditions_and_boundaries`，还有 `claude_handoff` 里的 `content_integrity_rules` 和 `appendices.corrected_simplifications`。这些规则对新题同样适用。
2. 讲义马哲部分：`学习资料/政治理论常识/颜培天广东政治理论常识.pages.jsonl` 第38—44页（字段 `pdf_page`、`text`）。
3. 广东真题的马哲题（2024—2026年，共6道，见下）。照它们的问法、长度和陷阱出。
4. 用户做过的模拟卷马哲题：`广东行测18套模拟/重编/政治常识/*.json` 里 `area` 以“马哲”开头的题（24道）。新题不要与它们或下面的真题撞题干、撞选项；同一知识点换角度可以。

## 广东真题的马哲题（照这个味道出）

- 2025年第4题（判断）：科学性是马克思主义理论区别于其他理论的根本特征。（错误）
- 2026年第4题（判断）：生产关系是人类社会发展的根本动力，也是一切社会变迁和政治变革的终极原因。（网友回忆版，无官方答案；按教材是错误）
- 2024年第12题（多选，答案ABC）：先用一句话界定“矛盾的同一性”，再问“关于矛盾的同一性，以下表述正确的有”；D项“矛盾双方的统一是一种矛盾统一体向另一种矛盾统一体过渡的决定性力量”把斗争性的作用安到了同一性上。
- 2024年第14题（多选，答案ACD）：道德起源，B项“道德起源于人与生俱来的善性”。
- 2025年第10题（多选，答案ABD）：一段讲理论思维的引语，问“关于唯物辩证法的认识正确的有”；C项“分析与综合不属于提高辩证思维能力的方法”。
- 2026年第10题（多选）：先界定物质范畴，问“关于马克思主义的物质范畴，下列选项正确的有”；选项有“物质的根本属性是运动”“世界的本原是多种物质的集合”“物质是标志客观实在的哲学范畴”“物质资料的生产方式构成了人类社会存在的基础”。

共同点：
- 判断题是一句话，错误的那句通常只偷换了一处：主宾颠倒（谁决定谁）、根本/直接/首要/唯一互换、层次混淆（矛盾 vs 矛盾的方面、感性 vs 理性）、主体偷换（马克思主义 vs 马克思主义哲学）、作用张冠李戴（同一性的作用安到斗争性上）、条件被删。
- 多选题先有一段引言或界定，再问“以下表述正确的有（）”，4个选项，答案2—4个（真题多是3个）。每个错项都有一处具体的错。
- 用教材通行表述（马工程《马克思主义基本原理》口径）和讲义原句，不用偏僻说法。

## 题型和数量

每位出题人按任务里给的数量出。题型：

- **判断**：一句话。错误题只错一处，`fix` 写改正后的完整句子。正确、错误各占一半左右。
- **单选**：问“下列说法正确的是”“下列说法错误的是”“下列选项中体现……的是”等。4个选项，答案唯一。答案A、B、C、D大致均衡。
- **多选**：引言＋设问＋4个选项，答案2—4个。各种答案个数都要有，3个的多一些。

覆盖：你负责模块的每张**A级卡**至少被一道题考到（做题干、正确项或错项都算）；B级卡挑容易混的考。一道题可以同时连几张卡（`card_ids` 全列上）。

## 不能出的题

- 答案靠“教材口径不同”才能定的题；有争议的史实或名句。拿不准就不出。
- 只靠绝对词就能判断的题：绝对词要同时出现在对的和错的句子里（“一切事物都处在普遍联系之中”是对的），错的句子也可以不带绝对词。
- 选项长短、位置有规律的题（不要总是最长的对）。
- 机械替换关系词凑出来的题（底稿明令禁止）。每道题都要能独立讲清楚为什么对、为什么错。
- 不要把自编题说成真题、官方答案或官方预测。

## 交付

写成一个JSON数组，存到任务里给的路径（`广东行测18套模拟/备考资料/马哲辨析/新题/<你的编号>.json`），每题一条：

```json
{
 "id": "N-M3-001",
 "module_id": "M3",
 "card_ids": ["M3.18", "M3.19"],
 "type": "判断",
 "kind": "仿真题",
 "lead": "",
 "stem": "……",
 "options": {},
 "answer": "错误",
 "fix": "改正后的完整句子（判断题答案为错误时必填，其他留空）",
 "analysis": "解析：判断题讲清错在哪个词、为什么；单选、多选逐项写（A项……正确/错误，因为……）。",
 "trap": "一句话点出陷阱，如“主宾颠倒：是社会存在决定社会意识”",
 "basis": "依据：讲义第41页“……”原句，或教材通行表述",
 "source_refs": ["H", "T"]
}
```

- `type`：判断、单选、多选。`kind`：仿真题（仿广东真题的题）或拓展（名句哲理、著作与来源、跨模块综合等）。
- `answer`：判断题写“正确”或“错误”；单选写一个字母；多选按字母顺序连写，如“ACD”。
- `lead`：多选和需要引言的单选写引言；判断题留空。
- `stem`：设问句（含“（）”）；判断题就是那一句话（不加“（判断题）”）。
- `source_refs` 用底稿 `sources` 里的字母（H讲义、T清华考研笔记、C矛盾论、P实践论、K、E、S、R、D、L、B、G等）；没把握就写H或T。
- 写完自己逐题再做一遍，确认答案唯一；再用脚本检查JSON能解析、字段齐全、答案分布。
- 不要提交（git）。完成后回报：题数、各题型数、答案分布、覆盖了哪些A级卡、哪些卡没考到及原因、你自己拿不准的题。
