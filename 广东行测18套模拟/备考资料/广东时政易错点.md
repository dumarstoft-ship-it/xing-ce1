# 广东时政易错点与重点

**依据**：颜培天《2027广东省考政治理论常识》讲义（下称讲义，页码是PDF页）第五节“广东省情27版”（p59—77）、“十一个广东热点”（p86—87）和党史里涉粤的条目；对照2024—2026年广东真题的6道广东题、M01—M18模拟卷已出的广东题。

**讲义编到哪儿**：广东部分最晚的事件是2026年8月11日湛江“绿钢”下线；APEC工商领导人峰会（2026年11月17—18日，深圳）讲义写的还是“将于”举办；全书最晚是党的二十届五中全会（2026年10月）。这之后的新会议、新报告（如峰会成果、省委全会）讲义没有，要另看。

**怎么用**：【重点】照讲义原文（“……”是省略），加粗的是出题人最爱换的词；【坑】里“→”后面是错项写法，标了题号的是真题或M卷考过的；“存疑”是讲义说法与官方原文或史实有出入，别当判断依据。

## 考前速记

1. 广东是改革开放的**排头兵、先行地、实验区**；大湾区建设中广东要发挥**主力军和火车头**作用（讲义p73、p74、p76）。
2. 使粤港澳大湾区成为新发展格局的**战略支点**、高质量发展的**示范地**、中国式现代化的**引领地**（讲义p77；2024年第9题）。
3. 广东增创新优势、实现新突破，必须大力弘扬**改革开放精神、特区精神**，以**全面深化改革开放**推动高质量发展（讲义p74；2026年第1题）。
4. 2023年4月：坚持以**制造业立省**，更加重视发展**实体经济**；2026年报告：**实体经济为本、制造业当家**（讲义p77、p64）。
5. 2025年11月：强化**科技创新和产业创新**深度融合（讲义p74）。
6. 2026年高质量发展大会以**制造业与服务业协同发展**为主题，在“**制造强省**”与“**服务高地**”相互成就中打开产业发展新天地（讲义p67—68）。
7. 开发横琴的**初心**就是为了**澳门经济适度多元发展**（讲义p75）。
8. 深中通道：全球首个集“**桥、岛、隧、水下互通**”为一体的跨海集群工程，深圳至中山约**2小时**缩短至**30分钟**；大湾区主要城市间基本实现**1小时**通达（讲义p76、p61）。
9. 2025年地区生产总值增长**3.9%**、总量**连续37年**居全国首位；高铁运营总里程**3411公里**、跃居全国第一（讲义p59）。
10. 产量占全国：无人机**9成**、工业机器人**4成**、服务机器人**8成**（讲义p59）。
11. “百县千镇万村高质量发展工程”实现**三年初见成效**（讲义p60）。
12. “十五五”地区生产总值年均增长**5%左右**；从党的二十大到二〇三五年用**13年**时间基本实现社会主义现代化；2026年增长**4.5%—5%**（讲义p63—64）。
13. “五外联动”：**外贸、外资、外包、外经、外智**（讲义p64）。
14. 大陆海岸线长约**4100千米，居全国首位**；全国光、热和水资源**较丰富**的地区（讲义p69；2024年第5题）。
15. 226年另置广州，“**广州**之名由此始”；997年分置广南东、西路，“**广东**”由此得名（讲义p71）。

## 一、总书记对广东的要求

### 1. 2023年4月考察广东（讲义p76—77）

【重点】
- 广东是改革开放的**排头兵、先行地、实验区**……围绕高质量发展这个**首要任务**和构建新发展格局这个**战略任务**……在推进中国式现代化建设中**走在前列**。（讲义p76）
- 树立**大食物观**，既向陆地要食物，也向**海洋**要食物……建设海上牧场、“**蓝色粮仓**”。（讲义p76）
- 这片红树林是“**国宝**”，要像**爱护眼睛**一样守护好。（湛江红树林国家级自然保护区，是我国红树林**面积最大、分布最集中**的自然保护区）（讲义p76）
- 把**徐闻港**打造成连接粤港澳大湾区和海南自由贸易港的现代化水陆交通运输综合枢纽（广东与海南相向而行的“**头号工程**”）；**以水定城、以水定地、以水定人、以水定产**。（讲义p76）
- 把粤港澳大湾区建设作为广东深化改革开放的**大机遇、大文章**……以**珠三角**为主阵地，举全省之力办好这件大事。（讲义p76—77）
- 实现**高水平科技自立自强**，是中国式现代化建设的**关键**……**强化企业主体地位**……打造具有全球影响力的**产业科技创新中心**。（讲义p77）
- 中国式现代化不能走**脱实向虚**的路子……广东要始终坚持以**制造业立省**，更加重视发展**实体经济**。（讲义p77）
- 带动和推进粤东、粤西、粤北地区更好承接**珠三角**地区的产业有序转移。要加强**陆海统筹、山海互济**，强化**港产城**整体布局……全面建设**海洋强省**。要积极推进以**县城**为重要载体的新型城镇化建设。（讲义p77）

【坑】
- 原文：战略支点、示范地、引领地 → 常见错项：“具有世界凝合力的双向开放枢纽”（2024年第9题）。
- 原文：承接**珠三角**地区产业转移 → 常见错项：承接**港澳**地区（M05第15题）。
- 原文：以**制造业**立省 → 常见错项：以**服务业**立省，更加重视发展现代服务业（M16第15题）。
- 原文：首要任务＝高质量发展，战略任务＝构建新发展格局 → 常见错项：两者对调。
- 原文：保护区“面积最大、分布最集中”在**湛江**，国际红树林中心落户**深圳**（讲义p61）→ 常见错项：两地对调（M07第12题）。
- “陆海统筹、山海互济，强化港产城整体布局”体现**必须坚持系统观念**（M17第6题）。

### 2. 2025年11月考察广东（讲义p73—74）

【重点】
- 叶剑英纪念园（梅州）：我们今天取得的伟大成就，都是建立在毛泽东等老一辈革命家打下的**江山**、攒下的**家底**之上的。（讲义p73）
- 发展**乡村特色产业**是推进乡村全面振兴的**基础**……推动**农文旅融合**。（讲义p73）
- 广东作为经济大省和发达地区，在编制“十五五”规划时要有**高站位、大格局**，体现**走在前、作示范、挑大梁**的责任担当。（讲义p73—74）
- 广东增创新优势、实现新突破，必须大力弘扬**改革开放精神、特区精神**，以**全面深化改革开放**推动高质量发展。（讲义p74）
- 要坚持**有效市场和有为政府**相结合……强化**科技创新和产业创新**深度融合……稳步扩大**制度型开放**……继续抓好**对内开放**……带动**中西部**地区产业发展。（讲义p74）
- 建设粤港澳大湾区，对广东来说既是**重大责任**，也是**难得的发展机遇**。要锚定建设富有活力和国际竞争力的**一流湾区和世界级城市群**的目标……广东要发挥**主力军和火车头**作用。（讲义p74）
- 要抓住**干部**这个决定性因素，选优配强领导班子。（讲义p74）

【坑】
- 原文：科技创新和**产业创新** → 常见错项：科技创新和**金融创新**（M03第13题）。
- 原文：**干部**这个决定性因素 → 常见错项：**人才**（M14第15题）。
- “继续抓好**对内开放**”就是原文，别当成“对外开放”的笔误（M03第13题）。
- “排头兵、先行地、实验区”讲广东的**地位**，“主力军和火车头”讲大湾区建设中的**作用**，别混（M01第3题）。

### 3. 2024年12月考察横琴粤澳深度合作区（讲义p74—75）

【重点】
- 横琴地处广东**珠海**南端，与**澳门**一水之隔……**2021年9月**，党中央、国务院发布《横琴粤澳深度合作区建设总体方案》。（讲义p74）
- “澳门+横琴”正在成为丰富“一国两制”实践的**新示范**、推动粤港澳大湾区建设的**新高地**、实现国家高水平对外开放的**新平台**。（讲义p75）
- 一定要牢记开发横琴的**初心**就是为了**澳门经济适度多元发展**。（讲义p75）
- 检验成效，要看在促进澳门经济适度多元发展、便利澳门居民生活就业上……要看在发挥“**两制**”之利、推进两地规则衔接和机制对接上……要看在以琴澳一体化推进粤港澳大湾区市场一体化建设上，有没有发挥**先行先试**的作用。（讲义p75）
- 要不断加强基础设施“**硬联通**”、规则机制“**软联通**”、琴澳居民“**心联通**”。（讲义p75）

【坑】
- 原文：初心是**澳门经济适度多元发展** → 常见错项：把第三个“要看”说成初心（M02第15题）。
- 原文：新示范、新高地、新平台 → 常见错项：三者对调。

### 4. 2024年6月致信祝贺深中通道开通（讲义p75—76）

【重点】
- 深中通道是继**港珠澳大桥**后粤港澳大湾区建成的又一超大型交通工程……中国式现代化是**干**出来的，伟大事业都成于**实干**！（讲义p75）
- 路线全长约**24公里**，**2017年2月**开工建设，历时**7年**建成开通，是全球首个集“**桥、岛、隧、水下互通**”为一体的跨海集群工程……深圳至中山的车程将从目前约**2小时**缩短至**30分钟**。（讲义p75—76）

【坑】
- 原文：“30分钟”只是深中通道；“十四五”回顾是主要城市间基本实现**1小时**通达（讲义p61）→ 常见错项：“主要城市间基本实现半小时通达”（M10第15题）。
- “桥、岛、隧、水下互通”属**深中通道**（2026年第13题D项）。同题A项说黄茅海大桥是珠江口“**首座**”跨江大桥：讲义只说黄茅海通道是“十四五”期间建成的（讲义p61），而虎门大桥1997年就已通车，“首座”站不住，A应是错项；C项虎门大桥“第一座特大型悬索桥”讲义没有。

## 二、广东高质量发展大会

### 1. 2026年大会（讲义p67—69）

【重点】
- 大会以**制造业与服务业协同发展**为主题。……现代化产业体系是中国式现代化的**物质技术基础**。（讲义p67）
- 推动制造业与服务业协同发展，是……实现产业高级化的**必由之路**；……赢得未来主动的**关键之举**；……丰富群众生活的**战略之需**。（讲义p67）
- 要以**制造业之强**牵引**服务业之优**，以服务业之优增进制造业之强，在“**制造强省**”与“**服务高地**”相互成就中打开产业发展新天地。（讲义p67—68）
- 以**科技服务**提升制造业核心竞争力，以**金融服务**为实体经济注入源头活水，以**商务服务**为工业产品开具市场通行证。（讲义p68）
- 要重点培育生态主导型“**头雁**”企业，要大力培育深耕主业的“**尖兵**”企业，要精心培育枢纽型“**平台**”企业。（讲义p68）
- 两业协同**起于科技创新、兴于科技创新**……着力破解“**老规矩管新质生产力**”的问题，最大限度为技术创新和市场探索“**松绑**”。（讲义p68）
- 未来10年……经济总量相比**2022年**实现倍增、达**25.8万亿元**左右；人均地区生产总值相比**2020年**翻一番。（讲义p69）

【坑】
- 原文：“**制造强省**”与“**服务高地**” → 常见错项：“制造大省”与“服务强省”、“智造高地”与“服务强省”（M01第15题）。
- 原文：深耕主业的是“**尖兵**” → 常见错项：“深耕主业的‘头雁’企业”（M13第15题）。
- 原文：必由之路、关键之举、战略之需；科技、金融、商务三种服务的作用 → 常见错项：对调。
- 原文：倍增的基数是**2022年**，翻一番的基数是**2020年** → 常见错项：基年对调。

### 2. 往年大会（讲义没收，只按真题题干和答案写）

【重点】
- 2024年2月：推进产业科技创新，发展新质生产力是广东的**战略之举、长远之策**（2024年第10题题干）。
- 2025年2月：广东从“**三来一补**”起步，从相对落后的农业省发展到牵动全球的**世界工厂**，再到**引领全球的智造基地和新兴产业重要策源地**（2025年第15题，答案C）。

【坑】
- 原文：讲义讲的创新主体都是**企业**（“强化企业主体地位”讲义p77，“强化企业科技创新主体地位”讲义p64）→ 常见错项：“要全力支持高校做创新的主角，推动创新资源向高校集聚”（2024年第10题，答案C）。
- 原文：引领全球的**智造基地**和新兴产业重要**策源地** → 常见错项：“国家重要先进制造业高地”“发展新质生产力的主阵地”（2025年第15题）。

## 三、2026年广东省政府工作报告

### 1. 2025年工作回顾（讲义p59—60）

【重点】
- 地区生产总值增长**3.9%**、总量**连续37年**居全国首位。……货物进出口总额**9.5万亿元**……贡献了全国**24.1**%的增量。（讲义p59）
- 无人机产量……占全国**9成**，工业机器人产量增长**31.2%**、占全国**4成**，服务机器人产量……占全国**8成**。（讲义p59）
- 高铁运营总里程**3411公里**、跃居全国**第一**。……揭阳潮汕机场成为全省**第4个**吞吐量超千万人次的机场。（讲义p59）
- 研发投入强度达**3.6%**……“**深圳—香港—广州**”创新集群跃居**全球首位**；全省研发人员达159万人、高技能人才达843万人，均居全国**首位**。（讲义p59—60）
- **连续6年**成为全国**唯一**出生人口超百万的省份。（讲义p60）

【坑】
- 原文：工业机器人**4成**、无人机**9成** → 常见错项：“工业机器人产量增长31.2%、占全国9成”（M06第12题）。
- 原文：研发人员、高技能人才均居全国**首位** → 常见错项：“均居全国第二”（M17第15题）。
- 37年、3411公里、第4个千万级机场、24.1%、3.6%：只改一个数就是错项。
- 存疑：广州实验室研发上市“**全球首个**”抗甲流PB2新药（讲义p60），“全球首个”未核实。

### 2. “十四五”时期回顾（讲义p61）

【重点】
- 第一产业增加值提升至全国**第二**……**数字经济**规模稳居全国**首位**。（讲义p61）
- 预计大湾区经济总量突破**15万亿元**……建成深中通道、**黄茅海通道**……主要城市间基本实现**1小时**通达。（讲义p61）
- 区域创新能力**连续9年**全国第一。……“**梦想**”号**大洋钻探船**等大国重器建成入列。（讲义p61）
- **连续4年**获评全国营商环境最佳口碑省份。……全省常住人口城镇化率提高到**76.58%**、居各省区**首位**。（讲义p61）

【坑】
- 原文：第一产业增加值全国**第二** → 常见错项：“跃居全国首位”（M01第12题）。
- 原文：**1小时**通达 → 常见错项：“半小时通达”（M10第15题）。
- 原文：“梦想”号是**大洋钻探船** → 常见错项：“深海载人潜水器‘梦想’号”（2025年第11题）。
- 存疑：这一栏讲义列的“麒麟高端芯片”，出题人核查时没在报告原文里找到，题目问“报告”时别靠这一项。

### 3. “十五五”目标任务（讲义p62—64）

【重点】
- 广东处在改革开放前沿和链接内外循环的**关键节点**……新兴产业未来产业诸多领域的**先发优势**……**庞大且年轻**的人口优势等更多更强的综合优势。（讲义p62）
- 锚定在推进中国式现代化建设中**走在前列**的**总目标**，紧扣坚定不移**挑好大梁**、全面推进**强省建设**的**总任务**……以**全面从严治党**为根本保障，深入落实省委“**1310**”具体部署。（讲义p62）
- 地区生产总值年均增长**5%左右**……从党的二十大到二〇三五年，用**13年**时间基本实现社会主义现代化，经济总量实现**倍增**。（讲义p63）
- 一是聚焦**经济建设**这一**中心工作**。二是锚定**高质量发展**这一**首要任务**。三是坚定**走在前列**这一**目标定位**。四是践行**为人民服务**这一**根本宗旨**。五是激活**改革开放创新**这**三大动力**。（讲义p63）
