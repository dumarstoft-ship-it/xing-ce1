- 自编速练由程序按规律出题（`构建/gen.js`），每道题由生成器名和种子完全确定，错题本只存这两项、可原样重出。出题时排除了答案不唯一的情况：别的常见运算也能解释给出的数、却指向另一个答案的，换一道；数交点图要求交点之间、线头与别的线之间留足距离，不出“看不清碰没碰到”的图。

## 文件

- `site/`：网页（index.html、data.json、fig/题图）。
- `构建/`：`page.html`（页面模板）、`gen.js`（自编题生成器）、`svg.js`（自编图形）、`config.json`（分组、方法要点、首页计划）、`build.py`（组装 data.json 和题图）、`assemble.py`（把生成器嵌进页面）、`ss_extra.py`→`ss_extra.json`（数推“三项关系”真题的答案与解析）、`fig_more.py`→`fig_more.json`（第二批图推题的答案与解析）、`frac_real.py`→`frac_real.json`（江浙卷分数数列）、`frac_more.py`→`frac_more.json`（国考、粉笔模考分数数列）、`check_frac.js`（分数速练独立复核）、`check_ss.js`（用程序穷举常见三项运算复核答案）、测试脚本；`解题记录/` 是解题人原始记录。
- 重新生成：`python3 构建/build.py site && python3 构建/assemble.py site`（在本目录下运行；build.py 里的路径指向仓库原卷和临时目录，换环境要改）。
