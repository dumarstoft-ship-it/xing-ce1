# 行测弱项特训（M10错题对应）

网页：[行测弱项特训](https://claude.ai/artifact/86qkpDE9naLPsPFkerDv2U)（手机、电脑都能用，做题记录跨设备同步；答错的题自动进错题本）。错题和对应规律另记在 [错题本.md](错题本.md)。

## 练什么

| 部分 | 对应M10 | 真题 | 自编速练（题量不限） |
| --- | --- | --- | --- |
| 图推·数交点 | 第47题 | 见网页 | 数交点、曲直交点：答完在图上标出全部交点 |
| 图推·灰格计数 | 第48题 | 见网页 | 灰格分区计数：两组方格图，按行、按列、按整体数 |
| 数推·三项关系 | 第33、35题（着重） | 39道（递推23、数表和圆圈10、进阶6） | 递推、数表、混合：每天至少一轮 |
| 资料·比重与比率 | 第73题 | 10道 | — |

每组真题前有方法要点（怎么认、怎么做、常见考法、易错）。真题解析分题眼、推导、易错三段。

## 题从哪里来

- 国考2014—2021年、江苏2020年A类：用官方答案和解析核对，解析重写成题眼—推导—易错。
- 粉笔模考第24—33季（M01—M08只用到第23季，这几季除三道借题外都没用过）：原卷不附答案，答案由解题人逐题算出，图推另由第二人只看题面盲做，两人一致才收。
- 广东旧卷、广东事业单位统考里与这几条规律相同的题，都已经在专项或模考里用过：网页里标“复习”放在组末；留给M11以后各套的题没有动。
- 避开了用户做过的《平面图推200题》（2021—2026年各地题）、24天集训前两天、2024—2026年广东卷。
- 自编速练由程序按规律出题（`构建/gen.js`），每道题由生成器名和种子完全确定，错题本只存这两项、可原样重出。出题时排除了答案不唯一的情况：别的常见运算也能解释给出的数、却指向另一个答案的，换一道；数交点图要求交点之间、线头与别的线之间留足距离，不出“看不清碰没碰到”的图。

## 文件

- `site/`：网页（index.html、data.json、fig/题图）。
- `构建/`：`page.html`（页面模板）、`gen.js`（自编题生成器）、`svg.js`（自编图形）、`config.json`（分组、方法要点、首页计划）、`build.py`（组装 data.json 和题图）、`assemble.py`（把生成器嵌进页面）、`ss_extra.py`→`ss_extra.json`（数推“三项关系”真题的答案与解析）、`check_ss.js`（用程序穷举常见三项运算复核答案）、测试脚本；`解题记录/` 是解题人原始记录。
- 重新生成：`python3 构建/build.py site && python3 构建/assemble.py site`（在本目录下运行；build.py 里的路径指向仓库原卷和临时目录，换环境要改）。
