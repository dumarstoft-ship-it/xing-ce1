# 打印排版｜考场样式题本

把任一套的 `题目.jsonl`（考生可见内容，不含答案）排成可直接打印的A4题本PDF。版式取自用户提供的粉笔样卷，字体取自中公样卷，18套共用。

```bash
python3 广东行测18套模拟/打印排版/build_print.py M01 --font-dir <字体目录>
```

输出到 `<套卷>/打印版/`：`M01_题本_打印版.pdf` 与 `排版日志.json`。日志列出每一项排版层面的处理、题图尺寸来源、选项排法和题号所在页，可逐条核对。

## 印刷建议

A4、**实际大小（100%）**打印，不要选“适合页面”。双面打印时第1张为封面＋注意事项，正文从第2张正面开始，可在左侧装订线处装订。答题卡由用户自购：判断题正确涂A、错误涂B。

## 依赖

| 依赖 | 用途 |
| --- | --- |
| Python 3：`pypdf`、`pdfplumber`、`Pillow`；可选 `fontTools` | 生成、合并、检查PDF；按PostScript名识别字体 |
| Node.js ＋ `playwright`（Chromium） | HTML 印成 PDF |
| `pdffonts`（poppler-utils） | 检查是否出现缺字回退 |

### 字体（不入库）

| 角色 | 字体 | PostScript名 |
| --- | --- | --- |
| 正文、选项、表格 | 方正书宋简体 | FZSSJW--GB1-0 |
| 部分标题、说明、表头、封面 | 方正黑体简体 | FZHTJW--GB1-0 |
| 重要提示、注意事项 | 方正楷体简体 | FZKTJW--GB1-0 |
| ASCII数字与字母 | Times New Roman；缺省时用度量兼容的 Liberation Serif | — |

以上即中公样卷PDF实际嵌入的字体。方正这三款可从方正字库官网获取，个人非商业使用免费；字体文件允许嵌入文档（OS/2 fsType=0x0008）。生成的PDF只嵌入用到的字形子集。缺字时构建会直接报错，不会悄悄换成别的字体。

## 版式依据（粉笔样卷300dpi实测）

| 项目 | 粉笔样卷 | 本排版 |
| --- | --- | --- |
| 纸张 | A4 | A4 |
| 正文 | 小四12pt，每行36字，行距约22.9pt | 同 |
| 题号 / 正文左缘 / 正文右缘 | 20.3 / 29.3 / 181.7 mm | 20.5 / 29.4 / 181.7 mm |
| 部分标题 | 黑体约18pt，居中，另起一页 | 同 |
| 部分说明 | 黑体约13.5pt，行距约21.5pt | 同 |
| 选项 | 9字网格：4列在0/9/18/27字处，2列在0/18字处，否则每项一行 | 同；按实际文字宽度自动选列 |
| 页脚 | 五号“第X页 共Y页”，封面不计页 | 同 |
| 部分结尾 | “※※※ 第一部分结束，请继续做第二部分！※※※”，全卷末“全部测验到此结束” | 同 |
| 封面 | 左侧装订线及竖排准考证号、姓名；右上方框；标题；重要提示；虚线下条形码粘贴处 | 同；方框文字为“仅供个人练习使用” |

中公与粉笔样卷都是模仿考场题本。粉笔样卷没有注意事项页；本排版按中公样卷把注意事项印在封面背面，可用 `--no-notice` 去掉。部分名称与广东2025、2026年卷一致（第二部分为“常识判断”）。

## 排版层面的处理（不改题意，均记入日志）

- 合并源PDF的行末硬换行；保留列表、对话、设问行等真实分段。
- 空括号统一为“（　）”；判断题题末补答题括号，并印“A.正确 B.错误”。
- 填空线统一长度；“·····”改为“……”；设问行末缺冒号时补上。
- 图推“选项在图中”的占位文字（“见题图中标为A的选项”）不印。
- 资料表格：删去转写者写进表中的注记（如“原表未标注”）；备注中“原表缺省项”改为“表示该项数据缺省”；两列长表改横排；两张窄表并排；列宽按内容计算，正文格不折行。
- 题图按源PDF中的原印刷尺寸，并按考场常见尺寸设上限：题干图宽≤120mm、高≤100mm。低分辨率原图不放大。

## 重绘题图

`redraw_figures.py` 只处理印刷时会看不清的小图。重绘按原图像素坐标完成，并与原图逐像素叠图核对。记录在 `重绘/重绘核对记录.json`，构建时只在源图SHA-256未变时才替换。目前只有M01第70题经纬网：原图271×220像素，纬度标注印出来字高约1.2mm。重绘后印80mm宽，原图深色像素有95.7%在重绘笔画1像素内，重绘深色像素有98.3%落在原图笔画上。源题库图片不改动。

## 已知限制

- 资料分析的原图表在题库中只有转写表格，没有原图，打印版以表格呈现。题号为“图1/图2”的材料也是表格。
- 江浙原卷PDF不在本仓库，图推题图沿用题库提取的原图。
- 版面在不同字体环境下会有细微差异，以本仓库生成的PDF为准。
