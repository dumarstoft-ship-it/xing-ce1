# 打印排版｜考场样式题本

把任一套的 `题目.jsonl`（考生可见内容，不含答案）排成可直接打印的A4题本PDF。版式取自用户提供的粉笔样卷，字体取自中公样卷，18套共用。

版面按实考的样子排，不为阅读舒适另作调整：题图按原卷印刷尺寸，题目和资料按顺序连续排，跨页、翻页照常发生。

```bash
python3 广东行测18套模拟/打印排版/build_print.py M01 --font-dir <字体目录>
```

输出到 `<套卷>/打印版/`：`M01_题本_打印版.pdf` 与 `排版日志.json`。日志列出每一项排版层面的处理、题图尺寸来源、选项排法和题号所在页，可逐条核对。

构建结束前自动检查：

- 只用了指定字体，没有缺字回退；
- 页脚页码连续；
- 题号按序出现；
- 题干、选项、资料文字按顺序出现在PDF文字层中，表格数值逐格出现。

`题目.jsonl` 的SHA-256记入日志，作为底稿指纹。

## 印刷建议

A4、**实际大小（100%）**打印，不要选“适合页面”。双面打印时第1张为封面＋注意事项，正文从第2张正面开始，可在左侧装订线处装订。答题卡由用户自购：判断题正确涂A、错误涂B。

## 依赖

| 依赖 | 用途 |
| --- | --- |
| Python 3：`pypdf`、`pdfplumber`、`Pillow`；可选 `fontTools` | 生成、合并、检查PDF；按PostScript名识别字体 |
| Node.js ＋ `playwright`（Chromium） | HTML 印成 PDF |

### 字体（不入库）

| 角色 | 字体 | PostScript名 |
| --- | --- | --- |
| 正文、选项、表格 | 方正书宋简体 | FZSSJW--GB1-0 |
| 部分标题、说明、表头、封面 | 方正黑体简体 | FZHTJW--GB1-0 |
| 重要提示、注意事项 | 方正楷体简体 | FZKTJW--GB1-0 |
| ASCII数字与字母 | Times New Roman；缺省时用度量兼容的 Liberation Serif | — |
| 补字：书宋（GB2312版）没有的生僻字 | 思源宋体（Noto Serif SC）含该字的子集，如 `@fontsource/noto-serif-sc` 的 `noto-serif-sc-73-400-normal.woff2`（含“岕”） | 放入字体目录，文件名以“补字”开头 |
| 补字（后备）：上面的子集也没有的字 | 思源宋体完整版 Noto Serif CJK SC Regular（如Debian包 `fonts-noto-cjk` 的 `NotoSerifCJK-Regular.ttc` 中SC字体），可用fontTools截取汉字部分，命名 `补字_后备_noto-serif-cjk-sc-regular.otf`（含“煻”） | 文件名排在前一个补字字体之后 |

以上即中公样卷PDF实际嵌入的字体。方正这三款可从方正字库官网获取，个人非商业使用免费；字体文件允许嵌入文档（OS/2 fsType=0x0008）。生成的PDF只嵌入用到的字形子集。书宋缺的生僻字只由“补字”字体排印，逐字记入日志；补字字体可以有多个，按文件名排序，前一个没有的字才由后一个补；连补字字体也没有的字，构建会直接报错，不会悄悄换成别的字体。思源宋体为SIL开源字体，允许嵌入。

## 排版层面的处理（不改题意，均记入日志）

- 合并源PDF的行末硬换行：只合并在句中断开的行；句末标点后、列表、对话（含“小朱：”这类两到四字称呼开头的行）、以问号或答题括号结尾的设问行的换行一律保留（误合并会改变题目结构，误保留至多多一个短行）。底稿已规范化时不合并任何行。
- 空括号统一为“（　）”；判断题题末补答题括号，并印“A.正确 B.错误”。
- 填空线统一长度；用一串空格充当的填空位置改为填空线（网页排版会把连续空格折成一个，横线就印不出来）；题面提到“横线”却没有填空线时构建报错；“·····”改为“……”；设问行末缺冒号时补上。
- 填空线与紧邻的句号、逗号、引号粘在一起，不在中间断行（网页排版会在填空线后断行，标点落到下一行行首）。构建时逐行检查正文，行首出现句号、逗号等就报错；行首是填空线、标点紧跟其后的不算。
- 图推“选项在图中”的占位文字（“见题图中标为A的选项”“见题图中的 A 选项”）不印；底稿没有标 `in_figure` 时按占位文字识别，记入日志。
- 原卷加下划线的文字（题库转写为 `<u>…</u>`，如“画线词”）印下划线；题面提到“画线”而没有填空线也没有下划线时构建报错。
- 转写留下的空白和半角标点：填空线两侧的空格、数字与汉字之间的空格（“6 条”“3000 米”）删去；汉字后的半角冒号、问号、分号、逗号改为全角。
- 资料表格：删去转写者写进表中的注记（如“原表未标注”“原表空白”）；备注中“原表缺省项”改为“表示该项数据缺省”，“原表未给出数据”改为“未给出数据”；只说明转写过程的备注句（含“原表、依题干、转写、不补算、原图、单元格展开”）删去，但说明“—”含义的句子不论措辞一律保留，真实备注保留；两列长表在放得下时改横排；两张窄表并排；表题用表格标题行，随表宽折行；列宽按内容计算，正文格不折行。
- 图形选项（如饼图选项）：按原印刷尺寸排，四幅一行放得下就排一行，否则两列。
- 分页：约6行以内的非资料题和所有带图、带表的非资料题整题不跨页；其余按顺序排，资料组跨过翻页也照常排。
- 可选 `--avoid-page-turns`（默认不用）：为阅读方便挪动版面，会改变实考样貌。开启后：
  - 从右页开始、延续到背面的资料组，改从下一个左页开始（部分内第一组和已在页首的组不挪）；
  - 从右页延续到背面、不长于约18行的非资料题，逐题试着整题移到下一页，只接受不改变后面各部分起始页和总页数的移动；
  - 两项都记入日志；正文第1页按双面印刷时的右页计算。
- M01、M02打印版是开着资料组挪页生成的，见下文“早期为阅读舒适所做的调整”。
- 题图按源PDF中的原印刷尺寸，并按考场常见尺寸设上限：题干图宽≤120mm、高≤100mm。不为看清而放大。没有源印刷尺寸的重建图另行登记印宽，见下节。

## 排版空白勘误

`排版空白勘误.json` 登记底稿丢掉原卷空白的地方，排版时按原卷恢复。只许改空格和换行，文字和标点一个不改。每条记下底稿那段文字的SHA-256和原卷依据：

- 底稿那段文字变了，构建报错，须重新核对原卷；
- 底稿已改成与登记相同，构建照常，日志提示这条登记可以删除。

目前没有登记。此前登记过旧M04 0.2.0第17、19题（浙江2025年A类第32题、浙江2026年A类第28题的选项词间空格等）；2026-11-16五套重编后这两题不再使用，旧M04已归档，登记随之删去。

## 已知限制

- 资料分析的原图表在题库中只有转写表格，没有原图，打印版以表格呈现。题号为“图1/图2”的材料也是表格。
- 江浙原卷PDF不在本仓库，图推题图沿用题库提取的原图。
- 版面在不同字体环境下会有细微差异，以本仓库生成的PDF为准。

2026-11-16（M07编排时发现）：M01、M04打印版的资料表格注里，各有一句转写说明照原样印了出来（M01“‘—’为原表未给出的数据”，M04“‘—’为原表符号，不补算”）。排版工具补了这两种说法，统一印成“‘—’表示未给出数据”，两套重排，页码分布不变，题本底稿不变。统计图下的“注”如果是题库转写时加的说明，由组卷时在 `重编/charts/specs.json` 标 `drop_note` 不印。

2026-11-16（M07排版时发现）：数字推理的数阵（各季第35题“题目数表”）在题库里转成了表，转写时加了表题“题目数表”和“第1列”这类列名；原卷只是数字方格。排版工具现在识别这种情况，只印数字方格。M01、M03、M07因此重排，页码分布不变，题本底稿不变。

2026-11-16（M08排版时发现）：方正书宋（GB2312版）没有“〇”（U+3007，如“二〇三五年”）。排版工具遇到书宋缺字会报错并提示补字；M08在字体目录加了思源宋体的分片 `补字_noto-serif-sc-86-400-normal.woff2`（来自 @fontsource/noto-serif-sc，含该字），由补字字体排印并记入排版日志。字体文件不入库。
