## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；判断推理和科学推理另由第二人只看题面独立再做（25题），三方对照。换入的题另由第二人只看题面盲做（1题），与来源答案一致。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。
- 原第64题（前提假设，县农业部门干部任驻村队长）两名解题人各自盲解都选B（农民收入是评价乡村振兴成效的重要指标），来源答案C（成效“只能”用农业产业发展衡量），答案可商榷，已换题；换入的2016年县级卷第78题两人盲解都是D，与来源答案一致。
- 第65题（加强）：第二人选C，第一位解题人和来源答案为D。C讲职业素养靠学校思想道德教育提升，说不出医德为什么比专业知识更要紧；D说患者更看重医生的道德素养，直接回应“很难适应社会需求”。按D，解析写明C为什么不如D。
- 第75题所在材料原句“重复用水量超过1000万立方米以上的企业88家，仅占重复用水量的96.2%”说不通，按第75题C项的用法和来源解析改明，数据不变。
- 第81—85题的材料是2021年乡镇卷的回忆版（原注“真实性有待核实”），答案键只有一行、没有解析；解题人按材料逐题重算，五题都与答案键一致，材料内部的合计、增速也自洽。第二张表标题图中印作“产业园大行业”，“园”应为“四”，错在原图里，不影响作答。
- 第48题原卷只在部分说明里写答题要求，补了通行题干；第37题设问补单位“天”。

## 难度

- 资料分析：读一眼就能判断1道、一步13道、两步6道、三步及以上0道（多步6道）；熟练考生连扫读材料约13.5分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步4道（两步4、三步及以上0），熟练考生约5.5分钟；近三年真题多步6—7道。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。按考场时段计时90分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：资料分析比较排序4道（真题3★）；资料分析材料理解0道（真题2—5★）；资料分析平均数2道（真题0—1）。
