## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- 第31—90题由三人分块先盲解、再对照来源答案，60题全部一致；言语15题选题人自做和第二人盲做都与来源答案一致。加量套没有安排第二人盲做判断推理和科推。
- 资料第79题题库记有一版答案作B，按原版解析和逐项重算为C（③①④②），用C；第76题原卷问增长率却写“个百分点”，来源解析也说表述不严谨，设问改为“同比增长约（　）%”。
- 第35题原卷是上下排的分数，按原卷排成分数；第29、52、58、60、61、62、64题原文档把设问并进上一段，设问另起一行。

## 难度

- 资料分析：读一眼就能判断6道、一步9道、两步3道、三步及以上2道（多步5道）；熟练考生连扫读材料约12.2分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步5道（两步5、三步及以上0），熟练考生约4.5分钟；近三年真题多步6—7道。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。建议限时75分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：数学运算最值与构造0道（真题1★）；数学运算排列组合与概率0道（真题1—2★）；数学运算浓度、容斥2道（真题0）；逻辑判断分析推理1道（真题2—3★）；逻辑判断真假推理1道（真题0）；逻辑判断削弱3道（真题1—2★）；逻辑判断加强0道（真题1—2★）；逻辑判断结构比较2道（真题3★）；逻辑判断归纳结论1道（真题0）；科学推理地理0道（真题1★）；资料分析比较排序7道（真题3★）；资料分析比重1道（真题2—5★）；资料分析现期量与简单计算0道（真题1—2★）；资料分析平均数2道（真题0—1）。
