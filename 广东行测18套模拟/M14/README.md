## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；判断推理和科学推理另由第二人只看题面独立再做（25题），三方对照。换入的题另由第二人只看题面盲做（2题），与来源答案一致。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。
- 原第60题（钢材关税）、第70题（冰块杯子的杯壁温度）解题人和第二人各自盲解都与来源答案不同，已换，原题列入“题目有问题”；第56题为减少反向设问而换。理由都见“与原题不同的地方”。换入的第56、70题第二人盲做与来源答案一致（第70题解题人此前看过那一页解析，以第二人盲做为准）；第60题编M13时解题人和第二人都盲做过，与来源答案一致。
- 选题时按题池的记录先换掉了两题（几何“草坪外圈石子带”题干表述不严谨、统筹“无人机施肥”要靠题干没写的条件），这两题也列入“题目有问题”。
- 第78题问四类乘用车“同比变化幅度”的大小关系：资料分析里“变化幅度”比较的是增减的大小（绝对值），交叉型乘用车下降18.1%按18.1%排，答案A，来源解析同；把下降当负数排在最后会误选D。题干照原卷，解析写明口径。
- 第66题原作“从B点垂直向下用力”，读成“垂直于杠杆”答案会变，题图画的是竖直向下的力，改为“竖直向下”。
- 资料第76—80题材料“中国品牌SUV销售55万辆……占SUV市场份额44.76%”前后对不上（55÷408约13.5%），原卷如此，各题不用这句。
- 数推第34题、数学第38、41题取自江苏省考A类卷，三题的来源答案行与来源解析正文算出的答案都一致。
- 言语15题选题人自做和第二人盲做都与来源答案一致。政治常识10题两步盲做与答案一致；第9题D项讲义作延安整风的“宗旨”，官方表述是“方针”（毛泽东《整顿党的作风》），按官方写作“方针”。

## 难度

- 资料分析：读一眼就能判断4道、一步6道、两步7道、三步及以上3道（多步10道）；熟练考生连扫读材料约15.1分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步7道（两步7、三步及以上0），熟练考生约7.3分钟；近三年真题多步6—7道。
- 本套按用户要求适当偏难（2026-11-25）。数学多步7道，第38、41题是江苏省考A类卷难题，第41题来源标注全站正确率7%；数推第34题也是江苏卷题。本套资料换了一位解题人评（多步10道、约15.1分钟），他计步和估秒都比M12、M13的评分人宽，几套的数字不能直接比；按题池的统一评法，本套资料多步8道（M12也是8道）。
- 数推、图推、科推按解题人评级：数推难2中2易1，图推难2中2易1，科推难1中4；逻辑评为难的2道（第62、63题，都是条件关系的结构比较）。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。按考场时段计时90分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：数学运算最值与构造0道（真题1★）；数学运算浓度、容斥1道（真题0）；资料分析比较排序6道（真题3★）；资料分析增长量0道（真题1—3★）；资料分析现期量与简单计算3道（真题1—2★）；资料分析材料理解1道（真题2—5★）；资料分析倍数2道（真题0—1）。
