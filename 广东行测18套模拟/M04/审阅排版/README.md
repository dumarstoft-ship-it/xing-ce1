# M04 审阅题本PDF

[M04_题本_打印版.pdf](M04_题本_打印版.pdf)依据0.1.0考生数据生成，共32页（2页封面和注意事项、30页正文）。封面明确标为“待审阅”，Claude外部审核尚未进行；这份排版不替代内容定稿。

## 打印设置

A4、100%实际大小；双面时使用长边翻页。正文页码从PDF物理第3页开始。题本与答案解析分开，PDF不包含答案或难度、题源提示。训练时限沿用90分钟。

正文沿用公共排版的方正书宋简体12pt、36字版心、22.9pt行距，标题与说明使用方正黑体，封面提示使用方正楷体。西文数字使用度量兼容的Liberation Serif。字体文件未入仓库；PDF嵌入字体子集。

现有方正GB2312版缺少“岕”，第28题“罗岕茶”的该单字使用Noto Serif CJK补字；其余正文仍为指定方正字体。此处保留正确地名，不将缺字替换为别字。字体核验从PDF内嵌字体流检查PostScript名，不能只凭渲染器赋予的ZG别名判断。

## 生成与检查

当前环境不允许Chromium所需的本地进程通信，已改用WeasyPrint离线渲染，公共排版文件未改。`../build_review_print.py`复用公共题本生成、内容比较和页码校验，并处理分数的行内呈现、选项分列、第64题对话分段和铁路材料独立起页。

```sh
python 广东行测18套模拟/M04/build_review_print.py M04 --font-dir /字体目录 --out 广东行测18套模拟/M04/审阅排版 --badge '待审阅|练习用卷'
```

需WeasyPrint 70、fontTools、pdfplumber、pypdf，以及Poppler工具；实际检验环境另有PyMuPDF。原方正字体从用户可合法使用的本地目录提供。

[排版日志](排版日志.json)记录考生数据指纹、题号页码、自动内容比对、选项分列与排版处理。[打印核验](打印核验.json)记录最终PDF指纹、实际逐页查看、字体来源和已闭环问题。全部32页均有人工作为图像查看：1—13页、17—27页由分工审读者核对，14—16及28—32页由整卷负责人核对；第23页修订后另行复看。

初版发现的分数跨行呈现、罕见字回退以及第64题换段问题已处理；铁路材料首段已移回同组页面。题干、选项、资料文本和表格数值通过与`题目.jsonl`的自动比对。源题内容准确性仍按整卷审核交接独立审查。
