# M04 数量与资料：选编及核验说明

本模块含第31—45题数量关系、第71—90题资料分析，共35题。底稿为 `quant_data.json`，与M03逐题结构相容；全部 `source_question` 均保持源库原对象，编辑变化另列。没有机构参考答案可供比较，文中答案均为编辑独立推导；数量15题与资料20题已分别完成内部第二读者核验，外部Claude审核尚未进行。核验记录中的初始理由与后续勘误分别保留。

## 选择判断

数量保留5道数字推理和10道数学运算。数推分别从二级差、共同分母、小数点两侧、相邻递推、平方外形进入；数学运算覆盖整数比例、利润分母、几何与端点、故障行程、资源分配、优惠上界、补集覆盖、抽样组合、点位合并、相邻限制。没有为答案字母调整题目，也没有把原题只换数后冒称新题。

第40题用配套零件分工形成真实的最优分配问题。解析既说明为什么让B优先生产螺丝帽，也给出总时间下界及52小时可行方案。第42题的容斥下界和第41题优惠上界都附可实现构造，防止“算出界”就等同于“达到界”。第43、45题先固定无序四人组或完整队列这一计数对象，解释重数来源。

资料四组分别为：

|M04题号|源材料|本组的主要作用|
|---|---|---|
|71—75|第26季材料1，绿美广东|保留广东材料的文字检索、时期与范围辨别，包含部分占比与期间平均数|
|76—80|第24季材料1，房地产|正负增速、基期差、混合增长、可计算性判断|
|81—85|第27季材料4，显示模组出口|季度聚合、高增长下单价变化、单位换算、基期倍数与直接比较|
|86—90|第23季材料4，铁路运输|平均数变化、两种基期还原、年均间隔、增速趋势图|

四组各5题完整保留，没有把材料拆为不同组拼凑。文字定位题的任务是核对材料信息范围，源题自然负担保留；不是为了预设简单题比例而增设的题。

## 源材料筛查与保留边界

筛查中放弃了第32季材料2（数字阅读）：其“作品总量5271.86万部”和三类分项“3458.84、206.92、87.49万部”的差额达1518.61万部，显然不能由材料末尾的四舍五入说明解释。该组又有作品总量及分类增量设问，不能把问题当作与解题完全无关的文字简单删去。此处记录为本轮候选淘汰，不写成已经用于M04，也不篡改源库。

房地产及显示模组表格按仓库转写数据运算；铁路正文“50.35亿吨”与表内“503535万吨”的差异与显示精度相容。没有本轮取得的原PDF逐格比对证据，因此不能把“题内一致、可计算”冒称“已对照原卷”。

第90题的A—D四张原始折线图均已实际查看。观测到的末段方向分别为下降、下降、上升、上升，结合前三段与高度关系，只有A符合本题计算的7.81%、3.18%、4.86%、4.41%。核验报告保存四图路径与SHA-256，使用现有源图，不虚称原图重绘或精确坐标恢复。

## 实际完成的核验

运行 `python 广东行测18套模拟/M04/编辑底稿/quant_data_check.py` 通过，输出 `quant_data_check.json`：

- 35题独立模型计算与编辑答案一致；全部已知数列项都进入关系检查。
- 第36题枚举100人以内的整数可行解；第38题核实直线端点与闭合边界后枚举整数三角形。
- 第40题枚举两车间全部整数螺丝钉分配，确认51小时不可行、52小时可行；另保留连续模型下界。
- 第41、42题均核验达到上界或下界的具体构造。
- 第43题遍历60个无序四人组；第45题遍历8!个队列。
- 资料题逐项从表格读取数值，核验全部选项相关计算；四组共用材料一致性及原始source_question逐对象保全均通过。
- 运行前核对35题考生可见输入指纹。若题面被改动，旧核验会拒绝通过，需要重新审读与更新输入契约；不会把旧输入的计算报告冒称为新题面核验。

`excluded_source_ids.json` 收集了本次读到的M01—M03选编底稿、撤题记录和用题登记中的广东模考源ID，35题无交集。旧专项的跨文本曝光检索由整卷环节统一进行；未命中也不证明用户从未在其他场景见过。

这些是当前题面的编辑核验，不能替代另一位审读者，也不能预先声称Claude已审核。数列的自然规律性、文字推断边界、整体训练价值仍须人工判断。
