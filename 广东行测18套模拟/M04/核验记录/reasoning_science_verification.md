## 选题取舍

这部分题按核心推理方法和材料多样性选择，没有规定易题占比，也没有按答案字母配平。图形题分别考循环移位、头尾不同步增长、图符同一性结构、折叠后面内方向、立体连接结构。逻辑部分同时保留条件推理、加强、削弱、前提、解释比例变化、真假约束、对话结构与范围辨析，避免15题都落成短小的单步支持/反对题。

科学推理覆盖受力与摩擦、电路、电化学性质区分、遗传和海陆风。第66、67题保留建模步骤与读图负荷；第68—70题保留知识辨析的自然难度，不为了让每题更难而额外拼接条件。

## 源答案与编辑答案

10道江浙题有仓库参考答案，最终编辑答案全部与其一致。其余15道广东模考题，包括全部5道科学推理题，源库参考答案为空，均明确标为编辑推导答案，未冒充官方或原卷答案。所有25条`source_question`均与源JSONL对象完全相等。

`reasoning_initial_answers.json`保留先读题作答的初始记录。该记录不是隔离环境下的模型盲测，pending也没有事后覆盖。初始第57题D属于后来淘汰的江苏2022 A 100题；最终第57题已换成投诉率题，答案为A。不能将这两项当作同一道题的改键。

题源排重覆盖用题登记、M01—M03现用源ID、整卷维护的排除ID表，以及旧图推200题和固定题型178题的已识别源ID。未命中不等于已经证明用户未在其他资料中见过，也不代表完成了全库视觉同图排查。

## 可复现核验

运行顺序为：

```sh
python 广东行测18套模拟/M04/编辑底稿/draw_reasoning_science.py
python 广东行测18套模拟/M04/编辑底稿/build_reasoning_science.py
python 广东行测18套模拟/M04/核验记录/check_reasoning_science.py
```

核验脚本使用标准库、NumPy；重绘还使用Pillow和Noto CJK字体。它不依赖临时工作目录或网络。`reasoning_science_verification.json`记录源文件、模块与图形的SHA-256，33项检查、唯一配置、立体匹配关系和示例电路表示数。

代码证明的是从所记录图形解释或题面模型推出的结果。它不能独立证明人工读取的源图没有错，不能替代文字论证题的审读，也未把原PDF逐字校对或整卷印刷版式检查列为已经完成。
