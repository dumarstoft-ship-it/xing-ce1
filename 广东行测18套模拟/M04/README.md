## 答案是怎么核的

- **第31—90题**：模考题库没有答案，每题由一人独立解出并写解析，数量和资料用程序核算、能枚举的枚举；判断推理和科学推理另由第二人只看题面独立再做（25题），两遍对照。换入的江浙真题用来源答案并复算。
- **第16—30题**：用国考、江浙真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”），真题每年都有而本季缺的已补上。与真题范围有出入的类别：数学运算几何2道（真题0—1）；图形推理拼合2道（真题1★）；逻辑判断加强3道（真题1—2★）；逻辑判断结构比较2道（真题3★）；资料分析比较排序2道（真题3★）。

## 与原题不同的地方

- 第45题，调序换题：第19季数学运算没有行程题（真题每年1道），工程、几何各两道：换下第45题（工程），补入2023年江苏省考A类第58题（行程）。
- 第66题，调序换题：按真题题序排为化学、力学、地理、电学、生物。
- 第52题，调序换题：第19季逻辑判断有一道真假推理（近三年真题没有），解释只有1道（真题每年2—3道）：换下第52题（真假推理），补入2022年江苏省考A类第95题（解释）。
- 第50题，调序换题：第19季第50题是截面题（近三年真题没有截面题），且切面只比第二级台阶的角低约一两个像素，印出来无法看清，答案取决于肉眼分辨不了的差别：换为2023年江苏省考A类第89题（立方体辨识，空间类）。
- 第35题，题干替换：原题圆形数阵图未入库，题库只有按位置转写的表。沿用旧M03按转写表重画的数阵图（四个圆，数字与方位不改），补写引导语。

- 第41题，改动：stem：恰好有3名应届毕业生笔试合格的概率 → 恰好有3名应届毕业生最终笔试合格的概率（补“最终”，指含补考后的结果；不补时按首次笔试理解没有对应选项）
- 第52题，改动：stem：、某企业秉持 → 某企业秉持（删去转写留下的题号后顿号）
- 第52题，改动：stem：以下哪项？如果为真，最能解释该企业今年招聘情况的变化。 → 以下哪项如果为真，最能解释该企业今年招聘情况的变化？（原卷翻印件问号错位，按通行设问改正标点，文字不变）
