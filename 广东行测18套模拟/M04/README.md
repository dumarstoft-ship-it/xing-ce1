## 卷面与选编

沿用本项目的90题结构和90分钟训练时限，不据此预测2027年实际考试题量。政治理论10题（4判断、4单选、2多选），常识应用5题，言语15题，数量15题，判断20题，科学5题，资料20题。数量保留5道数字推理与10道数学运算；判断保留5道图形与15道逻辑；资料为4个完整材料组，各5题。

保留题源本身的阅读量和推理负担，不设简单题比例，不按答案字母配平，不以题源份额反推选题。当前来源恰为国考言语10题、江浙15题、广东模考50题、依据讲义主题及直接资料命制的政治常识15题；这是选编结果，不是配额。

75道选编题都保留完整源对象。其中24题有库参考答案，51题没有库参考答案；本卷均另给编辑推导，不把编辑答案写成官方答案。15道原创题注明讲义主题页及直接依据，主题页码不替代具体事实的证据。

## 底稿与复现

`selection.json`是全卷可审阅底稿，`题目.jsonl`为只含考生内容的数据，`来源登记.jsonl`为溯源表。四个模块的合并指纹在`核验记录/assembly_manifest.json`。

```sh
python 广东行测18套模拟/M04/assemble_m04.py
python 广东行测18套模拟/M04/build_m04.py
python 广东行测18套模拟/M04/核验记录/verify_m04.py
```

先修改对应模块生成器及必要核验，再更新模块、合并、构建；避免只改成品文字后被下一次构建覆盖。旧卷、旧审核及原题库均保持不变。M04在共用登记中仅表示待审预留，不表示用户已做。

后续按既有流程由Claude独立审核，GPT处理具体意见后更新版本和PDF。审核应围绕题面、答案唯一性、推导与整卷价值，可以质疑本次任何选编判断，不以内部“同键”替代审阅。
