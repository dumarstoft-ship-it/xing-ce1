# 广东行测18套模拟｜协作入口

本目录是新的整卷项目，与`广东行测24天集训/`旧专项分开。原始题库不移动、不覆盖。

## 共同目标

用用户指定的陌生题源组成18次有真实取舍压力的模拟，训练识别、跳过、继续推进和回收难题。不是凑18套题，也不是堆砌最难题。

广东近五年真题用于校准题型、设问、结构和纸面体验，不用于把自然偏难的题源降回广东原卷难度。**不人为设置简单题保底比例，不为配难易比例塞水题。** 同时比较单题价值和它在整卷中的作用。

题库上传不等于每题已核验，也不意味着用户已做过。已交付、已做和已用于本项目是不同状态。

## 分工与数据约定

GPT选编并核验；Claude独立审核；GPT处理意见后定稿；Claude参考广东原卷制作打印版。各接手者可直接看源卷和成品，不把上一模型的理解当唯一标准。

一套为一个工作单元，不承诺无人触发时后台推进。题本不显示难度、建议跳题位置或来源，编辑判断后置。审核前不称定稿，缺题不计为完整卷。

[用题登记](用题登记.jsonl)中的`reserved_for_review`表示待审预留，不表示定稿采用或用户已做。本次科学题记录与原85题一起登记。现有72组资料材料恰好对应18套需求；后续如淘汰整组，需要补源或明确改编。
