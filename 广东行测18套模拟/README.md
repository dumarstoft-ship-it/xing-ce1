# 广东行测18套模拟｜协作入口

本目录是新的整卷项目，与 `广东行测24天集训/` 的旧专项任务分开。原始题库不移动、不覆盖。

## 共同目标

用用户指定的陌生题源组成18次有真实取舍压力的模拟，训练识别、跳过、继续推进和回收难题。不是凑18套题，也不是堆砌最难题。

广东近五年真题用于校准题型、设问、结构和纸面体验，不用于把自然偏难的题源降回广东原卷难度。**不人为设置简单题保底比例，不为配难易比例塞水题。** 同时比较单题价值和它在整卷中的作用。

题源范围由用户确定。题库上传不等于其中每题已经核验，也不意味着用户已做过。已交付、已做和已用于本项目是不同状态，不混记。

## 分工

GPT选编并核验；Claude独立审核；GPT处理意见后定稿；Claude参考广东原卷制作打印版。每个接手者都能直接看广东原卷和当前成品，不必把上一位模型的理解当成唯一标准。

先以一套为基本工作单元；不承诺无人触发时后台推进。题本不显示难度标签、建议跳题位置或来源，题源与编辑判断放在答案及编者记录。审核前不称定稿，缺题不冒算成完整卷。
