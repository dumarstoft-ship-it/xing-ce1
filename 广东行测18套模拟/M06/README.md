## 答案是怎么核的

- **第31—90题**：模考题库没有答案，每题由一人独立解出并写解析，数量和资料用程序核算、能枚举的枚举；判断推理和科学推理另由第二人只看题面独立再做（25题），两遍对照。换入的江浙真题用来源答案并复算。换入题、改写的资料题和编辑新写的题另由第二人只看题面盲做（8题），全部一致。
- **第16—30题**：用国考、江浙真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”），真题每年都有而本季缺的已补上。与真题范围有出入的类别：数学运算和差倍比方程4道（真题2—3★）；图形推理拼合2道（真题1★）；逻辑判断结构比较2道（真题3★）；资料分析比较排序2道（真题3★）；资料分析基期量2道（真题0—1）；资料分析平均数2道（真题0—1）。

## 与原题不同的地方

- 第71题，资料组调序：真题第1组是广东材料、纯文字材料都在前两组、第4组是“文字＋统计图”：第21季原第2组（广东“十四五”教育，纯文字）挪到第1组，原第1组（S市保险，文字＋月度统计图）挪到第2组；原第3组（监管货运，表格）和第4组（纸浆，文字＋统计图）不动。
- 第32题，调序换题：第21季数字推理没有递推和分数数列（真题每年至少1道递推、1道分数数列），作差、相邻项求和一类却有三道：换下第32题（作差得质数列）和第35题（作差后作商），补入2020年江苏省考A类第48题（递推）和第50题（分数数列）。
- 第37题，调序换题：第21季数学运算没有行程题（真题每年1道），工程有两道（真题每年1道）：换下第37题（工程，工作量与效率的比例；转写还把分数1/6错放到了句首），补入2021年江苏省考A类第54题（行程）。
- 第60题，调序换题：第21季逻辑判断第60题是真假推理（四人预测、至多两人说错，近三年真题没有），分析推理只有1道（真题每年2—3道）：换下第60题，补入2025年浙江省考A类第102题（分析推理，分组与数量匹配）。
- 第61题，调序换题：第21季第61题是对话型结构比较（比较两段对话的逻辑），近三年真题的结构比较都是比较推理形式或论证结构，没有对话型：换为第24季第58题（推理形式型）。第24季有三道结构比较，借出后还有两道。
- 第66题，调序换题：第21季科学推理没有电学题（真题每年1道），力学有两道：换下第66题（平抛，题图两条轨迹是示意弧线），补入编辑新写的电学题；按真题题序排为化学、力学、地理、电学、生物。
- 第87题，调序换题：真题第89题三年都是比较排序：第4组改写后的排序题（原第87题）与原第89题（年均增长量）对调位置。
- 第35题，改动：stem：32/7，4，128/25，128/17，512/43 → $\frac{32}{7}$，4，$\frac{128}{25}$，$\frac{128}{17}$，$\frac{512}{43}$（题库把分式转写成“a/b”，按原卷排成上下式分数，数值不变）

- 第35题，改动：C：512/19 → $\frac{512}{19}$（同上）
