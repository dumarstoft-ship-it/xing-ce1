## 数据与重新生成

- [selection.json](selection.json)：当前选编底稿，保存题目选择、原始源对象、编辑答案、解析、改动及核验。**含答案，不用于考生端。**
- [paper.json](paper.json)：版本、目标题量、缺题编号、模块数量和源库快照。
- [题目.jsonl](题目.jsonl)：规范化题面，**不含答案字段**；用于后续打印或展示。图片路径相对于仓库根目录。
- [来源登记.jsonl](来源登记.jsonl)：题号与稳定源ID映射、源文件哈希、原卷定位、编辑判断及答案来源。
- [跨卷用题登记](../用题登记.jsonl)：本稿预留记录，不等于定稿采用或用户已做。

在仓库根目录运行：

```bash
python3 广东行测18套模拟/M01/build_m01.py
```

只需Python标准库。脚本从`selection.json`与`paper.json`重新生成题本、答案、题面数据、来源登记、选题记录、用题登记和结构报告；不修改原题库。修改题面、答案或选择时先更新底稿，再重新生成，避免只改成品而在下次构建时丢失。
