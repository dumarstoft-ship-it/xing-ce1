## 答案是怎么核的

- **第31—90题**：模考题库没有答案，每题由一人独立解出并写解析，数量和资料用程序核算、能枚举的枚举；判断推理和科学推理另由第二人只看题面独立再做（25题），两遍对照。换入的江浙真题用来源答案并复算。
- **第16—30题**：用国考、江浙真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”），真题每年都有而本季缺的已补上。与真题范围有出入的类别：图形推理拼合2道（真题1★）；逻辑判断加强3道（真题1—2★）；逻辑判断结构比较2道（真题3★）；资料分析比较排序2道（真题3★）；资料分析比重1道（真题2—5★）；资料分析基期量3道（真题0—1）；资料分析平均数2道（真题0—1）。

## 与原题不同的地方

- 第71题，资料组调序：真题纯文字材料都在前两组、广东材料在第1组；第16季的广东纯文字材料原在第3组，挪到第1组，其余三组顺次后移，第4组（统计图）不动。
- 第39题，调序换题：第16季数学运算有两道工程题、没有最值与构造题（真题每年工程1道、最值1道）：换下第39题（工程），补入2025年浙江省考A类第63题（和定最值）；排列组合两题按真题题位放到第41—42题。
- 第66题，调序换题：第16季科学推理没有力学题、有一道热学题（真题每年力学1—2道、近三年无热学）：换下第66题（热学），换入第18季第67题（力学，流体压强；第18季有两道力学）。按真题题序排为化学、力学、地理、电学、生物。
- 第89题，改写设问：第16季资料分析有4道基期量（真题每年0—1道）、只有1道比较排序（真题每年3道，且第89题三年都是比较排序）。第89题原问2022年9月国内销量（基期量），改为同一图中2024年5—8月同比增量的排序，难度相当（要算4个增量，增速最高的月份增量不是最多）。

资料分析中原卷的统计图没有入库，只有转写的数据，打印版按数据重画（图形样式为推定，数值与转写一致），见编排说明。
