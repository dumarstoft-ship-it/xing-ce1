## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；判断推理和科学推理另由第二人只看题面独立再做（25题），三方对照。换入的题另由第二人只看题面盲做（8题），与来源答案一致。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。
- 原第57题（花椒价格）、第58题（课堂学习与大脑活动）、第63题（全球变暖与害虫）解题人和第二人各自盲解都与来源答案不同；原第69题（色散）题图把折射光画成偏离法线。这四题都换掉并列入“题目有问题”。第56题（与第55题相邻的反向设问）、第61题（与前一天S06第61题同模板）也换了。换入的第57题先是火星咸水含氧（与前一天S07第58题情境相同），再换成江苏卷的加强题；第59题换入的江苏题与前一天M15第51题同模板，又换一次。理由都见“与原题不同的地方”。换入的题解题人和第二人盲做都与来源答案一致。
- 第51题（交通巨变，“一定错误”）两人都选D，与来源一致；按题干陈述为真的出题惯例作答，解析写明。第80题A项“播种面积增长主要是因为粮食和蔬菜增加”推不出：材料列出的五类作物合计反而减少约20.5万亩，增长来自未列出的作物，两人都选D，与来源一致，解析写明。

## 难度

- 资料分析：读一眼就能判断5道、一步4道、两步5道、三步及以上6道（多步11道）；熟练考生连扫读材料约15.8分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步7道（两步6、三步及以上1），熟练考生约7.1分钟；近三年真题多步6—7道。
- 本套按用户要求适当偏难。数学多步7道（两步6、三步1，约7.1分钟），第40、43题是江苏卷题；数推第33题（江苏，来源标全站正确率29%）、第35题也取自江苏卷。本套资料的解题人计步和估秒偏宽，与M14、M15同一评法（多步11道、三步6道，约15.8分钟）；按题池的统一评法，本套资料多步8道。
- 图推按解题人评级难2中3，科推中4易1。逻辑解题人评易9中6，没有评为难的：答案可商榷的三道换掉后，换入的题都不难；广东剩下的逻辑难题多是答案可能有争议的结构比较，江苏卷补了两题（第57、59题）。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。按考场时段计时90分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：数学运算最值与构造0道（真题1★）；逻辑判断分析推理1道（真题2—3★）；逻辑判断真假推理1道（真题0）；逻辑判断解释1道（真题2—3★）；逻辑判断归纳结论1道（真题0）；科学推理电学0道（真题1★）；科学推理地理0道（真题1★）；科学推理光热声及其他1道（真题0）；资料分析比较排序6道（真题3★）；资料分析比重1道（真题2—5★）；资料分析现期量与简单计算0道（真题1—2★）；资料分析材料理解0道（真题2—5★）；资料分析基期量2道（真题0—1）；资料分析资料分析／计数2道（真题—）。
