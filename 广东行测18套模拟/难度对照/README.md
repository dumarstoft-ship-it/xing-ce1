# 资料分析、数学运算难度对照（2026-11-19）

**起因**：用户做M01、M02时觉得数资比广东真题难很多，资料分析尤其绕：难题多几道，整张卷的时间和作答顺序都被打乱。此前Claude只比过字数、各类题的题数和解题人标的难易，没有逐题比过难度。这次补做了逐题对比。

## 做法

- 三人按同一标准（[rubric.md](rubric.md)）逐题评GD2024—2026真题和M01—M08模拟卷的第36—45题（数学运算）、第71—90题（资料分析）。评的项目有：
  - 作答方式：读、一步、两步、三步及以上；
  - 选项要求的精度；
  - 口径坑；
  - 熟练考生走最快路径的秒数；
  - 资料另评每组材料的扫读秒数。
- 尺度对齐：三人都评了GD2025第36—40、71—80题作锚点。
  - 锚点合计分别为630、635、625秒，步数判断几乎一致。
  - 秒数按锚点换算到真题评分人的尺度，见 [aggregate.py](aggregate.py)、[summary.json](summary.json)。
- 两处不能直接横比：
  - M05—M08评分人判“三步及以上”的门槛偏低：他标的三步题平均64秒，另两人是71、75秒。所以下表把两步和三步合计为“多步”。
  - 口径坑三人数法不同：有人只算验到的选项，有人四个选项全算。这一项不作横向比较。
- 秒数是熟练考生的估计，普通考生做多步题会慢得多，见下文“折算”。

真题平均：资料16.1分钟（含扫读材料），数学运算8.5分钟。

- **资料分析**：
  - 真题20题里多步题每年5—8道，读一眼或算一步的有12—15道。
  - 模拟卷多步题10—14道，约为真题的两倍；读一眼或算一步的只有6—10道。
  - 真题的综合分析大多一步就能定。
  - 模拟卷常要拆口径或连算两三次，例如：
    - M02第84题，先算两个平均数再作差；
    - M02第87题，补全12月再求增速；
    - M02第88题，四年单价增速逐个推。
- **数学运算**：
  - 多步题模拟卷7—10道，真题6—7道。
  - 按熟练考生秒数，M03比真题平均多约4分钟，其余在两三分钟以内。
- **整套**：熟练考生在模拟卷的数资上多用0—7分钟。
  - 多出的几乎都来自多步题。
  - 普通考生做多步题，耗时比熟练考生涨得更多，正好是用户说的“难题比例上升一点，整卷难度上升很多”。

## 折算成模考时长（建议）

- 普通考生按做多步题比熟练考生慢一倍折算：这是估计，不是实测。
- 再加上模拟卷言语、逻辑比2026年真题多出的阅读量：按每分钟500字折算，约1—2.5分钟。
- 两项合计四舍五入到5分钟，得到建议时长：

| 卷 | 建议时长 |
| --- | --- |
| M01 | 100分钟 |
| M02 | 95分钟 |
| M03 | 105分钟 |
| M04 | 100分钟 |
| M05 | 105分钟 |
| M06 | 95分钟 |
| M07 | 100分钟 |
| M08 | 100分钟 |

用法：
- 顺序和各部分截止时间照真考的安排。
- 到建议时长时换一支颜色的笔继续做完，记下做完的钟点。
- 下一套的加时按实际情况调。

## M03与粉笔第28季对比（2026-11-20）

用户问M03和粉笔广东模考卷哪个难、难多少。随机抽了第18—23季以外的第28季（M03第31—90题除3题外都取自粉笔第18季），同一块由同一人评两卷，卷与卷直接可比。数推、图推、科推这块用户说不用再比，没有评完。

| 部分 | M03 | 第28季 | 真题参照 |
| --- | --- | --- | --- |
| 资料分析（熟练考生，含扫读） | 17.5分钟；读2、一步7、两步5、三步及以上6 | 15.6分钟；读2、一步8、两步8、三步及以上2 | 2024—2026年平均16.1分钟 |
| 数学运算 | 11.2分钟；两步5、三步及以上5，没有一步题 | 9.4分钟；一步3、两步4、三步及以上3 | 平均8.5分钟 |
| 逻辑判断 | 14.8分钟，4493字，难题1道 | 15.3分钟，4474字，难题3道（其中2道答案本身说不清） | 2025、2026年平均13.2分钟、3357字 |

- 数资：M03比第28季多约3.7分钟，资料、数学各占一半；第28季的数资和真题差不多（多0.4分钟），M03比真题多约4分钟。秒数已按GD2025锚点换算到真题评分人的尺度（系数1.068），见 [M03-S28_数资.json](M03-S28_数资.json)。
- 逻辑：两卷差不多，第28季多约半分钟；两卷字数都是真题的1.33倍，多出的1.5—2分钟几乎都在读题，思考时间与真题相当，见 [逻辑_M03-S28.json](逻辑_M03-S28.json)。
- 合计：熟练考生做M03比做第28季多约3分钟，主要差在数学运算和资料分析的多步题。上表M03的数资与本文前面三人评的数（资料19.3、数学12.4分钟）不同，是评分人松紧不同；同一人评的两卷之间的差才可比。
