## 答案是怎么核的

- **第31—90题**：模考题库没有答案，每题由一人独立解出并写解析，数量和资料用程序核算、能枚举的枚举；判断推理和科学推理另由第二人只看题面独立再做（26题），两遍对照。换入的江浙真题用来源答案并复算。
- **第16—30题**：用国考、江浙真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”），真题每年都有而本季缺的已补上。与真题范围有出入的类别：数学运算经济利润2道（真题0—1）；逻辑判断翻译推理3道（真题0—2）；逻辑判断分析推理1道（真题2—3★）。

## 与原题不同的地方

- 第36题，调序换题：第17季数学运算没有最值与构造题、行程和经济利润各两道（真题每年最值1道、行程1道）：换下第42题（行程），补入2023年江苏省考A类第64题（和定最值）；排列组合题按真题题位放到第41题。
- 第66题，调序换题：第17季科学推理没有力学题、有一道热学题（真题每年力学1—2道、近三年无热学）：换下第66题（热学），换入第28季第67题（力学，摩擦力方向；第28季有两道力学）。按真题题序排为化学、力学、地理、电学、生物。
- 第56题，调序换题：第17季逻辑判断形式逻辑有5道（翻译3、真假1、分析1，真题合计3—4道、近三年无真假推理），削弱3道，解释和结构比较偏少：换下第56题（真假推理）补入2023年江苏省考A类第96题（解释），换下第58题（削弱）补入2021年江苏省考A类第92题（结构比较，比较推理形式）。
- 第69题，改动：stem：均为电压表。闭合开关S后 → 均为电压表，各电表均为理想电表。闭合开关S后（原题未说明电表是否理想，补上初中电学题的通常条件，答案不变）
- 第74题，改写设问：第17季资料分析没有增长量题（真题每年1—3道），且有两道“有几个”式计数设问（真题三年只出过1道）。第74题原问上海增速超过10%的年份个数，改为同一表中广东省的年均增长量，难度相当（要定准基期与间隔年数）。
