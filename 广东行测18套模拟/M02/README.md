## 结构与选择

1—10政治理论（4判断、4单选、2多选），11—15常识应用，16—30言语，31—45数量（5数字推理、10数学运算），46—65判断（5图形、15逻辑），66—70科学推理，71—90资料分析（4完整材料组）。此结构沿用当前项目配置，不是对未来考试题量的保证。

本卷保留先前选定的75题题源与答案，补入15道依讲义主题原创的政治常识题。政治部分另核对五中全会公报、2026年广东两业协同等正式资料，逐题保留依据。

与M01相比，本卷选入折纸剪裁与正方体展开图、往返相遇题、广东主题纯文字资料，以及饼图选项和增速折线判读。目的是丰富整卷取舍与信息处理，而不是机械凑小类配额或降低题源难度。没有对不确定的用户做题史作推断。

第38、43、56、67、68题明确原题隐含条件；第71、72题在保留完整材料的基础上改写设问。原始源对象保持不动，编辑覆盖另存。其余排版处理记录于格式日志。

## 数据和构建

`selection.json`为完整整卷编辑底稿，`题目.jsonl`为不含答案的考生数据，`来源登记.jsonl`记录溯源，项目上一级`用题登记.jsonl`保存跨卷预留。预留不等于定稿或用户已做。

```bash
python3 广东行测18套模拟/M02/build_m02.py
```

常规构建只需Python标准库。首次组装脚本`assemble_m02.py`在已有selection.json时不会重置它；后续审核应修改selection.json再构建。编辑底稿和两个断点保留作历史，不可据旧断点覆盖已审核内容。

数值核验只需标准库；图形核验另需NumPy、Pillow和SciPy。两者都不修改原题库。打印待审核后使用项目既有打印工具与原指定字体，答题卡仍由用户自行购买。
