## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；判断推理和科学推理另由第二人只看题面独立再做（25题），三方对照。换入的题另由第二人只看题面盲做（5题），与来源答案一致。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。
- 原第51题（面试条件）答案与来源一致，但解题人和第二人都指出由“进入面试”推出满足条件是肯定后件，严格说四项都推不出；原第56题（医疗用品集中采购）、第62题（汞中毒）、第63题（古典经济学）解题人和第二人各自盲解都与来源答案不同。这四题都换掉并列入“题目有问题”；第56题换入的第一道（公共交通支出与空气质量）第二人盲做又与来源不同，也列入“题目有问题”，再换一次。

## 难度

- 资料分析：读一眼就能判断2道、一步6道、两步7道、三步及以上5道（多步12道）；熟练考生连扫读材料约15.8分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步7道（两步5、三步及以上2），熟练考生约8.0分钟；近三年真题多步6—7道。
- 本套是考前最后一套（12月5日），资料比M17稍轻：解题人评多步12道、三步5道，约15.8分钟（与M14—M17同一评法）；按题池的统一评法，本套资料多步10道、约11.3分钟（M17为9道、约12.8分钟），估时仍比M17短。
- 数推按解题人评级难1中1易3，图推难3中2，科推中2易3（广东科推已用完，第69、70题由编辑新写）。逻辑解题人评中6易9，没有难题：广东剩下的逻辑题都不难，江苏卷共用了6道（第54、57、58、61、63、64题），答案可商榷的四道换掉后换入的题也不难。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。按考场时段计时90分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：数学运算工程2道（真题1★）；逻辑判断分析推理1道（真题2—3★）；逻辑判断真假推理1道（真题0）；逻辑判断解释1道（真题2—3★）；逻辑判断结构比较2道（真题3★）；逻辑判断归纳结论1道（真题0）；科学推理力学3道（真题1—2★）；科学推理电学0道（真题1★）；科学推理生物0道（真题1★）；科学推理地理0道（真题1★）；科学推理光热声及其他1道（真题0）；资料分析比较排序2道（真题3★）；资料分析材料理解0道（真题2—5★）；资料分析平均数2道（真题0—1）；资料分析图形选项2道（真题0—1）；资料分析资料分析／计数2道（真题—）。
