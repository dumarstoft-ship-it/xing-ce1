## 答案是怎么核的

- **第31—90题**：模考题库没有答案，每题由一人独立解出并写解析，数量和资料用程序核算、能枚举的枚举；判断推理和科学推理另由第二人只看题面独立再做（25题），两遍对照。换入的江浙真题用来源答案并复算。换入题、改写的资料题和编辑新写的题另由第二人只看题面盲做（10题），全部一致。
- **第16—30题**：用国考、江浙真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，15题中14题一致；第22题盲做选B、来源答案A，文段先用“然而”提出AI仿声的侵权风险，再以“民法典规定……所以……”说明声音受保护的条件和构成侵权的情形，重点在“所以”之后的法律规定，维持来源答案A；解析的易错写明B只是文段提出的问题。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”），真题每年都有而本季缺的已补上。与真题范围有出入的类别：数学运算和差倍比方程1道（真题2—3★）；数学运算经济利润2道（真题0—1）；逻辑判断结构比较2道（真题3★）；资料分析平均数2道（真题0—1）。
