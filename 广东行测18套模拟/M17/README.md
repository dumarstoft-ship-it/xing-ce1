## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；判断推理和科学推理另由第二人只看题面独立再做（25题），三方对照。换入的题另由第二人只看题面盲做（1题），与来源答案一致。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。
- 原第64题（江苏2024年卷，对话方式）解题人和第二人各自盲解都与来源答案不同，换掉并列入“题目有问题”；第38题为补上真题每年都考的最值与构造题换掉（原第38、43题同为行程）。理由都见“与原题不同的地方”。换入的两题解题人盲做都与来源答案一致，第64题另由第二人盲做，也一致。
- 第56题（削弱）解题人盲解选C，第二人盲做选A、与来源答案一致，保留，解析写明C为什么不对。第43题（钟表）精确用时为720/13≈55.4分钟，B项“55分钟”是近似值，其余选项相差都在5分钟以上；第39题的效率之比要代入选项验证，来源解析也是代入。资料第71—75题表中没有单列零售业，要用“批发和零售业”减“批发业”求得，解析写明。
- 第70题（两只白炽灯串联）由编辑新写（广东剩下的科推不够用），解题人和第二人盲做都选A，与编辑答案一致。第46、47题原卷没印题干，补上通行的题干；第63题C项“因此。教育”的句号改为逗号、D项“戒骄成躁”改为“戒骄戒躁”；第87题题干的半角逗号改为全角，第86—90题资料里的“．同比增长”改为逗号、段末补句号。
- 数推第33、35题，数学第38、39、40、42题，逻辑第54、57、64题取自江苏省考A类卷，来源答案行与解析正文都一致；图推第50题取自2025年广东事业单位统考题。
- 言语15题选题人自做和第二人盲做都与来源答案一致。政治常识10题两步盲做与答案一致；第8题（宪法与法治）用的是M15留下的讲义材料，第13题是科技三会讲话第三次出题（前两次是M02第12题、M05第13题），三题的选项各不相同。

## 难度

- 资料分析：读一眼就能判断1道、一步3道、两步8道、三步及以上8道（多步16道）；熟练考生连扫读材料约18.8分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步6道（两步6、三步及以上0），熟练考生约6.8分钟；近三年真题多步6—7道。
- 本套按用户要求适当偏难，是18套里资料最重的一套：S07原定的地铁运营一组（第81—85题）对加量套太重，与M17对调，留考前一天的M18稍轻。资料的解题人计步和估秒偏宽，与M14—M16同一评法（多步16道、三步8道，约18.8分钟）；按题池的统一评法，本套资料多步9道、约12.8分钟。
- 数推按解题人评级难1中1易3，图推难2中2易1，科推难1中4（广东剩下的科推多是力学，本套5道都是物理，第70题电学由编辑新写）。逻辑解题人评难1中8易6，难题是第53题（旧卷分析推理）；广东的加强、结构比较题已用完，江苏卷补了3道（第54、57、64题）。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。按考场时段计时90分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：逻辑判断翻译推理3道（真题0—2）；逻辑判断解释1道（真题2—3★）；科学推理力学3道（真题1—2★）；科学推理生物0道（真题1★）；科学推理地理0道（真题1★）；科学推理光热声及其他1道（真题0）；资料分析比较排序6道（真题3★）；资料分析增长量0道（真题1—3★）；资料分析材料理解0道（真题2—5★）；资料分析资料分析／计数2道（真题—）。
