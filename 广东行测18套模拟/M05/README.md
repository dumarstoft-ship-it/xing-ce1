## 答案是怎么核的

- **第31—90题**：模考题库没有答案，每题由一人独立解出并写解析，数量和资料用程序核算、能枚举的枚举；判断推理和科学推理另由第二人只看题面独立再做（25题），两遍对照。换入的江浙真题用来源答案并复算。
- **第16—30题**：用国考、江浙真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”），真题每年都有而本季缺的已补上。与真题范围有出入的类别：逻辑判断结构比较2道（真题3★）；资料分析比较排序2道（真题3★）；资料分析平均数2道（真题0—1）；资料分析图形选项2道（真题0—1）。

## 与原题不同的地方

- 第34题，调序换题：第20季数字推理没有递推数列（真题每年至少1道），多重数列有两道：换下第34题，补入2022年浙江省考A类第54题（递推）。
- 第38题，调序换题：第20季数学运算没有行程题和最值题（真题每年各1道），有一道浓度题（近三年无）、两道经济利润题：换下第42题（浓度）补入2020年江苏省考A类第58题（相遇行程），换下第38题（经济利润）补入2024年江苏省考A类第55题（不定方程求最值）；排列组合两题按真题题位放到第41—42题。
- 第66题，调序换题：按真题题序排为化学、力学、地理、电学、生物。
- 第60题，调序换题：第20季逻辑判断有一道真假推理（近三年真题没有），分析推理只有1道（真题每年2—3道）：换下第60题（真假推理），补入2022年江苏省考A类第97题（分析推理）。
- 第42题，改动：stem：分别为50%、60%、70%。 → 分别为50%、60%、70%，且各类项目能否夺冠互不影响。（原题未说明三类项目结果相互独立，概率无法唯一确定；补上同类题的通常条件，答案不变）
