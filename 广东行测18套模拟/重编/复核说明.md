# 第二人盲解复核说明

## 目的

模考题库没有答案。第一遍解题已经给出答案和解析；这一步由另一个人只看题面独立作答，看两遍是否一致。不一致的题要找出谁错、错在哪，或者题目本身有两可之处。

## 做法

1. 只看 `输入/fig_logic.json` 与 `输入/quant_sci.json` 中指定题号的题（题号在任务里给出）。题图是PNG，用Read工具看，必要时用Python（Pillow）放大局部。
2. 不要打开 `解题/` 目录、`输入/prior.json` 和旧卷文件。
3. 每题独立作答，写清理由；分析推理题写枚举脚本验证；图形推理逐一检查四个选项。
4. 结果写到 `复核/second.json`：

```json
[{"id": "gd-mock-2026h2-s16-q46", "number": 46, "answer": "B", "confidence": "high",
  "reason": "规律与排除理由，几句话", "doubt": "题目本身可疑之处，没有就空"}]
```

脚本放 `复核/scripts/`。只写 `复核/` 目录，不改其他文件。完成后回复：每题答案一行，以及你认为题目本身有问题的题。
