# 重编（2026-11-16）

## 为什么重编

用户要求各套的题型与近年广东卷基本一致；五套都还没做，用户让Claude把五套都改了，题库里的题都交给Claude编排，并说明广东模考卷是机构按广东题型出的。旧五套由GPT逐题从各题库挑选，整卷的题型与真题有系统偏差，见 [题型对照](../题型对照/)。

这里记下这次是怎么编的、为什么这样编，供以后接着编的人参考。这些是做法和理由，不是规则；遇到新情况按目的判断。

## 怎么编的

- **第31—90题一季一卷**：整段采用粉笔2026下半年广东省考模考的一季原题。机构按广东卷结构出整卷，整段采用，题型、题位和难度搭配就大体像真题；18季正好对18套，各套之间也不会互相挤占。M01—M18依次对第16—33季。
- **补缺，不凑数**：与2024—2026年真题对照（[题型参照](../题型参照_2024-2026.md)）。本季缺真题每年都有的题型，或某类明显偏多时才换题；差一两道的保留（用户原话“一两道之差无妨”）。补换题的来源依次是：
  - 江浙真题（有来源答案；旧五套用过、审核过的优先）；
  - 别季多出来的同类题（只借有两道以上的，借出后对方仍有）；
  - 编辑新写（题库缺这类题又没有富余时，如M03的电学题）。
- **资料题不动材料**：某套缺比较排序、增长量这类每年都有的考点时，改写同组一题的设问，难度不低于原题；资料组按真题的位置调序（纯文字在前两组、广东材料在第1组、统计图组在第4组）。
- **原图没入库的就重画**：资料统计图按转写数据重画成柱状、折线、柱线、饼图（样式为推定，数值与转写一致）；数阵、分区图按转写重画。每处都记在各套的编排说明里。
- **原题缺条件、有排印错误的才改**：如补“各项目结果互不影响”“电表均为理想电表”，改正翻印件的错位标点；言语、逻辑的文字不改。
- **言语**：按真题题位（16—20逻辑填空、单空多空混排，21主旨，末题6句排序等）从国考、江浙真题中选，见 [言语/选题说明.md](言语/选题说明.md)。
- **政治常识**：依据用户的《颜培天2027广东省考政治理论常识》讲义（含二十届五中全会《决定》）新写，照2025、2026年真题的问法，每题正确项和错项都有讲义原句依据，见 [政治常识/出题说明.md](政治常识/出题说明.md)。

## 答案怎么核的

- 模考题库没有答案。第31—90题每题先由一人盲解（写完答案才看旧卷用过的答案），数量、资料用程序核算，能枚举的都枚举；图形推理用程序读图、穷举拼合、折叠展开图。判断推理和科推再由第二人只看题面独立做一遍，两遍对照（`tools/compare_second.py`）。
- 言语用来源答案，选题时自己先做；新选的题另由一人盲做。
- 政治常识另由一人先凭知识盲做、再对照讲义和公开原文核查。
- 改写的资料题、补入的江浙题用程序复算。
