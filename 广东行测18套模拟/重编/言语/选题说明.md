# 言语选题说明（M01—M05，第16—30题）

## 目的

五套模拟卷的言语部分要像近年广东卷：题型的多少和位置大体与2024—2026年真题一致，题目本身是好的真题，用户没做过。考生用它练真实的题型感觉和时间分配。

## 题源

`pool.json`：国考言语（2016—2025）和江浙言语真题，共964条，每条有：

- `subtype`：按设问关键词粗分的题型，可能分错，以读题为准；`?` 多是国考篇章阅读或设问特殊的题。
- `exposed_old_drill`：在用户以前的24天集训、习题本里出现过，不能用。
- `withdrawn_reason`：以前因为题目问题撤下，不能用。
- `used_in_old`：现在五套旧卷里用到的位置。用户五套都还没做，这些题可以重新安排；它们审核过，合适的优先留用。每题在五套里只能用一次。
- `answer`、`answer_status`：来源答案；没有答案或答案有争议的不用。

真题样子看 `/home/user/xing-ce1/广东/行测/2022-2026/GD2024.jsonl`、`GD2025.jsonl`、`GD2026.jsonl` 的第16—30题。

## 怎样挑

- 先看题本身好不好：文段完整、设问清楚、答案唯一、干扰项有迷惑性。自己先不看答案做一遍，与来源答案不一致的，查清楚；查不清就不用。
- 同一套里文段话题不要重复（比如两道都讲文物保护）。
- 难度不要都挑容易的；广东卷是标准，不是上限。
- 国考与江浙都可以用，不必配比例。
- 江浙题的转写有两个已知问题：
  - 题干里有PDF行末硬换行（排版时会合并，不用管）；
  - 2020、2022年江苏卷部分多空题的选项丢了词间空格，像“如雷贯耳刀光剑影客观性”。用到这样的题，在 `option_spaces` 里写出恢复空格后的四个选项（按词的边界分开，字一个不改），我会对照原卷核实。
- 国考题没有解析，要自己写；江浙题有来源解析，可以参考改写，去掉“【文段出处】”和硬换行；旧卷留用的题可以参考旧卷 `selection.json` 里的解析，同样只留给考生看的内容。

## 交什么

写 `/home/user/xing-ce1/广东行测18套模拟/重编/言语/selection.json`：

```json
{
  "M01": [
    {"number": 16, "id": "GKYY-2023-012", "subtype": "逻辑填空-单空", "blanks": 1,
     "answer": "C", "my_answer": "C", "analysis": "给考生看的解析",
     "option_spaces": null, "why": "一句话说为什么选它", "concern": ""}
  ],
  "M02": []
}
```

- `my_answer`：你自己做出的答案。与`answer`不同的题不要选。
- `analysis`：给考生看，点明题型和关键信息，说清正确项为什么对、主要干扰项错在哪。不写“原题”“题库”“旧卷”等编辑用语。
- `concern`：拿不准的地方，没有就空着。

再写一个 `selection_notes.txt`，列出每套各类题的数量、逻辑填空的总空数，以及你放弃不用的旧卷言语题和原因（只写有实质问题的）。只写这两个文件，不改其他文件。
