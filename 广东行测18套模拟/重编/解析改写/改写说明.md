# 解析改写说明：讲清“球在哪”

## 为什么改

用户的说法：公考是抛球接球，不是数学考试。命题人会在题面上留提示（球），考生要学会看见它、接住它。好题的错误选项，就是接漏了某个球的人会选的答案。

现在的解析大多只讲怎么算、怎么推。这次改写，让每题解析告诉考生三件事：

1. 题面上哪个信号告诉你该怎么做（题眼）；
2. 顺着这个信号怎么做出来；
3. 哪个错误选项是漏接了哪个球的结果（易错）。

## 格式

每题解析三段，每段另起一行：

```
题眼：一句话，指出本题题面上具体的提示，以及它指向的做法。
（推导：保留原解析中正确的计算或推理，可以精简、可以理顺，结论和数字不变。）
易错：误以为……会选X；只看……会选Y。（没有典型陷阱的题可以省略这一段。）
```

## 写法要点

- **题眼要具体到本题**。写“题干问‘至少’，且四个选项相差1，提示要构造最不利的情况”，不写“本题考查最值问题，需要认真分析”。考生读了题眼，下次遇到同类信号能想到同样的做法，才算写好。
- **易错要对应真实的错误**。写清楚“按什么错误思路会得到哪个选项”，最好算出来。四个选项看不出对应哪种错误的，就不硬写。
- **不改答案，不改推导的结论**。原解析里正确的计算、数值、依据都保留。如果发现答案或题目本身有问题，不要改解析去迁就，写在 note 字段里。
- **篇幅**：与原解析相当，最多长一半。题眼一句，易错一两句。
- **给考生看**：不写“原题”“题库”“转写”“复核”“讲义”等编辑用语，不提出题过程。

## 各模块的球，常见在哪里

这些是常见的位置，供参考，不是清单。以本题实际的提示为准。

- **政治常识**：题干里的限定词和原文关键词（“根本”“首要”“核心”“必须坚持”）；错误选项通常换掉了原文中的一个关键词，或把两个相近的表述对调。
- **言语**：逻辑填空看语境里的提示词（转折、并列、递进、解释说明），以及空格前后能对应的词；主旨看转折之后、结论句、反复出现的话题词；语句填空看前后句的衔接；排序看首句特征、指代词和关联词形成的捆绑。
- **数量**：数字特征（倍数、整除、奇偶、比例关系），问法（“至少”“最多”提示构造或最不利情况，“恰好”提示枚举），选项特征（选项间差距、尾数、是否同为某数的倍数）。
- **图形推理**：图形的共同特征（直线曲线、开闭、面数、笔画、对称、黑白块）；选项之间的差别往往指向规律所在。空间题看相对面、公共边、特殊面的方位。
- **逻辑**：设问指向的题型（削弱、加强、前提、解释）；论点和论据之间的落差（前提和加强常要“搭桥”）；条件词（如果、只有、除非）。
- **科学推理**：题干里的关键物理量或现象词，以及“理想”“匀速”“静止”这类条件。
- **资料分析**：设问的时间和口径（现期、基期、同比、环比、增量、增速、比重）；选项之间的差距，它决定要算到多精；材料中对应数据的位置。

## 交付

写 `out_<模块>.json`：一个列表，每题一项：

```json
{"paper": "M01", "number": 31, "analysis": "题眼：……\n……\n易错：……", "note": ""}
```

note 只写给编辑看的话（答案或题目的疑问），没有就留空。只写自己那个输出文件。
