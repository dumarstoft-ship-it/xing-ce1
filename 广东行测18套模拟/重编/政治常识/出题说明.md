# 政治理论与常识判断出题说明（M01—M05，第1—15题）

## 目的

五套模拟卷的第1—15题要像2025、2026年广东卷：考的内容、问法、选项的写法都与真题同一路数，内容跟上今年（2027年度广东省考，2026年下半年考试）的考点。考生用它检验自己对讲义和时政的掌握，所以每道题的答案必须有确切依据，不能有两可。

真题样子先看 `/home/user/xing-ce1/广东/行测/2022-2026/GD2025.jsonl`、`GD2026.jsonl` 的第1—15题（GD2024的前15题是旧结构，可参考问法）。

## 依据

`/home/user/xing-ce1/学习资料/政治理论常识/颜培天广东政治理论常识.pages.jsonl`（同内容的 .txt 便于搜索）：用户备考用的“2027广东省考政治理论常识”讲义，107页，含二十届五中全会《决定》全文（2026年10月）、思想理论、马哲、党史、广东省情、重要时政、法律常识、人文科技。

- 每道题的正确答案和每个错误选项为什么错，都要在讲义里找到依据，记下PDF页码和原句。
- 讲义没有、你又不能确定的事实不要用。不要凭印象写年份、数字、排名、“首次”“最大”之类的说法。
- 古语名句要准确，优先用讲义里出现的；用讲义外的名句时只用出处和字句都确定的。

## 交什么

写到 `/home/user/xing-ce1/广东行测18套模拟/重编/政治常识/<甲|乙|丙>.json`，一个列表，每题一项：

```json
{
  "paper": "M01",
  "number": 1,
  "form": "判断",
  "area": "全会",
  "stem": "题干。判断题只写陈述句；单选、多选写到“（　）。”为止",
  "options": {"A": "", "B": "", "C": "", "D": ""},
  "answer": "正确",
  "analysis": "给考生看的解析：说清正确答案的依据（可以引用原文），错误选项错在哪",
  "grounding": [{"pdf_page": 5, "quote": "讲义原句"}],
  "distractor_basis": "每个错误选项错在哪、依据哪句",
  "self_check": "你自己隐去答案重做一遍的结果，以及有没有两可之处"
}
```

- 判断题 `options` 留空对象，`answer` 写“正确”或“错误”；单选写一个字母；多选写字母串，如“ABD”。
- 解析不写“讲义第几页”，可以写“二十届五中全会《决定》指出……”这样的依据。
- 写完后逐题隐去答案自己再做一遍，有两可的改到没有为止。
- 只写自己那一个JSON文件，不改其他文件。

## M06起（2026-11-16补）

M01—M05的75题已定稿（甲、乙、丙、丁四个文件，丁的题替换甲在同一题位的题）。后面每套15题由一人写，题位表同上（双数套第3题写党史党建、第8题写生态文明、国家安全、民生等领域），写到 `<出题人>.json`（M06为 `戊.json`）。

- **考点避开**：先读甲、乙、丙、丁四个文件，已考过的论断、名句、法条、事件不要再考；同一份讲义的同一段话，换个问法也算重复。也不要直接用2024—2026年广东真题前15题的原题或原文段。
- **解析**：按“题眼—推导—易错”三段写，每段另起一行，写法见 [../解析改写/改写说明.md](../解析改写/改写说明.md)，样子看 `../../M01/答案与解析.md` 第1—15题。判断题的题眼指出该核对的关键词，易错写把哪个词记混会误判。
- 其余要求同上：正确项和每个错误项都要有讲义原句依据，写完隐去答案自己再做一遍。

### M07起补充（2026-11-16，来自M06的核查与Astra审核）

- M07为单数套（第3题写广东省情，第8题写宪法与法治），出题人代号“己”，写到 `己.json`；考点还要避开 `戊.json`（M06）。
- **单选要靠材料本身区分**：语段整段要只对应一个选项。M06第6题的语段后半段取自全球治理倡议“倡导以人为本”，出题时只删了小标题，内容还在，“人民至上”就成了竞争项。遇到这种情况，换材料或换选项，不要靠删小标题回避。
- **讲义与官方原文不一致的地方**，以官方原文为准，或者不考：
  - 挺进大别山“转入战略反攻”（党史材料两种用语都有，序幕多从强渡黄河算起）；
  - 治安管理处罚法：防卫过当“情节较轻可不予处罚”（法条为“情节较轻的，不予处罚”）；学生欺凌一款的“由主管部门”（法条只写“责令改正”）；
  - 新发展理念“人与自然和谐共生问题”（原话“人与自然和谐问题”）；
  - “惠州博罗成为全省首个千亿县”（政府工作报告原文没有“全省首个”）；
  - 出题人拿不准、M06没用的几处：“教育是根本，科技是关键，人才是基础”“科教兴国是基本国策”、朱雀三号“一子级陆地垂直回收”、雪龙号“第一代”极地科考船。
- 改题后，distractor_basis、self_check 要跟着改，不要让旧选项的核验留在新题上。

- **题位要守**：M08初稿第12题写了岭南文化、第13题写了生活中的物理，与题位表（第12题经济或发展成就，第13题科技或经济）和2025、2026年真题（历史人文、地理、生活常识都是0题）不符，已退回重写。广东内容只放第15题（第11题可写广东的经济目标，但第12、13题写全国层面）。
- **讲义里能用的材料快用完了**：全国层面的“十四五”成就、重大工程、科技成就到M08已被甲至庚用完（讲义的“十四五”成就都是广东的），M08第12、13题考的是政策表述（基本分配制度与农业强国、科教兴国等三大战略）。甲写过、后来被丁替换、不在定稿里的几题的考点（105周年贡献、金砖、探月航天器、基础研究座谈会、上合、AI特征）还没在定稿里考过，可算作余量，用前先查定稿里有没有同一论断。
- **错误项的错处要钉死**：M08第15题B项原为“汕汕高铁全线开通运营，粤西地区正式融入……‘2小时经济圈’”，错在把粤东换成粤西；但同日开通的广湛高铁让粤西也被报道融入“2小时”交通圈，后一分句单看可能属实。已改为“粤西地区由此正式融入”，把错处落在因果上。写“A，B”两个分句的错误项时，要检查每个分句单独看是否也会被认为属实。
- **讲义与官方原文或史实不一致、后面各套避开的说法**（M08出题人查出）：
  - 一大“选举陈独秀为党的总书记”：应为中央局书记；
  - 广州起义是“建立苏维埃政权的首次尝试”：海陆丰苏维埃政权建立更早；
  - 新文化运动是“第一次思想解放运动”：戊戌变法常被称为近代第一次思想解放运动；
  - 逸仙-A星是“世界首颗”成功在轨验证木质外板的卫星：日本的木质卫星LignoSat 2024年已发射；
  - 科举“1906年退出”：通常说1905年废除；
  - “依法治军是基本方式”：常见表述是“基本方略”；
  - 总体国家安全观是“新中国成立以来第一个”被确立为国家安全工作指导思想的战略思想：官方表述是“我们党历史上第一个”；
  - 井冈山根据地“1927年10月29日”：党史资料多只写1927年10月（M08未考）。
  - （M09辛与盲做复核查出）党的基本路线是“国家的生命线、人民的幸福线”：官方原文是“党和国家的生命线”（M09第2题按官方原文写）；
  - 遵义会议纠正了“王明‘左’倾冒险主义”、党“从幼年达到成熟”：常见表述是“左”倾教条主义、“走向成熟”；
  - 英歌舞取材于《水浒传》“第六十四回”：未核实，粤剧“发源于佛山”：学界说法不一；
  - “情谊行为不归属于民法调整”：说得过宽，民法典第1217条好意同乘就属于民法调整。
  - （M11癸查出）十一届三中全会“彻底否定了‘两个凡是’的方针”：1981年历史决议的表述是“坚决批判了‘两个凡是’的错误方针”（M11第9题C项只用后半句“重新确立了解放思想、实事求是的思想路线”）。
