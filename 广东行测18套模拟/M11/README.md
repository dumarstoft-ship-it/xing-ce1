## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照；判断推理和科学推理另由第二人只看题面独立再做（25题），三方对照。解题人此前核对别的套时看过答案页的题，另由一人只看题面独立再做（1题），与来源答案一致。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- **第1—15题**：每题的正确答案和每个错误选项都对应讲义原句；另由一人先凭知识盲做、再对照讲义和公开原文核查，答案全部一致。
- 原第47、48、65题两名解题人各自盲解都与来源答案不同：第47题（图推，来源B按“都能一笔画”）两人都选A（题干单数位外形规律、封闭区域数4、3、4、3），A能否一笔画取决于印刷上几乎看不出的细节；第48题（两组图，来源D按“翻转后求同”）两人都选A（两组对应图形直线数相同）；第65题（加强，来源D）两人都选A（优良传统面临失传，说明当前要大力弘扬）。答案可商榷，三题已换。

## 难度

- 资料分析：读一眼就能判断0道、一步14道、两步6道、三步及以上0道（多步6道）；熟练考生连扫读材料约12.2分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步4道（两步4、三步及以上0），熟练考生约5.3分钟；近三年真题多步6—7道。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。按考场时段计时90分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：逻辑判断削弱3道（真题1—2★）；资料分析比较排序4道（真题3★）；资料分析现期量与简单计算0道（真题1—2★）；资料分析材料理解0道（真题2—5★）；资料分析基期量2道（真题0—1）；资料分析倍数3道（真题0—1）。
