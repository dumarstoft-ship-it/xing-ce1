## 答案是怎么核的

- **第31—90题**：用真题的来源答案（答案解析PDF）。每题先由一人不看答案独立解出并写解析，数量和资料用程序核算、能枚举的枚举，写完再与来源答案对照。
- **第16—30题**：用真题的来源答案，选题时自己先做一遍；新选的题另由一人只看题面盲做，全部一致。
- 第31—90题由三人分块先盲解、再对照来源答案，终稿60题全部一致。原第50题（江苏2024年视图题）解题人盲解与来源不同，重核后认同来源，但两项只靠很细的画法区分，换掉；其余换题都是为避开同一天M15、前一天S06和次日M16的相同情境或同套话题重复，理由见“与原题不同的地方”。言语15题选题人自做和第二人盲做都与来源答案一致。加量套没有安排第二人盲做判断推理和科推。
- 资料原定第86—90题是2021年国考地铁运营一组，解题人评多步5道、三步3道，比主套任何一组都重，与M17原定的2019年国考钓鱼网站处理一组对调。
- 图推“模考保留”里剩下的题不够M16—M18、S07用，本套第49、50题用了江苏省考A类卷的空间题和拼合题（按统筹）。言语有11道国考、江浙题：同一天的M15和前一天的M14、S06用掉了大部分话题，剩下的广东较易题多与它们相撞，且留给M17、M18。
- 第78题“社会物流总额最高的季度”：图中是累计数，按单季比较（第三季度最高），来源同，解析写明；第89题选项是没有刻度的折线，只看走势；第67题“平均速度”来源按路程÷时间算（严格说是平均速率），不影响答案。

## 难度

- 资料分析：读一眼就能判断0道、一步9道、两步10道、三步及以上1道（多步11道）；熟练考生连扫读材料约16.3分钟。近三年真题多步5—8道、约16.1分钟（见[难度对照](../难度对照/README.md)）。
- 数学运算：多步3道（两步3、三步及以上0），熟练考生约4.0分钟；近三年真题多步6—7道。
- 本套资料由M15、M16的同一位解题人评（多步11道、约16.3分钟，与S05、S06相当），他计步偏宽；按题池的统一评法，本套资料多步5道。数学多步3道、约4分钟。
- 评分人各有松紧（同一组资料，题池归类时另一人评的多步题少几道），只作大致参照。建议限时75分钟。

## 题型

各部分各类题的多少与2024—2026年广东卷对照见[编排说明](编排说明.md)。与真题范围差一两道的保留（用户原话“一两道之差无妨”）。旧卷资料几乎没有“材料理解”（不用计算、在纯文字材料里找信息）这类题，现期量题也少，各套多半缺这两类。与真题范围有出入的类别：数学运算最值与构造0道（真题1★）；数学运算杂题4道（真题1—2）；逻辑判断翻译推理3道（真题0—2）；逻辑判断分析推理1道（真题2—3★）；逻辑判断削弱3道（真题1—2★）；逻辑判断加强0道（真题1—2★）；逻辑判断论证缺陷与评价2道（真题0—1）；逻辑判断解释0道（真题2—3★）；逻辑判断结构比较1道（真题3★）；逻辑判断归纳结论2道（真题0）；科学推理力学3道（真题1—2★）；科学推理电学0道（真题1★）；科学推理生物0道（真题1★）；科学推理地理0道（真题1★）；科学推理光热声及其他2道（真题0）；资料分析比较排序4道（真题3★）；资料分析材料理解0道（真题2—5★）；资料分析平均数3道（真题0—1）；资料分析资料分析／计数1道（真题—）。
