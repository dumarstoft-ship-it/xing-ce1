## 收录规则

1. 覆盖副省级、地市级 2016—2025 年各 10 套，行政执法 2022—2025 年 4 套。
2. 同一年跨卷重复题合并；跨年份重复题保留。合并题不逐条标明出处。题号 `GKYY-年份-三位序号` 为本题库编号，不是原卷题号。
3. 去重不只比较题干：同时核对选项、阅读材料和答案；选项次序变化按选项内容对应答案。同题个别错字或细小措辞差异经核对后合并。
4. `____` 表示原题填空。PDF 中嵌成图片的数字、百分数、温度已转写为文字。没有截图、图片选项或外链图片。
5. 排除 2020 年副省级第 53 题（冕的图示选项）；排除 2017 年副省级第 51—55 题（共用材料原文件缺少比例数字），共排除 6 个原卷题次。
6. 原始 930 个题次，排除 6 个，合并 337 个重复题次，最终 587 题。已知争议答案列出全部候选，未自行裁定。

## 字段

| 字段 | 含义 |
| --- | --- |
| `id` | 稳定检索编号，例如 `GKYY-2025-001` |
| `year` / `section` | 考试年份 / 言语理解与表达 |
| `passage` | 共用阅读材料的完整文字；普通题为 `null` |
| `stem` | 题干，包含设问及填空标记 |
| `options` | A、B、C、D 四个选项 |
| `answer` | 原资料唯一答案；有分歧时为 `null` |
| `answer_candidates` | 原资料给出的答案候选列表 |
| `answer_status` | `single` 或 `disputed`；不将原参考答案称为官方答案 |
| `notes` | 画线文字提示或答案分歧说明 |

## 检索示例

在本目录运行：

```sh
rg 'GKYY-2025-001' all.jsonl
rg '新质生产力' 2025.jsonl
rg '"answer_status":"disputed"' all.jsonl
python3 verify.py
```

Python 读取并按年份和关键词筛选：

```python
import json
from pathlib import Path

for line in Path("all.jsonl").read_text(encoding="utf-8").splitlines():
    q = json.loads(line)
    content = (q["passage"] or "") + q["stem"] + " ".join(q["options"].values())
    if q["year"] == 2025 and "新质生产力" in content:
        print(q["id"], q["stem"], q["options"], q["answer_candidates"])
```
