## 给 AI 的入口

- [all.jsonl](all.jsonl)：每行一道题，UTF-8；可直接逐行解析、分块或建立检索索引。
- 每卷的 Markdown：供阅读，保留图片与图表文字数据。
- [schema.json](schema.json)：字段类型；[assets-manifest.json](assets-manifest.json)：图片来源页、裁剪坐标、处理方式与 SHA-256；[sources.json](sources.json)：原 PDF 路径及 Git blob SHA。
- [质量报告](quality-report.md)：完整性、图像、答案和已处理源文件问题。

JSONL 每条题目都包含完整 `material`（如果有），包括材料文字、图表数据文字和图片路径。每题的 `figures` 包含题图；`options[].image_refs` 指向图形选项。读取图形题时，需要把图片一并交给支持图像的模型。所有 `path` 相对于本目录，不能只传 JSONL 而丢弃 `assets/`。

`answer.values` 表示候选答案集合：单选 `[ ["A"] ]`，多选 `[ ["A","B"] ]`，判断题 `[ ["正确"] ]`；争议答案例如 `[ ["D"], ["B"] ]`，表示 D 或 B 两个候选，**不是多选 DB**。`status` 分别为 `known`、`disputed`、`missing`。缺失时 `values=[]`。

2026 年 90 题的配套答案在仓库中缺失，全部标记 `missing`，未推测答案。2022 年乡镇第 52 题、县级第 47 题各保留原答案的 D/B 争议。2024 与 2026 年按源文件标注为网友回忆版。2024—2026 年的文件没有乡镇/县级卷别标记，`paper_variant` 记为“未标卷别”。

## 图文处理

正文、选项、数字、分数、温度及上下标转为文字。154 个题图/材料图文件中，147 个为原 PDF 页面渲染后的清晰裁剪（288 DPI），7 个为代码重绘，并标注处理方式。33 个图表或数字矩阵另有经过对照的文字转写，便于纯文本检索。原图已可辨认或代码重绘已匹配，未使用生成式图片。

2022 年乡镇第 81 题与县级第 84 题的原题干缺少 M₁、M₂、F₁、F₂ 等符号，经确认按原配图恢复，并在题内注明。其余源文件的措辞、数据和答案按原卷保留；图表空白单元格不补值。页码为 PDF 的 1 起算物理页码。

## 检索与验证

Python 3 标准库即可使用：

```bash
python3 query.py --year 2024 --section 资料分析 --keyword 法律援助
python3 query.py --paper GD2023-XJ --number 100 --jsonl
python3 query.py --answer-status disputed
python3 verify.py
```

`query.py --jsonl` 输出完整题目；默认输出匹配题号、题干摘要、答案状态及图片路径。检索覆盖题干、选项、共用材料和图表文字，不以答案或解析作为关键词内容。
