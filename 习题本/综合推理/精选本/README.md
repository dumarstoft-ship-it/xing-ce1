本册新增的是选题与分类、认知地图、各模块导读（每个模型的本质、信号、第一笔、易错）和突破口速查。

## 怎么用

1. 先读认知地图（第2页）：几种题型都可以用同一套五个动作来解，依次是表示、起点、传播、分支、收口。
2. 每个模块先读导读，记住每个模型的“第一笔”，再按卡片顺序做题。
3. 先做核心题，做对后再做进阶题；时间紧只做核心题（45道）。
4. 练习页在正面，翻页看原书的草稿解析，重点看“收笔”和“容易错推”。
5. 某个模型错两道以上，去原书做该模块导读页列出的加练备选。
6. 全部做完后，用附录“突破口速查”（第179页）盖住右栏自测。

A4 双面打印，选长边翻页：每题练习页在正面，解析在背面。PDF 目录、模型卡片里的题号和书签都可以点击跳转。

## 怎么挑的

- 337题逐题重解一遍，核对参考答案；题面歧义或答案有争议的题不进主线。
- 按“突破口能否迁移”取舍：一两步就能读出答案、只能靠代入选项的题删去。
- 同一个动作只留最典型的一道；更难的变式只在多出新要素时才留，标为“进阶”。
- 优先广东省考、市考和事业单位的近年真题；早年题只留经典母题。

- 原329、334、335、336：按印出的题面，参考答案不成立。未收入。
- 原330、332、337：题干只给充分条件，参考答案按“列出的条件是唯一途径”给出。收入原330作避坑。
