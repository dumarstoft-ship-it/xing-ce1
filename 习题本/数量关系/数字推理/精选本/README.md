# 数字推理精选本

[打开精选本（PDF，60页）](./数字推理精选本_75题.pdf)

从[《广东数字推理 · 条件反射训练》](../广东数字推理_30个模型条件反射训练.pdf)的249题中精选 **75** 题（全部是真题）：核心 37、进阶 38。按原书的模型编号分成 8 个模块，最后一个模块是不给提示的识别训练。题目和解析都从原书原样裁出，编号沿用原书（如 M01-04 指模型 M01 的第4题）。

本册新增的是选题与分类、认知地图（看到什么就先写什么）、各模块导读（每个模型的本质、信号、首式、易错）和首式速查。

## 怎么用

1. 先读认知地图（第2页）：看到什么，先写什么。
2. 每题先在“首式”一栏写第一个算式，再算答案，限时三十秒到一分钟。
3. 先做核心题，做对后再做进阶题；时间紧只做核心题。
4. 做完一页翻到背面，对照原书解析；做错的题回到导读卡片，找对应模型。
5. 最后做模块8：不看提示，自己认出模型；做错就按“回练”回到对应模型。
6. A4双面打印，选长边翻页。
