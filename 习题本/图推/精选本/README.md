本册新增的是：选题与分类、认知地图（看到什么，第一步做什么）、每组一张方法卡（方法、信号、最快路径、易错、限时）、每题一句最快路径、10套限时卷，以及对原解析的勘误。

训练模块“题后即看答案”：每道题下面紧跟答案和解析，做题时先遮住。限时套卷先排5道题，答案在后一页。

## 怎么用

1. 空间（A1—A6）练提速：先读方法卡，做题时照“最快路径”的顺序走，每题掐表，超时就看答案，记下卡在了哪一步。
2. 平面（B1—B5）练认稳：做题前先写下“我第一眼看什么”，对完答案，比一比自己第一眼看的和最快路径差在哪。
3. 训练模块里，题型写在每组标题上；C模块的限时卷不告诉你，那里才是在练识别。C1、C2是广东2025、2024年的图推原题整块。
4. 时间紧：每组只做标“核心”的题（共76道），再做C模块。
5. 复盘：盖住附录右栏，看题号回忆第一步；想不起来就翻回去重做。
