# 2026 下半年广东卷模考 · 第 16—33 季 · AI 可读题库

18 份试卷、990 道题，按原卷的 **数量关系、判断推理、资料分析** 三个模块整理。

| 模块 | 每季原题号 | 每季题数 | 总题数 |
| --- | --- | ---: | ---: |
| 数量关系 | 31—45 | 15 | 270 |
| 判断推理 | 46—65 | 20 | 360 |
| 资料分析 | 71—90 | 20 | 360 |

原卷第 66—70 题属于独立的“科学推理”模块，不在本次三模块范围内。

## 给 AI 使用

- **按模块阅读**：打开下表的 Markdown。题干、选项、分数、公式、表格均为可直接读取的文本；资料分析的共用材料位于对应 5 道题前。
- **程序或检索读取**：[全部题目.jsonl](全部题目.jsonl) 每行一题，已内嵌该题所需的资料材料，无需再次拆页、OCR 或拼接材料。每季的 `题目.json` 同时提供独立的材料列表和题目列表。
- **图形题**：图像保存在 `assets/`，Markdown 已按题嵌入。上传文件给 AI 时，把相应 Markdown 和图片一起提供，或使用[完整资料包](广东模考16-33季_三个模块_AI可读.zip)。读取图形仍需具备读图能力的 AI；纯文本模型不能据文件路径看到图像。

优先读取题目正文文件；`来源清单.json`、`图片清单.json`、`转写核验记录.json` 用于溯源核对。

## 转写方式与核对

- 文字直接提取自 PDF 文本层，修正了 PDF 字符映射中的康熙部首编码，并合并跨行、跨页的同一段文字。
- 239 处内嵌公式或符号已转为文本/LaTeX；分子、分母、根号、正负号和选项位置按原图核对。
- 84 幅含文字或数值的图表已转成表格，包括 74 幅资料分析图表、10 幅数量或逻辑题数表/布局。统计图保留原标注数值、年份、单位和图例含义；不通过柱高或折线位置估算缺省数据。
- 157 幅空间图形、几何图、图形选项保留 PDF 内嵌原图，以 PNG 无损保存。逐图检查边界、线条、阴影与标签，未使用整页截图替代文字。没有对原图进行缩小或有损压缩。
- 全部 990 题均有 A—D 四个选项；72 组资料材料按原题号关联。保留原卷页码、源文件 SHA-256 和图像位置，便于追溯。
- 原表中的 `—`、空白、`？` 或未标注数值保持其原意，具体说明写在对应表格下方。原卷中的统计口径与数据按题本保留。

本次源文件为题本，JSON 中 `answer` 为 `null`。质量检查结果见[校验报告](校验报告.json)。

## JSON 字段

| 字段 | 含义 |
| --- | --- |
| `id` / `season` / `number` | 稳定题目 ID、季次、原题号 |
| `section` | 原卷模块名称 |
| `stem` | 有序题干块，类型为 `text`、`table`、`figure` |
| `options` | A、B、C、D 各自的有序内容块 |
| `material` | JSONL 中内嵌的完整资料材料；非资料题为 `null` |
| `material_id` | 资料材料 ID；每季 JSON 的 `materials` 列表中可查 |
| `source_pages` / `source_spans` | 原 PDF 的 1 起始页码及页面坐标（pt） |
| `source_asset_ids` | 原内嵌图像 ID，已转成文字的图像也保留该记录 |
| `source` | 来源文件名、SHA-256、总页数 |
| 图像的 `path` | 相对本资料包根目录；每季 JSON 的 `asset_base` 为 `..` |

表格单元格以字符串保存，保留小数末尾的 0、百分号和缺省符号。图形题图片中的 A—D 字母与 JSON 选项标签一一对应。
