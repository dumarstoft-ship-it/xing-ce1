## 给 AI 使用

- **阅读或上传**：使用各季各模块 Markdown，或科学推理汇总文件。正文、选项、分数、化学式和表格都是文本。
- **程序或检索读取**：[全部题目.jsonl](全部题目.jsonl) 每行一题，包含该题所需的完整资料材料。无需再次拆页、OCR、辨认公式图片或拼接材料。每季的 `题目.json` 另含独立材料列表。
- **图形题**：`assets/` 内图片已经按题提取并建立引用。Markdown 与相应图片需一起提供给具备读图能力的 AI。纯文本模型不能凭文件路径看到图形。可使用[完整资料包](广东模考16-33季_四个模块_AI可读.zip)；具体上传方式取决于接收工具能否打开 ZIP 及其中图片。
- **原卷定位**：每题保留原题号、PDF 页码、坐标和来源哈希；不需要重新预处理即可追溯。

## 转写与校验

- 文字来自 PDF 文本层，规范化 PDF 字符映射中的康熙部首编码，合并跨行、跨页的同一段文字。
- **358 处公式或符号**转为文本/LaTeX，其中科学推理新增 119 处。分子、分母、上下标、化学式、方向符号和选项归属均按原图核对。
- **90 幅图表或关系图**转为结构化表格，其中新增 6 幅科学推理图表：昼夜差值、pH、食物网、遗传系谱、速度曲线、微观粒子图。保留原图标注、节点与箭头关系，不补写答案或推导结论。
- **194 幅需要看图的题图**保留为独立图片。其中 193 幅直接提取自 PDF 内嵌图像，以 PNG 无损保存；第 21 季第 66 题的小尺寸平抛图按原图坐标重绘，提供 SVG 和 1296×1020 PNG，并保留原图供比对。没有用整页截图替代题干或选项。
- 校正 3 题中的公式阅读顺序与选项归属，详见[阅读顺序校正记录](阅读顺序校正记录.json)。
- 每季 60 题、每题 A—D 四个选项；72 组资料材料完整关联。新增 90 题与原来的 990 题合并后，原有题目对象和 54 份模块 Markdown 均保持一致。
- 原题中刻意设置的错误选项、数据口径、缺省符号按原卷保留。本次未额外提供答案；JSON 的 `answer` 为 `null`。

可查 [校验报告](校验报告.json)、[转写核验记录](转写核验记录.json)、[重绘核对记录](重绘核对记录.json)、[图片清单](图片清单.json)、[来源清单](来源清单.json) 和 [文件校验和](SHA256SUMS.txt)。原始 PDF 未改动。

## JSON 字段

| 字段 | 含义 |
| --- | --- |
| `id` / `season` / `number` | 稳定题目 ID、季次、原题号 |
| `section` | 原卷模块名称 |
| `stem` | 有序题干块，类型为 `text`、`table`、`figure` |
| `options` | A、B、C、D 各自的有序内容块 |
| `material` | JSONL 内嵌资料材料；非资料题为 `null` |
| `material_id` | 资料材料 ID；每季 JSON 的 `materials` 列表中可查 |
| `source_pages` / `source_spans` | 原 PDF 的 1 起始页码及页面坐标（pt） |
| `source_asset_ids` | 原内嵌图像 ID，转成文字后仍保留溯源记录 |
| `source` | 来源文件名、SHA-256、总页数 |
| 图像 `path` / 可选 `svg_path` | 相对资料包根目录；每季 JSON 的 `asset_base` 为 `..` |

表格单元格保存为字符串，保留小数末尾的 0、百分号和缺省符号。重绘图的原图和处理说明可在核对记录中找到。
