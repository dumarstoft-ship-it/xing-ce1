# 共同编者工作说明（第一批：资料1日、判断1日、言语3日）

## 为什么做这件事
用户备考 2027 年度广东省考，笔试预计 2026 年 12 月上旬，现在是 11 月 7 日，时间很紧。用户和另一个模型（GPT）定了一套 24 天集训：数量、资料、判断各 8 天，每天一个主模块 135 道新题 + 40 道言语。任务书原文在 `/home/user/xing-ce1/广东行测24天集训/Claude协作任务书_v1.md`，请完整读一遍；更早的一份方案 `/home/user/xingce/广东省考备考训练方案 (1).pdf` 讲了用户的总原则，可当背景读（两者冲突时以任务书为准）。

用户特别交代：**指月之指非月**。任务书的字句是手指，用户要的是月亮——一套能直接拿来练、答案可靠、练了真有用的题。字面要求和它背后的目的冲突时，按目的办，并在报告里写清你怎么理解、为什么这样做；用户已授权编者这样判断。反过来，凡是关系到对错和可追溯的底线（下面"底线"一节），不要松动。

用户的特点：容易沉迷深挖，所以要固定框架、集中训练；数量和资料"不是不会做，而是要提速"；言语靠语感，要把语感校准到广东命题人的口味。

你是**对成品负责的共同编者**，不是搬运工：选什么、怎么成组、哪题删、哪题改，由你判断。你交回的东西会被合并进正式题包，用户会直接拿来练。

## 底线（只管对错和可行性）
1. 不编造：题目、图、答案、出处、原文都必须来自实际文件或你的实际计算。看不清、缺图、乱码、答案对不上，就标出来，不要补。
2. 可追溯：每题能回到 文件 + 页码 + 原题号；改编题标 `variant_of` 指向原题。
3. 专项（资料、判断）逐题独立解一遍，不因为解析写了某答案就算核验。能算的用程序算。图形题要真看图（用 render.py 出图后用 Read 看），不能只靠文字层。
4. 言语只做数据完整性和原文对应检查：保留原参考答案和原有争议标记，不写解析，不为争议题论证唯一答案，不改标答。
5. 不改动 `/home/user/xing-ce1`、`/home/user/xingce` 里的任何文件；只在你自己的输出目录写。
6. 不声称和 GPT 联系过；你只通过交回的文件和题号与它交接。
7. 用 `claim.py` 登记你用的原题，避免与其他编者重复（重复卷里的同一道题会被一起锁住）。

## 现成的工具和索引（都在 /home/user/work）
- `index/<tag>.json`：每份题本切好的题，含 `qno / section / segs(页, y0, y1) / text / images / material`；`kind='material'` 是资料题的材料段。tag：xing-ce1 的文件无后缀，xingce 的文件带 `_xc`（同一年同卷常两边各有一个版本，可互相校对）。切题是自动的，偶有错位（尤其 section 标签和老格式），以你看到的原页为准。
- `answers/<tag>.json`：从解析 PDF 自动抽出的参考答案（部分有 `rate` 正确率、`yicuo` 易错项）。自动抽取可能错位，用前和解析原文核对。2013–2021 年广东解析是扫描件，没有文字层，要出图看。2026 年度广东卷没有解析。
- `qindex.jsonl`：全部题的平铺索引，含 `dup_group`（跨卷重复同题）。
- `tools/render.py`：把某题/某材料/某页渲染成 PNG；`render.py ans <tag> <正则>` 打印解析原文片段。见文件头注释。
- `tools/claim.py`：`check / take / list`，见文件头注释。
- 卷号对照：GD=广东省考（X县级 Z乡镇），GDXD=广东选调，GK=国考（F副省 D地市 X行政执法），ZJ浙江 JS江苏 SD山东 SC四川 HB河北 SZ深圳 等；数字是考试年度。原始登记见 `tools/papers.py`。
- 范围：任务书说暂按 2017—2026 考试年度检索，广东与国考定边界，外省补充同范围题目。老卷或外省题有充分理由也可用，写明理由。
- 已做情况：用户做过哪些真题没有确切记录，一律标 `已做情况未知`。

## 交回什么
在你的输出目录（如 `/home/user/work/out/ZL-A/`）下：
- `questions.jsonl`：一行一题，字段如下（可加字段，不要少）：
```
id               你的本地编号，如 "ZL-A-001"（合并时统一改成正式题号，会保留对照）
module           资料 / 判断 / 言语
day              ZL01 / PD01 / YY01 / YY02 / YY03
group, group_title  题组编号和组名（组名不泄露全部解法）
topic            细分题型
order            在组内的建议顺序
source           {"paper": "GK2024F", "file": "相对 /home/user 的路径", "page": 页码(从1起), "qno": 原题号,
                  "ans_file": 解析文件, "ans_page": 解析页码或null, "version_note": 如"网友回忆版"}
done_status      "已做情况未知"
stem, options    题干与选项（options 用 {"A":..,"B":..,"C":..,"D":..}，图形选项写"见图"）
material_or_article  资料材料ID / 言语原文ID / null
assets           本题用到的图片相对路径列表（相对你的输出目录）
source_answer    解析给的答案（没有则 null）
checked_answer   你核验后的答案
brief_solution   专项：简短解法（给答案册用，几行即可，突出提速点）；言语：留空 ""
selection_value  一句具体的入选价值（如"给出两期增长率需先判断用间隔增长率还是逐期回推"），不要"巩固基础""有一定难度"
variant_of       改编题指向原题如 "GK2024F-118"；原题为 null
check_status     已核验 / 已核验-改编 / 冲突待复核 / 图像待复核 / 未核验
flags            列表，如 ["网友回忆版","原答案冲突","疑似多解","图不清","范围存疑","争议(原标)"]
notes            编者记录（不给考生看）
```
- `assets/`：本题需要的图（题图、表、图表截图）。截图保持清晰，必要时提高 dpi。
- 资料：`materials.jsonl`，一行一份材料 `{mid, source, text, assets, notes}`；材料 ID 统一用 `ZLM-<paper>-<序号>`（序号按该卷材料出现顺序 1、2、3…），文字材料照原文保留，表和图截图，单位、表头、脚注不能丢。两位资料编者可能共用同一份材料：先看 `/home/user/work/out/zl_materials/` 下有没有，有就复用，没有就建在那里（目录名=材料ID）。
- 言语：`articles.jsonl`，一行一个原文对象 `{aid, kind, source, title, text, note}`。
- `report.md`：实际查过哪些来源、交付多少、缺口、未决问题（写成"题号 + 原始证据 + 具体分歧 + 建议"）、你对任务书安排的不同意见及证据。

## 质量标准
- 专项每题"难，或者有明确训练价值"，不用水题凑数；难也必须在广东/国考范围内。
- 约 20 题成组，组内要有实质的条件变化、方法辨别、边界或提速空间，难易交叉；不是换数换人名。
- 宁可少而真，不要多而虚：做不完就交实际完成的完整题组，写清缺口和接续点。
