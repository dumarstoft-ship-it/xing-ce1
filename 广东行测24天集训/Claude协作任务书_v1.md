# 广东行测24天集训｜Claude协作任务书 v1

## 给 Claude：直接按此任务书开始，不重新讨论备考方法

你与另一位模型共同编制一套广东省考行测训练材料。你是独立负责成品的共同编者，不是只负责搬运资料的助手。你可以选题、设计题组、改编、解题核验，并有依据地质疑原方案。另一位模型负责全局边界、数量主编以及重点交叉复核。

当前没有建立模型之间的直接通信。用户转交本文件及成果包，双方通过文件和题号交接；不要声称已联系另一模型、已自动同步，或将在无人触发时后台持续工作。

## 1. 用户已确定的约束

- 目标是广东省考；广东与国考近十个考试年度的真题结构作为训练边界，外省真题用于补充同范围题目。暂按2017—2026考试年度检索，实际材料缺失要如实报告；卷别、年份与最新大纲如需核实，必须用实际来源，不凭本任务书推断。
- 24个训练日，数量、资料、判断各8天。每天只练一个主模块135道新题，另有40道言语。专项全部做两遍后核对；言语一遍。合计4,200道不同题目、7,440题次。
- 用户上午还练申论，但本任务不编申论、政治理论及常识学习材料，也不重新优化其日程。
- 用户容易沉迷深挖，要求固定框架、集中训练，不扩展成竞赛数学、高中理科全课程或庞大的学习平台。
- 每道专项题必须“难，或者有明确训练价值”。不设基础题保底比例，不用水题凑配额；难题也必须在既定范围内。
- 同一主题约20题成组，组内有实质条件变化、方法辨别、边界或提速空间，难易交叉。不能只是换数换人名重复；不能在组名中泄露全部解法。
- 言语主要训练语感。用户故意保留争议题，不能因争议标记删题、改标答或增写辩论。保留原参考答案及原争议标记，只附原文，不写解析。
- 不得推定用户做过哪些年份的真题。没有确切记录的标为“已做情况未知”，不把另一模型未经证实的陈述当事实。

## 4. 编题目标配额（不是已证实的考试占比）

- 数量日：数推30＋运算105；8天合计240＋840。
- 资料日：135个设问；不是135篇。材料数量依实际保留的有效设问决定，不固定27篇。每天保留广东式文字理解、统计口径和轻计算训练，其余覆盖相关计算与比较主轴。
- 判断日：图形45（平面25＋空间20）、逻辑75、科学15；8天合计360＋600＋120。
- 逻辑75的工作目标：论证35、条件与必然性15、组合15、结构与归纳10。
- 言语日：选词12、片段18、语句填空6、排序4；24天合计288＋432＋144＋96。

上述细分是现有训练设计，不得写成广东真题统计结论。发现明显不适配时，把证据和建议集中写进交接摘要；不要自行增加题型或更改用户总量。具体题组可以微调细分数量，但不得为凑某个小类数目收低价值题，需说明调整。

数量8次主轴：基本关系与比例；工程与分配；行程；经济与混合；整数余数周期；排列组合概率；容斥最值分配；几何与综合。
资料8次主轴：基期现期与口径；增长量；增长率比较；比重；平均数；倍数混合；跨期年均；综合比较与整组处理。
判断围绕以上已定范围编排，图推固定放在判断日开头，避免被科推挤占。不主动添加国考独有或外省特有的独立专项。

## 5. 筛选、改编与核验

### 专项
每道入选题内部保留一句具体的“入选价值”，如减少分类、端点计数、基准识别、条件变化导致方法变化、图形特征辨别等。不接受仅写“巩固基础”“有一定难度”。此句只放编者记录，不放题目前。

优先选编真实题目。换数值必须有目的；修改题干、条件、选项或设问后，重新独立解题并核对唯一答案，标“改编”，保留原题对应关系。不得因来源解析写了某个答案就视为已验证。

资料保留所需材料上下文和单位、表头、脚注。无价值设问可删或改，不必凑齐每篇五问。图形和科推保留清晰原图或经核对的忠实重制图；不要凭模糊图自行补线。PDF中嵌图必须实际查看，不能只依赖文字提取。优先读取文本层，OCR仅在确无可用文本时使用。

来源至少能回到具体文件、页码和原题号。缺图、乱码、答案不一致等必须标记，未解决前不进入正式题包。

### 言语
- 先选广东未确认做过的真题（已做情况未知如实标注），再用用户HTML；排序用公考真题补足。
- HTML中的政治/常识题、单纯遮词点和文章篇数不能冒算成独立言语选择题。
- 题干、选项、原站参考答案、争议标记按原数据保留；不把“争议”当作废题。
- 选词/语句填空附恢复空缺的原文段落；主旨/意图/标题附对应原文及必要上下文，恢复被删中心句与原标题。
- 原文直接取源数据，保持原样，不用模型改写，不从解析倒推。原站解析可留在原始备份中，但不显示在训练答案册里。
- 排序附参考顺序及还原的完整文段；未找到文章出处，不冒称有外部原文。
- 不在答前暴露标题、中心句、原文或邻题答案。同文多题集中出示原文时，须等关联题全部完成，防止互相泄题。
- 只做数据完整性与原文对应检查，不为争议题论证唯一正确性。

## 7. 交接只保留必要材料

交付一个压缩包，至少包括：
- `handoff.md`：一页摘要，写实际已检查来源、已交付数量、缺口、未决问题和下一步；不要重写备考理论。
- `questions.jsonl`：结构化题目、来源、答案、材料/图片/原文引用、入选价值、改编关系及核验状态；题号稳定，方便直接指出某一题。
- 图片、材料与原文文件：可用共同材料ID/文章ID复用，避免重复与错配。
- 可直接阅读的题目册和答案/原文册：简单排版即可；有网页工具时可生成离线HTML，不开发账号、复杂仪表盘或新的训练平台。

最小记录字段可合并组织，不必做数据库工程：
`id / module / topic / source / stem / options / material_or_article / assets / source_answer / checked_answer / brief_solution / selection_value / variant_of / check_status`。

言语`brief_solution`为空，保留原参考答案，不写“已证明唯一答案”。题目编号与来源编号分开：变式有自己的ID，但必须指向原题，不能冒充全新原题。记录已用题，避免两边或不同日包重复。

未决问题直接用“题号＋原始证据＋具体分歧＋建议”表达，另一模型拿到后可处理，不让用户重新翻译。无法访问源文件或缺少HTML时明确指出阻塞；可继续不依赖缺失材料的部分，不自行补造。
