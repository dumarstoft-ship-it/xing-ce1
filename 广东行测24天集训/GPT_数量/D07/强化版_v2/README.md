## 强化的具体目标

不是靠增加大数、铺陈无关背景或含糊说法提高难度，而是让题面自然包含相互关联的条件，由考生自行完成以下判断：

| 需要从文字中辨明的关系 | 本版实例 |
|---|---|
| 不同时间起点、含不含停留、显示时间与真实时间 | M002、013、018、052 |
| 按全局时间触发，还是按本人累计路程触发 | M038、042、054、065 |
| 运动、停车、转向、到站等候前后，是否还能使用同一方程 | M048、053—055、074、090—091 |
| “首次”“最迟”“至少”及开闭区间是否改变可行范围 | M003、033、092、099—100 |
| 两人条件不同、额外停留后，原来的经典结论是否仍成立 | M070、088、101 |
| 隐含条件用于排除分支，而不只是计算数字 | M043第二次相遇仍为迎面相遇 |

升级题的答案先写“读题定位”，再给模型、计算及必要的阶段检验。题本不先划时间线、标方法或透露关键转折。短题中仍保留有辨别价值的标准结构，不强行把每题拉成长题。
