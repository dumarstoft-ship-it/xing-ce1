## 编者与模型交接

[题源与关键计算索引（JSONL）](D01_数学运算001-060_编制记录.jsonl) 是60条**引用式编制记录**，不是又一套新题。`id`对齐题本和答案册的标题；题干、选项在题本，解答、入选价值、改编说明在答案册，避免复制多套后互相不一致。

字段：`id / group / kind / paper / qno / pdf_page / answer / source_answer / check`。

- `paper` 对应输入目录下同名Markdown文件；`qno`为原卷题号，`pdf_page`为交接标注的物理页。
- `answer`为本题答案；`source_answer`为母题原参考答案。`null`表示本次交接文本未抽到原答案，不表示本题没有解答。改编题两种答案不要求一致。
- `check`保存已经执行通过的关键数值检查表达式，其中`F`表示Python的`fractions.Fraction`。它是核验记录，不代替完整数学推导，不宣称穷尽所有潜在歧义。
- 后续续编沿用稳定ID，从D01-M061接续，不重新编号已交付题目。数字推理另用D01-N001起编号。
