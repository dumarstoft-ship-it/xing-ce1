## 3. 边界
归增长量（本日收）：所求是变化量本身或变化量之间的关系（倍数、占比、贡献率、排序、最值、计数、走势），中途要回推基期的也算（如平均数的增量、用各部分增量相加求整体增速）。归基期（第 1 轮 ZL-A 已收）：所求是某一期的水平，或不同量在基期的差、和、倍数，增长量只是已知条件（据此剔除已登记的 GD2023X-96；ZL-A 的 010、014、042 也属于这一侧）。年均增长量留给第 7 日；增长率比较只收一道辨别题 GDXD2020ZH-91。

## 9. 对安排的不同意见
1. 材料 ID 两套编号并存：zl_materials 一直按卷面标号（（一）（二）…；无标号的按资料部分顺序），但 index 的 mid 编号常错一位（GK2025D、GDXD2019XC、ZJ2026A、ZJ2024A、GK2024F）。建议统一按卷面标号，check 时两套 ID 都查。
2. claim.py 没有释放功能，剔除或误登的键收不回来，建议加 release。
3. “按材料连续排列”后组主题只能按主导题型定，组内题型必然混杂；已按主导题型分组并保证每组都有精度和条件上的变化；各组字母分布有偏（ZA1 的 C、D 各 3 个；ZA4 的 A 只有 2 个），整体均衡。
4. 本日 27 问落在第 1 轮用过的材料上，用户第二次读这些材料会快一些，速度训练略有失真，但这是题源紧张下的合规复用。
