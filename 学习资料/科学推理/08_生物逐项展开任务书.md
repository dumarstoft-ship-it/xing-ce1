# 广东省考生物：逐项展开任务书 v1.1

修订日期：2026-11-14

先读[范围调研](06_生物范围调研与证据边界.md)、[62项知识框架](07_生物知识框架_v1.md)和[全科校对记录](12_全科校对记录_v1.1.md)。本文件约束对象、深度和验收，不要求一次展开全部知识。

本次修正示范B中的原句“配子数目减半”：应为人和多数动物的标准模型中，配子的染色体条数相对相应二倍体体细胞减半，并非配子数量减半。植物等生物的生活史不能一律照搬这个直接产配子模型。其余示范仍为自拟教学材料，不是原题答案。

## 一、目标与学习者起点

目标是掌握广东科推的基本生物模型，能处理换背景、改条件和图表综合；不是重学完整高中生物或背动植物百科。

生物基础尚未单独诊断，不能把此前未选化学解释成未选生物。先用少量有区分度的问题确认最小前置：术语指什么，过程发生在谁身上，关系在什么条件下成立。已会的迅速通过，不用十道定义题拖慢。

解释应形成可检验的理解，落回物质、细胞、信号、路径或收支，不是看见某特征就选某项的机械口诀。

## 二、每轮解决一个具体问题

开头写编号或问题包和一句目标，例如“B02-05：为什么植物有光时也可能净消耗有机物”。

先查前置。缺净量概念就补产生与消耗，不重讲全部叶绿体；缺父亲给儿子什么染色体就补路径，不先堆遗传术语。

一个问题可调用多个编号，一个编号也可分次补缺。不为目录工整强求同样段数、题数和长度。

## 三、解释要求

先让词指向对象：染色体/DNA/基因，酶/激素/抗体，细菌/真菌/病毒要有具体区别，不能用未解释的术语替代说明。

把关系讲成过程：植物增重追踪来源和消耗；血糖追踪输入利用储存调节；遗传追踪亲代信息组合；生态追踪资源、食物和相互影响。拟人比喻只辅助起步，不作原因。

分开一般关系与必要事实：净变化的收支可迁移，胰岛素来源和细胞类型差异则需少量事实。既不承诺所有事实都能推导，也不把记忆扩成百科。

先讲题设标准模型，再补真正改变判断的条件；不能借现实复杂否定所有推理，也不能把题内简化当无条件规律。

## 四、单元交付与验收

| 检查项 | 要求 |
|---|---|
| 定位 | 编号、目标、最小前置，区分题源主题/变式/补漏 |
| 解释 | 清楚对象和完整过程，不只术语与口诀 |
| 条件 | 标出有关温度、光照、时间、对象、遗传模式、统计口径 |
| 证据 | 题给、常识、假设、观察、推论分开；图是否实际读取 |
| 迁移 | 改一个真正影响结论的条件；熟练部分短过 |
| 验收 | 能解释、能迁移、能指出错误遗漏的条件 |
| 记录 | 只记已掌握点、缺口和错因，下一轮不重复已通过前置 |
| 停止 | 达标即停；未达标修缺口，不重讲整章 |

题少而有区分度，不靠大量低价值重复制造训练量。

## 五、四个展开深度示范

以下均为自拟教学模型，不冒充原题，也不要求现在一次完成四节课。

### 示例A：有光为何仍可净消耗

对应B00-03、B02-03—05。设同对象、同时段、统一有机物当量单位，忽略其他输入输出。生产速率6、呼吸消耗2，净积累4；光照减弱后生产1、呼吸仍2，净变化为−1。数字是教学设定，不是真实测量。

第二种仍有生产，只是收入少于支出。生产和总量增加是两个命题；净零也不代表两过程停止。[K4]

验收改变光照或题给温度条件、观察净气体交换，先确认对象单位相同，不能拿气体体积直接减有机物质量。

停止在收支与限制因素；不扩光呼吸、光反应电子传递和全部碳循环中间物，不输出温室农艺配方。

### 示例B：DNA复制与染色体计数

对应B01-05、B06-01。自拟正常二倍体细胞，复制前4条核染色体，完成一次有丝分裂；忽略异常，统计核遗传物质，不混入线粒体/叶绿体DNA。

| 时点与统计对象 | 染色体条数 | 核DNA分子数 |
|---|---:|---:|
| 复制前的一个细胞 | 4 | 4 |
| 复制后、姐妹染色单体未分离的一个细胞 | 4 | 8 |
| 姐妹染色单体已分离、细胞未分开的整个细胞 | 8 | 8 |
| 分裂完成后的每一个子细胞 | 4 | 4 |

复制和分离是两个事件；相连副本与独立染色体的计数不同；最后一行换成每个子细胞。不能只背先倍增再恢复而不知数什么。[K2]

验收换初始条数或统计对象，能稳定判断即可，不画全部时期精细结构。

**减数分裂的补充只针对明确模型：**人和多数动物中，形成配子的过程中染色体套数减少，普通配子的染色体条数为相应二倍体体细胞的一半；受精使双亲贡献结合，恢复二倍体数目。减半的是每个配子的染色体条数/套数，不是生成的配子个数。植物的减数分裂直接产生孢子，配子由配子体形成；这一边界只短提示，不展开全部世代交替。

停止在基本分配与受精意义，不扩异常分离和多时期综合图。原理与模型边界另见校对记录A07。

### 示例C：伴X显性不是父病子必正常

对应B06-04—07。采用人类教材XX/XY、X连锁显性A、正常a，假定完全外显、无新突变等。

父亲XᴬY、母亲XᵃXᵃ时，女儿取得父亲Xᴬ，儿子取得父亲Y，母亲只给Xᵃ。若母亲改为XᴬXᵃ，儿子就可能从母亲获得Xᴬ。

稳定结论是该模型中父亲不把自己的X传给儿子，不是不管母亲如何儿子都正常。[K11]

验收分别问给定性别概率和全部子代概率，并说明亲代基因型；不把概率当几次生育的固定配额。

停止在单基因、少代数、标准模型；不做真实家庭诊断，不扩连锁互换、多基因或临床外显率。

### 示例D：食物网不是永远可靠的增减号

对应B08-02—07。自拟捕食网：草→兔，草→鼠，兔→鹰，鼠→鹰，鼠→蛇，蛇→鹰；箭头表示食物到取食者，不对应任何原题图。

先找从生产者到题设终端消费者的完整路径，再沿每条路径定营养级。鹰可处不同营养级；鹰和蛇既争用鼠，也存在捕食。这些来自明确连线。

鼠减少会有直接食物减少的影响，但鹰的长期数量还取决于替代食物、蛇变化、食谱比例和时间。题给限制就使用，没给则不把必然灭绝当直接事实。[K14]

验收分清关系判断、路径计数、数量预测所需信息不同。讨论能量时，未流向某一捕食者的部分还可能进入残体、排遗和分解者路径，不能全部当成立刻散失的热。

停止在图中信息和必要关系，不推种群方程，也不因现实复杂放弃标准模型推理。

## 六、题源与图形

原题标年份卷别题号，改编和自拟明确区分；县乡同题不重复计证据。

家系核性别、标记、代次和连线；食物网核箭头、节点及省略成分；曲线核轴、单位、图例和条件。未读图不猜选项，不按题号拼出一张方便的图再说验证了原题。

原图拿不到可另用自拟模型讲原理，必须说明不是原题。参考解析有省略时，分开题面事实、通常简化和严格条件；不硬凑答案，也不一概否定教学简化。

## 七、防错表

| 主题 | 要阻止的错误 |
|---|---|
| 细胞 | 全部有核；无核就无DNA；植物细胞全部有叶绿体 |
| 分裂 | 复制就条数倍增；配子个数减半；所有生物减数分裂都直接产配子；不标统计对象 |
| 光合呼吸 | 白天只光合；有光必净放氧；净零就是没有活动 |
| 生长水分 | 鲜重增加必为有机物增加；肥料越浓越好；越热蒸腾必越强 |
| 调节 | 有反应就是反射；酶激素抗体可互换；稳态永不变化 |
| 遗传 | 显性必常见优良；父不传X给子就子不可能有相关性状；概率固定配额 |
| 生殖 | 传粉等于受精；嫁接融合全部基因；克隆性状只由核供体决定；体细胞变化在任何繁殖方式下都不能传递 |
| 微生物免疫 | 全部致病；病毒为细菌；抗体抗生素疫苗相同；人体自己变耐药 |
| 生态 | 类别等于角色；图省略即系统无；能量循环；高营养级个体数必少；未传递能量全已变热 |
| 证据 | 相关必因果；关系图能预测全部长期数量；只按外观读图 |

表是教师自检和错因定位工具，不要求学习者先背反例大全。

## 八、安全与跨科边界

纸面推理不转换成个人诊断、药物剂量、疫苗安排、遗传风险结论，不安排病原培养、未知微生物扩增或危险实验。食品保存解释题设，不制定真实保质期或家庭操作方案。

化学已有酶、发酵、浓度先调用；生物补细胞、组织与代谢。物理已有热和扩散同理。新增地理水循环与气象由D框架主讲，生物补植物响应，不重复完整章节。

## 九、错因与停止标准

具体记录术语对象不清、层级错、方向错、总量净量速率混淆、计数单位错、漏条件、漏图、相关因果混淆、模型泛化、必要事实遗忘或运算错，不全部归为基础不牢。

修复对应缺口后用一个变式复验，不从第一章重来。收尾只保留通过编号、不稳判断和最小下一步，不自动生成庞大新计划。
