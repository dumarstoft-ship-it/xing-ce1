# 广东省考生物：逐项展开任务书

版本：v1.0｜日期：2026-11-14

先读[范围调研](06_生物范围调研与证据边界.md)和[62项知识框架](07_生物知识框架_v1.md)。本文件约束后续讲解的对象、深度和验收，不要求一次性展开全部知识。

## 一、目标与学习者起点

目标是掌握广东省考科学推理范围内的基本生物模型，并能应对换背景、改条件和图表综合；不是重学完整高中生物，更不是背动植物百科。

学习者的生物基础尚未单独诊断。此前“没有选化学”不能解释为“没有选生物”。先用少量有区分度的问题确认本轮前置：术语知道指什么，过程知道在谁身上发生，关系知道在什么条件下成立。已经会的迅速通过，不用十道定义题拖慢进度。

学习者需要的是能够融入常识理解、又可以实际检验的模型，不是“看见某特征就选某项”的机械口诀。解释必须能落回具体的物质、细胞、信号、传递路径或收支关系。

## 二、每轮只解决一个具体问题

开头写明知识点编号或问题包，以及一句掌握目标。例如：

> 本轮解决B02-05：为什么植物有光时也可能净消耗有机物？

先检查最小前置，再围绕这个问题展开。若缺的是“净量”的含义，就补产生与消耗的区分，不重新讲全部叶绿体结构。若缺的是“父亲给儿子什么染色体”，就先补传递路径，不先堆一页遗传术语。

一个问题可以调用多个编号；一个编号也可能分两次补缺口。不要为了目录工整，要求每节都有同样的段数、题数或长度。

## 三、解释要做到什么

**先让词指向对象。**“染色体、DNA、基因”“酶、激素、抗体”“细菌、真菌、病毒”必须有具体区别。不能用另一串尚未解释的术语替代说明，也不能把所有陌生词一次性讲完。

**把关系讲成过程。**植物增重，就追踪物质来源和呼吸消耗；血糖变化，就追踪输入、利用、储存与调节；遗传，就追踪父母给出的信息及其组合；生态，就追踪资源、食物和相互影响。拟人化可帮助起步，但不能成为原因。

**区分一般关系与需认识的事实。**“净变化要比较收入和支出”可以迁移；“胰岛素由哪类细胞产生”“细菌和真菌的细胞结构有何区别”需要少量事实支持。不要承诺所有事实都能现场推导，也不要把事实记忆扩大成百科。

**有条件的规律要带上条件。**不过先讲题目所采用的标准模型，再补会真正改变答案的边界；不要在每个基础概念后罗列十种罕见例外，使简单问题失去可用结论。

**严谨不是拒绝简化。**题干明确给出一种遗传模式、短期扰动或其他条件时，先在该模型下推理。不能拿“现实很复杂”否定一切判断；同样不能把题内简化当成无条件现实规律。

## 四、每个单元的交付与验收

| 检查项 | 必须做到 |
|---|---|
| 定位 | 标知识点编号、目标层级及最小前置；说明是真题主题、基本变式还是补漏 |
| 解释 | 有清楚对象和完整关系，不只列术语或给一句口诀 |
| 条件 | 标出本轮会影响结论的温度、光照、时间、对象、遗传模式、统计口径等条件 |
| 证据 | 区分题给事实、常识、教学假设、观察和推论；图题说明原图是否实际读过 |
| 迁移 | 改变至少一个关键条件，检验学习者是否仍会判断；已熟练内容可以短过 |
| 验收 | 能解释典型情境，能处理关键变化，能指出常见错误少了什么条件 |
| 记录 | 只记已掌握点、具体缺口、错误类型；下一轮不要重复已经通过的前置 |
| 停止 | 达标就停止；未达标只修对应缺口，不把整个模块从头重讲 |

题目要少而有区分度。定义问答可以用于诊断，但不能靠大量低价值重复题制造训练量。

## 五、四个展开深度示范

以下均是自拟教学模型，不冒充原题。它们说明应该讲透哪一层，不是要求学习者现在完成四节课。

### 示例A：有光，为什么仍可能净消耗

对应B00-03、B02-03—05。

设同一对象、同一时段，用统一的有机物当量表示速率，并忽略其他输入输出。适当光照下，生产速率为6、呼吸消耗为2，净积累为4；光照减弱后，生产为1、呼吸仍为2，净变化为−1。数据为教学设定，不是真实植物测量值。

需要讲清：第二种情况仍有光合生产，只是收入少于支出。“有生产”和“总量增加”是两个命题。若生产和消耗相等，净量为零，也不能说两个过程停止。[K4]

验收：能处理“光变弱”“温度改变而其他条件给定”“净气体交换为零”三类变化；知道必须先确认各量使用同一对象和单位。不能把气体体积直接与有机物质量相减。

停止位置：会做简单收支和限制因素判断即可；不扩光呼吸、光反应电子传递、碳循环全部中间产物。涉及现实温室时，只解释题设条件，不输出农艺配方。

### 示例B：DNA复制了，染色体为什么不立即翻倍

对应B01-05、B06-01。

自拟标准模型：某正常二倍体细胞原有4条核染色体，完成一次有丝分裂；忽略突变与异常，统计核遗传物质，不把线粒体/叶绿体DNA混入。

| 观察时点与对象 | 染色体条数 | 核DNA分子数 |
|---|---:|---:|
| DNA复制前的一个细胞 | 4 | 4 |
| DNA复制后、姐妹染色单体尚未分离的一个细胞 | 4 | 8 |
| 姐妹染色单体已分离、细胞尚未分开的整个细胞 | 8 | 8 |
| 分裂完成后的每一个子细胞 | 4 | 4 |

需要讲清：复制和分离是两个事件；相连副本与独立染色体的计数规则不同；最后一行把观察对象改成“每一个子细胞”。不能只记“先加倍再恢复”，却分不清在数什么。[K2]

验收：换一个初始条数，或者把问题从“整个细胞”改为“一个子细胞”，还能稳定判断。学习者不需要画出全部有丝分裂时期的精细结构。

停止位置：到普通有丝分裂的关键阶段及计数对象区分为止。减数分裂只补配子数目减半和受精恢复的基本理由，不自动进入异常分离和多时期综合图。

### 示例C：伴X显性，为什么不能背成“父病子必正常”

对应B06-04—07。

使用教材标准人类XX/XY模型，某X连锁显性性状的相关等位基因为A，正常等位基因为a；假定完全外显、无新突变及其他特殊情况。

先给父亲XᴬY、母亲XᵃXᵃ。逐个追踪：女儿取得父亲的Xᴬ，儿子取得父亲的Y；母亲只提供Xᵃ。再将母亲改为XᴬXᵃ，儿子就可能从母亲取得Xᴬ。

稳定结论是“在该模型中，父亲不把自己的X传给儿子”，不是“不论母亲如何，患病父亲的儿子都正常”。后一个说法丢失了母亲的条件。[K11]

验收：能分别回答给定性别时的概率和所有子代中的概率，并主动说明父母基因型；不能把概率读成少数几次生育的固定配额。

停止位置：单基因、少代数、标准假设下的传递与排除。这个模型不是现实家庭诊断，不讨论个人家系疾病风险；不扩连锁互换、多基因、特殊外显率和临床遗传咨询。

### 示例D：食物网不是一串永远可靠的增减号

对应B08-02—07。

自拟简化捕食网，用“食物→取食者”表示：草→兔，草→鼠，兔→鹰，鼠→鹰，鼠→蛇，蛇→鹰。这里只是明确的文字模型，不对应任何原题图。

先找从生产者到图中终端消费者的完整路径，再沿每条路径分别确定营养级。鹰可沿不同路径处在不同营养级；鹰和蛇既可能争用鼠，也存在捕食关系。这些都来自图中明确的连接。

随后问“鼠减少，鹰会怎样”。可以识别直接食物减少这一影响，但长期数量还取决于兔等替代食物、蛇的变化、食谱比例和时间尺度。题干若给出额外限制就使用它；没有给出时，不把长期必然灭绝作为图中直接事实。[K14]

验收：能区分关系判断、路径计数和数量预测三种任务，知道它们所需信息不同。

停止位置：不推种群动力学方程；不因存在现实复杂性就放弃题设下的基本判断。

## 六、题源和图片的硬性规则

原题、改编题、自拟题必须分开标注。原题要有年份、卷别、题号；县级/乡镇重复题保留对应关系，不能当成新增独立证据。

家系图要核对性别、患病标记、代次和亲缘连线；食物网要核箭头、节点及图是否省略分解者；曲线要核纵横轴、单位、图例和题给实验条件。未读原图，不提供假装确定的选项答案，也不根据题号“还原”一张猜出来的图。

原图拿不到时，可以明确改用自拟模型讲该知识点，但必须说明不是原题。不能用自己画的方便结构替代原图，再声称验证了原题答案。

题库解析也可能省略条件或表述错误。核验时分三层：题干实际给了什么；通常采用了什么简化；严格成立还需要什么。不要为凑参考答案制造错误科学规律，也不要把所有教学简化都一概判成无解。

## 七、重点防错表

| 主题 | 必须防止的错误模型 |
|---|---|
| 细胞 | 所有细胞都有成形细胞核；没有细胞核就没有DNA；所有植物细胞都有叶绿体 |
| 分裂 | DNA一复制染色体条数就翻倍；不说明一个细胞还是每个子细胞就比较数量 |
| 光合呼吸 | 白天只光合、晚上才呼吸；有光必净放氧；净变化为零说明没有生命活动 |
| 生长与水分 | 湿重上升就等于有机物积累；肥料越浓植物越长得好；越热蒸腾必越强 |
| 调节 | 对刺激有反应就叫反射；酶与激素只因都是蛋白质就可以互换；稳态等于数值不变 |
| 遗传 | 显性一定更常见或更优良；父亲不传X给儿子就等于儿子不可能有X相关性状；概率是固定名额 |
| 生殖 | 传粉等于受精；嫁接等于双方全套基因融合；克隆个体的全部特征只由核供体决定 |
| 微生物与免疫 | 微生物都致病；病毒是细菌；抗体、抗生素和疫苗是一种东西；耐药是人体变耐药 |
| 生态 | 生物类别等于生态角色；食物网省略某成分说明生态系统不存在它；能量循环；高营养级个体数必更少 |
| 证据 | 两条曲线相关就证明因果；根据食物关系图能预测任意长期数量；按图像外形而非变量判断 |

此表是教师自检和错因定位工具，不是要求学习者先背一张反例大全。

## 八、医学、生物安全及跨学科边界

本课程用于纸面科学推理。胰岛素、抗生素、疫苗、免疫和遗传内容不转换成个人诊断、用药调整、剂量或真实家系风险结论。不得安排病原体培养、未知微生物取样扩增或危险生物实验。

食品保存只解释题设中的温度、水分和氧等机制，不据此制定现实食物保存时限或家庭操作方案。需要实际健康或食品安全建议时，应另查相应权威指南。

与化学重复的酶、发酵、浓度等，先调用已掌握的部分；生物补的是细胞、组织和生命过程，不重写整套化学课。与物理重复的热、气压、扩散等同理。

## 九、错误记录应指向具体缺口

用具体类型记录：术语对象不清；把不同层级混在一起；过程或传递方向错；总量/净量/速率混淆；计数单位错；漏关键条件；图未读全；把相关当因果；把题内模型无限推广；必要事实遗忘；单纯计算失误。

不要全部归为“基础不牢”。例如家系错题可能只缺一条父母染色体传递路径；光合题可能只缺收支概念。修复这一点后，应立即用一个有意义的变式复验，而不是从生物第一章重学。

每轮收尾保留：本轮已通过的编号，仍不稳定的判断，以及下一步需要的最小补充。不要自动生成新一轮庞大计划。

## 十、扩范围的条件与可复制指令

增加主课内容必须记录：可靠广东省考题源、原图是否核验、现有框架为何不足、最小新增知识。其他省份、国考、竞赛题只能作同模型同深度的补充，不能单独决定广东省考必学范围。
