# 地理、气象与基础天文：逐项展开任务书

版本：v1.0｜日期：2026-11-14

先读[范围调研](09_其余科推范围调研与证据边界.md)、[35项框架](10_地理气象与基础天文知识框架_v1.md)及[全科校对记录](12_全科校对记录_v1.1.md)。本文件供讲解模型逐项展开，不要求一次把全部知识讲完。

## 一、目标与起点

目标是建立广东科推所需的空间、过程和条件判断能力，不是压缩背完高中地理或天文百科。学习者在这部分的基础尚未单独诊断，不能从“化学基础久远”推定地理也不会。

每轮从一个具体问题出发，注明D编号或问题包。先检查必要前置：能否认方向、看懂高度、分清当天和正午、知道太阳时与钟表时不同。已会的部分跳过；缺一个概念，只补最短链。

## 二、解释方法

**先固定观察者和对象。**地图朝向、地面与高空、北极上空与地面朝北，必须明确。不要一开口就说“向右”“顺时针”“升高”，却不说明相对谁。

**把结论还原为过程。**等高线用高度与坡度解释；风用推动、偏转和摩擦解释；锋面用冷暖气团相对运动与抬升解释；雪线用积累与消融解释；昼长用受光区域和自转路径解释。

**区分模型条件与地理事实。**太阳位置可由几何关系推理，但城市大致纬度属于必要事实；板块边界的某个实例需要位置知识，不能伪装成只凭国名就能推出来，也不能扩成世界地理背诵。

**条件要适量。**先用题目采用的标准模型得到可用判断，再补真正会改变答案的边界。不能用现实复杂为理由拒绝作答，也不能把模型里省略的条件变成无条件常识。

## 三、每轮的最低产物

| 内容 | 要求 |
|---|---|
| 定位 | 本轮编号、问题、最小前置；说明是不是补漏项 |
| 观察框架 | 时间、位置、朝向、高度、图的投影或视角 |
| 原理 | 可连续追踪的因果过程，不只是结论口诀 |
| 边界 | 至少改变一个关键条件，说明结论如何变化或为何无法判定 |
| 验收 | 少量有区分度的题；错因具体到对象、方向、条件、事实或推理链 |
| 停止 | 达到可迁移的标准就停止，不自动开全套地理章节 |

不强制每次都用同样六个标题或相同题数。以上是质量检查，而不是正文模板。

## 四、四个展开深度示范

以下为教学模型，不冒充原题；需要示意时另画清楚的教学图，不能假称是未取得的真题原图。

### 示例A：山谷等高线为什么向上游弯

调用D01-01—03。先让学习者知道一条线上的海拔相同，再考虑同一横向位置中谷底比两侧低。要在谷底找到与两侧同样高的点，往往需要向地势较高的上游走，因而等高线在谷中向高处弯。

再给出高程数字，让学习者自己确定哪边高、哪边低，然后判断水流。验收变式只改变图的朝向或高程排列，看其是否仍能解释。不能训练成“V尖一律朝北”“看见V就一定有河”。

停止在看懂简单地形、坡度和可能水流路径；不升级为专业测绘、实际营地安全或工程选址。

### 示例B：北墙照到太阳，缺了什么条件

调用D03-03—04。先区分当地正午与一整天任意时刻。明确限定正午时，比较当地纬度与太阳直射纬度，判断太阳处于南侧还是北侧。换成清晨或傍晚，再考虑日出日落方向。

验收问题不是“背出哪个城市”，而是判断两个表述是否等价：“夏季某时北墙被照亮”和“夏季某日当地正午太阳在北侧”。学习者能指出时间条件不同，即已抓住核心。

J23-70的公开题面未写正午。引用原题时必须保留原话与条件缺口，不能在讲义里默默把原题改成更严谨版本。可以另外给一题明确标为“补足正午条件后的改编题”。

停止在基本太阳几何，不研究房屋遮挡的精细工程模型、天文坐标变换或建筑采光计算。

### 示例C：海风为什么不能只背“热就低压”

调用D04-02—03及物理P06。先说明比较的是近地面同一高度的海陆气压，而非拿地面气压与几千米高空气压比较。再从差异受热、气柱膨胀及质量重新分配说明环流的形成，在题目简化模型中得到白天地面海风与高空回流。

应明确：仅把一根气柱加热，并不能在任何约束下立即推出底部压强降低。固定容器、封闭气体和开放大气有不同边界；近地面压力与上方空气质量有关。无需用气象方程求解，但不能用“空气一热就凭空少了”作为解释。

验收时把昼夜互换，或者把观察位置移到高空，让学习者重新判断流向。保持模型的其他条件，不混入真实天气预报的全部复杂因素。

### 示例D：升温又增雪，雪线一定怎样变

调用D05-04。先分别分析：其他条件相同时，消融增强通常不利于积雪保留；更多固态降水若能保留，则增加积累。两种作用方向相反时，单凭“一个增、另一个也增”不足以决定最后高低，需知道相对强弱或题给信息。

验收可对照“升温且固态降水减少”与“升温且固态降水增加”。不是每题都要数字，但必须知道什么条件足够作方向判断、什么条件不够。

停止在积累—消融收支，不学冰川物质平衡专业测算，也不拿一次降雪后的边界当长期气候雪线。

## 五、真题与原图规则

原题需标年份、卷别、题号。原题、改编、自拟分开；同题县乡两个版本不得当作两次独立覆盖。

涉及2021昼长图、2024等高线、2025海陆风、2026锋面等，必须在正式讲选项前真正读取原图。只读到“如图”及题干，不代表知道图中位置、箭头、海拔和风向。无法取得图时，使用有明确说明的自拟模型，不猜原题选项。

参考解析不是科学定律。遇到遗漏时间、高度、半球、状态的解析，先补充说明“这是在什么模型下才成立”，不能把补充条件装作题干原有内容。

自然地理背景中的日常安全、灾害、出海、攀岩等，仍只用于纸面推理，不把简化试题当实际操作决策。

## 六、全科交叉怎么执行

热学、压强和相变调用物理；浓度与气体溶解调用化学；蒸腾和生态调用生物。缺哪一小段就回查对应编号，不重讲全部基础。

M01—M05是共同检查，不另布置五套练习。一个错题可同时记录“图轴读错”和“对象选错”，但只针对真正的原因修补，不能笼统归为“地理不行”。

地理题面出现某个新地点或新技术，先提取题给条件。必要的位置事实可以补充；未知技术内部实现若与解题无关，不加入课程。
