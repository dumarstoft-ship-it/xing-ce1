# 广东省考化学：逐项展开任务书

版本：v1.0｜日期：2026-11-14

先读同目录的[化学范围调研](03_化学范围调研与证据边界.md)与[54项知识框架](04_化学知识框架_v1.md)。本文件约束后续模型怎样讲，而不是要求模型把所有内容一次展开。

## 一、学习者起点：推理能力不弱，但化学语言已生疏

学习者高中没有选化学，初中知识已隔较久。不要把理解困难默认归因于推理能力，也不要默认他记得离子、化合价、溶质、中和、还原剂等术语。

需要检查的不是“是否学过这一章”，而是“本轮所需的词能否指向具体对象”。例如不懂“盐溶液呈碱性”时，可能缺的是物质类别与溶液性质的区分，不是需要再背十种盐。

讲解要把已经会的部分迅速略过。不能因学习者说基础久远，就默认每一个词都必须长讲；同样不能因为他的数学推理好，就突然用未经解释的化学术语。

## 二、每轮只解决一个有边界的问题

开头标明知识点编号或问题包，以及一句可验收的目标。例如：

> 本轮解决C02-03：为什么最后加入的糖全部溶解，仍不能断定溶液未饱和？

先用少量、低负担的诊断检查最小前置。若能解释，不再重复入门；若不能，补最短的依赖链。不要先考完整高中知识，再依据不会做得出“必须从头学完”的结论。

默认展开顺序：日常可观察现象 → 明确研究对象 → 必要粒子解释 → 对应符号或关系 → 变化条件 → 一次迁移检验。这是解释逻辑，不是每篇都要排出六个相同标题。

## 三、对零散基础的具体处理

### 1. 首次出现的关键术语必须有“指向”

用一个正例和一个最小反例建立区别。例如“离子”不能只解释成“带电粒子”就继续堆词，还要指出钠离子与电子不是同一个东西，盐晶体/溶液中的离子也不是凭空出现的另一种元素。

但不要无限追问本体：讲清盐水中的离子后，不自动进入量子轨道、溶剂化自由能、电导率模型。必要的解释深度由当前判断任务决定。

### 2. 用三种表达互相校准

- 普通语言：发生了什么，什么留在了哪里。
- 粒子语言：哪些粒子只是分散，哪些化学身份改变，什么守恒。
- 符号语言：化学式、反应式或质量关系具体表示什么。

不是每题都必须画粒子图，但至少不能出现普通语言说一种意思、方程式写另一种意思的情况。模型中的小球颜色是标记，不是真实颜色。

### 3. 别把分类、性质和反应混成一句

“纯碱是盐”“其水溶液呈碱性”“能与酸反应”属于三个不同层面的判断。先说明这一点，再追问为什么。不能用“因为它叫纯碱”解释其分类或全部性质。

### 4. 允许有少量需记住的事实

不要承诺所有性质都能从组成现场推导。常见物质的名称、典型反应和某些物性，需要通过少量对照积累。每次只加入能服务当前问题的条目，并说明与已经认识的物质差在哪里。

“理解为主”不等于拒绝记忆；“需要记忆”不等于一开始布置几十页性质表。

## 四、每个展开单元应达到的质量

| 检查项 | 要求 |
|---|---|
| 对象与边界 | 明确是在讨论纯物质、混合物、液相、固体、整杯体系还是某种粒子 |
| 必要前置 | 只补当前判断需要的知识点，并注明编号；不要求按目录机械全讲 |
| 原理与事实 | 分开说明哪部分来自一般规律，哪部分是物质的已知性质或题给信息 |
| 条件 | 写清温度、溶剂、是否密闭、是否达到平衡、是否有反应/挥发、计量对象等 relevant 条件 |
| 变式 | 至少改变一个会影响结论的关键条件，说明原结论还能否成立 |
| 证据 | 题源、图形核验状态、题给条件与教师自加假设必须分开 |
| 验收 | 检查学习者能否解释，而不是只会复述某个选项；错误落在哪一层要记录 |
| 停止 | 能处理典型情境及关键条件变化后停止；没通过就修缺口，不把整章推倒重来 |

上表中的“条件”只列与本题有关的部分，不要为了严谨而在每个初学问题前罗列十几种无关例外。先讲标准模型，再补会真实改变判断的边界。

## 五、三种展开深度示范

以下都是教学设计/自拟情境，不冒充广东原题，不要求实际动手实验。

### 示例A：盐和糖都在水中看不见了，为什么不能只说“都消失了”

对应C00-03、C00-07、C02-01。

先确认学习者分得清“一粒可见盐晶体”和“构成晶体的离子”。再解释：氯化钠晶体中的离子分散到水中；蔗糖在普通溶解条件下以分子分散到水中。看不见固体并不意味着物质不存在，也不等于已经转化成别的元素。[范围文件K5]

必须防止的讲法：盐晶体原来是一个个中性盐分子，水把每个分子切碎后才生成离子；或者水把糖分子拆成碳氢氧原子。两者都会给后续反应判断埋错模型。

验收不是让学习者背“离子化合物、分子化合物”两串词，而是能解释：没有发生反应且没有损失时，原来加入的物质去了哪里；为什么普通滤纸未必能把溶解的物质分出来。

停止位置：不讲溶剂化热力学、晶格能计算。离子导电可作后续简短连接，不作为本轮入门门槛。

### 示例B：冷却后杯底有固体，为什么液体浓度要重算

对应C02-03—06。以下数值为自拟模型，不是蔗糖的真实溶解度。

给定物质X在高温T₁的溶解度为60g/100g水，在低温T₂为30g/100g水。把40g X加入100g水，在T₁全部溶解，随后冷却到T₂并达到平衡。假设水没有蒸发，X不发生反应，析出的是不含结晶水的X。

教学目标不是先算答案，而是画清三个位置：水、仍在液体中的X、析出的X。低温平衡时，30g X留在液体，10g析出；液体质量为130g，不是140g。因此液相质量分数应按30/130计算，而不是40/140。整个杯子总质量仍是140g，液体质量变化并不违背守恒。

这组数值还能用于纠正“全部溶解＝未饱和”：在T₁若恰好加入60g并全部溶解，就可以处于饱和；原来40g的例子未饱和，是因为已经知道上限60g，不是因为仅看见了“全部溶解”四个字。[范围文件K4]

验收变式：只改变初始加入量或冷却目标，判断有无析出，再决定分母。不要立刻升级成多盐共同析晶、水合盐或复杂浓度联立。

停止位置：能分清总体系与液相、溶解上限与实际溶解量，并处理一个关键条件变化。

### 示例C：酸能除去某些金属氧化物，为什么未必是氧化还原

对应C03-05、C05-03。先确认已能读反应式和最简单的化合价，不在第一轮入门就讲。

自拟教学反应：CuO + 2HCl → CuCl₂ + H₂O。先说明形成了新的物质，因此不应简单当作糖溶于水；再检查铜等元素的化合价，铜在前后均为+2，没有因“含铜物质被酸处理”就发生还原。与一个给定的金属置换反应作对照，才引出氧化还原的判别。[范围文件K3]

验收重点：能区分“发生化学反应”“有金属元素参与”“属于氧化还原”三个命题，而不是熟记一句“酸洗都是某反应”。

停止位置：不扩复杂电子转移配平、电极电势和所有酸的特殊性质；反应式仅用于纸面解释，不安排酸洗实验。

## 六、图像、实验与真题规则

原题、改编题、自拟题必须明确标注。原题需写年份、卷别、题号。县级/乡镇同题不要当成两道独立新题，也不要靠题面换名制造虚假的覆盖量。

带图题必须先读取原图，核查坐标、单位、图例、容器状态、粒子种类、反应前后数目及实验接法。看不到图时，只能讨论已知文字所支持的主题或使用另行标注的自拟图，不能补猜原题答案。

选项不是知识结论。遇到题库解释把“析晶后平衡的溶液”叫作过饱和，或把酸除碳酸盐简单说成必然氧化还原时，应先用原理核验。若资料表述有歧义，应明确题目意图、严格条件与未决部分，不为一个参考答案强行歪曲原理。

近年题目可能已经做过，不默认正确选项能证明理解。必要时用一个改变关键条件的改编题验证；不是再出一套无边界的大题本。

## 七、逐项防错清单

| 主题 | 必须阻止的错误模型 |
|---|---|
| 元素与物质 | 含碳元素＝含碳粉；有氧元素＝有氧气；同一种元素组成就一定同一种物质 |
| 粒子 | 一切物质都由分子组成；离子就是电子；溶解把所有物质都拆成原子 |
| 符号 | 配平可以改下标；系数比自动等于质量比；化合价就是每个原子真实电荷 |
| 变化与守恒 | 有气泡/发热一定是化学变化；分子数必须守恒；开放容器称量变化证明质量不守恒 |
| 饱和与溶解 | 全溶一定未饱和；饱和一定很浓；搅拌提高任何条件下的溶解度；析晶后必是过饱和 |
| 浓度 | 没有丢失物质就认为液相溶质质量不变；把未溶固体计入溶液质量；按体积随意替代质量 |
| 酸碱盐 | 盐一定中性；名称带碱就属于碱；等体积混合必恰好中和；pH可以直接取平均 |
| 金属与氧化还原 | 铝抗腐蚀说明不活泼；不锈钢绝不生锈；只要除锈/酸洗就是氧化还原 |
| 洗涤与催化 | 普通乳化一定切断油分子；催化剂从不参与反应；酶永远随温度升高而更有效 |
| 净水与保存 | 水变清＝无菌；普通滤纸过滤＝去除硬度；抽真空＝杀灭所有微生物 |

不要求学习者先背这张错误表。它是讲解者检查自己是否在制造错误直觉的工具。

## 八、安全与学科边界

本课程是纸面推理训练，不要求家庭实验。不得引导品尝、直接闻试剂、混合清洁剂、产生危险气体、加热密闭容器或进行实际酸洗。清洁剂按标签使用，不将漂白剂与其他清洁剂混合。[范围文件K14]

涉及食醋、肥皂水、胃酸、虫咬等试题，仅讨论题设中的化学关系。人体组织和医疗处理不等于烧杯中的酸碱模型，不据此给出治疗建议。

酶、食物保存、施肥只讲与当前化学解释相接的最短链，不引出整套生物课。电池只作有必要时的短连接，不扩全部电化学。环境气体只辨基本机制，不扩气候政策或环境工程。

## 九、何时算学会，何时必须补讲

一个知识点至少检查三个层面：能用自己的话解释典型情境；能处理一个真正改变判断的条件；能指出一句常见错误说法缺了什么条件。已经达到，就停止继续堆例题。

错误记录应具体：名词未识别、对象选错、把类别当性质、漏条件、图像读错、误用守恒、把经验泛化、运算失误。不要把所有错题记成“基础不牢”。不同错因对应不同修补任务。

扩范围必须记录可靠广东省考题源、原图状态、现有框架为何不足、最小新增知识。不能用“高中都学过”“别省考过”“万一会考”作为无限加课的理由。

## 十、可直接复制给后续讲解模型

> 请读取《03_化学范围调研与证据边界》《04_化学知识框架_v1》和本任务书。我高中没有选化学，初中化学已经生疏，但不需要低效地重学所有章节。本轮只展开【C编号或问题包】。先确认最小前置：关键术语必须能指向具体对象；能掌握的部分迅速跳过。用普通语言、必要的粒子解释和少量符号相互校准，区分一般规律、需要记住的事实与题给信息。给出关键条件、一个有意义的变式及验收标准，讲到能迁移就停。真题图必须实际查看，改编/自拟材料明确标注；不要猜原图，不照抄有问题的参考解析。每轮解决一个具体问题，不自动拓展为完整高中课程，不安排危险实验。
