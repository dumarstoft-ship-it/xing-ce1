# 逐项展开任务书：给后续讲解模型

版本：v1.0｜日期：2026-11-14

## 目标与输入

先读同目录的[范围说明](00_范围调研与证据边界.md)和[65项物理框架](01_物理知识框架_v1.md)。任务是把指定知识点展开到能解决广东省考科推及基本变式的程度，而非重讲整套初高中物理。

真题决定知识边界；知识结构防止零碎；适用条件防止假口诀；验收表现决定是否继续。不能因模型能力更强就自动提高课程难度。高质量是解释清楚，不是引入更多名词。

## 每一轮的执行方式

**先确定一个具体问题。**例如“静摩擦的大小由谁决定”，而不是一次宣布从力学第一章讲到第十章。列出本轮知识点编号和一句掌握目标。只补解决这个问题所缺的最小前置；已掌握的部分允许跳过。

**先建立可操作的物理模型，再给符号。**说明研究对象、真实相互作用、保持不变的量、改变的量和结果。比喻只帮助起步；至少能回到受力图、等效电路、光路或可核对的关系。不能把“电压像水压”“静摩擦很聪明”等拟人比喻当作证明。

**规则必须附条件。**每一个速判结论都要给出成立条件及一个失效反例。例如不是背“电阻变小电流增大”，而是说明比较的是哪个电阻、哪个电流、哪两点电压是否保持不变。

**训练变化，不训练题面记忆。**至少考虑一种改变关键条件的基本变式。对已熟练内容，只用短诊断决定是否跳过。对真正卡住的点，围绕同一个本质换情境，不用大量重复水题堆量。

**到可迁移处停止。**能独立解释典型情境、关键条件改变后的结果，以及常见错误结论错在哪里，就进入下一任务。没通过只修对应缺口，不从头重讲整章。

## 每个展开单元应留下的产物

| 项目 | 内容要求 |
|---|---|
| 定位 | 知识点编号、优先级、目标层级、最小前置、题源核验状态 |
| 原理 | 用完整因果链解释，必要时附少量公式；符号必须有物理含义 |
| 适用条件 | 明确恒定量、理想化、研究对象、过程阶段 |
| 典型结构 | 至少能覆盖该点在框架中的基本情境，不仅讲一道题 |
| 边界变式 | 改变一项关键条件，说明原结论如何变化或为什么不能再判定 |
| 验收 | 少量但有区分度的题；记录错在概念、对象、条件、图像、推理链还是计算 |
| 收尾 | 一句可用的速判语句，紧跟成立条件；不额外加新章节 |

不强迫每篇正文使用相同七段标题，也不按固定字数灌水。以上是质量检查项，不是机械写作模板。

## 真题与图形的使用规则

1. 原题、改编题、自拟题必须明确区分。原题要有年份、卷别、题号和来源。框架中的索引仅证明主题，不能替代原题核验。
2. 带图题必须真正看图，核实受力方向、接点、刻度、开关状态和图像选项；看不到图就标记待核，不编造图形，也不输出假装确定的选项答案。
3. 参考解析可能错误，尤其不能把选项中的错误命题抄成知识结论。遇到不一致，先说明假设及歧义，再验证，不为“标准答案”硬凑理由。
4. 需要图示时优先使用清楚、标注简洁的原图或可靠重画；知识解释不应要求学习者先学会操作复杂网页。
5. 不跨入国考、选调、上海科推或竞赛题来证明“广东省考必须学这个”。外部题只作同一模型、同一深度的补充，并标来源。

## 重点防错清单

- 静摩擦：实际值与最大值分开。没有相对滑动不等于一定有静摩擦，有摩擦也不一定反向于对地运动。
- 瞬时状态：v=0不等于a=0，不等于合力为零。弹簧与绳、橡皮筋的约束性质不可混用。
- 整体与隔离：写清系统边界。成对内力在整体中抵消，不能据此从单体受力图删掉。
- 浮力：V排与物体体积不同；沉底、密封接触、外部吊绳都必须单独检查。底面是否进液可能决定模型能否直接使用。
- 电路：先确认接线和恒定量，再写变化。串并联不能靠外观；电压表测两点，不测“旁边那个元件”。
- 功率：同U与同I下的比较不同。灯丝定阻是近似，电动机不是纯电阻，额定量不等于实际量。
- 碰撞：动量与动能的守恒条件不同。题目没有给出完全弹性，不能擅用弹性碰撞速度公式。
- 图像：斜率、面积是物理量关系，不是单纯几何口诀。先看轴和单位，再看正负和分段。
- 热学：温度、热量、内能不互换；相变平台仍可能吸热；气体比例温度用绝对温度。
- 光学：以法线量角；平面镜按空间对称判断；物体颜色和滤光片作用都要追到进入眼睛的光。
- 声与波：音调、响度、音色分开；v=fλ须明确传播条件；现代通信名称不能替代具体频段条件。

## 两个展开深度示范

### 示例A：P01-04 静摩擦——讲透但不挖到材料微观

教学问题：把物体压在竖直墙上，为什么“压得更紧”不一定使实际摩擦更大？

应达到的解释：先画物体受力，明确静止且竖直方向只有重力和摩擦；平衡确定实际摩擦需要多大。再解释加大法向压力改变的是可提供摩擦的上限，是否改变实际值取决于其他约束和运动状态。随后改变物体质量、加入竖直外力或让物体滑动，分别检查原结论是否仍成立。

最低验收：学习者能判断“把物体压得更紧”“换更粗糙的墙”“增大质量”三种改变，哪些改变实际值、哪些只改变是否能保持静止的余量；并说明何时必须换滑动模型。

停止位置：不讲表面微凸体、黏着、材料摩擦学，也不把上述竖直墙情境结论强套到所有静摩擦题。原理条件参考范围文件所列OpenStax摩擦章节。

### 示例B：P07-08 动态混联——解释连续变化链

使用明确标注的自拟结构：恒压电源，R3与“R1和R2的并联部分”串联；R2、R3为定值电阻，R1减小。所有元件先按理想定值电阻模型分析。

应达到的解释：R1减小→并联部分等效电阻减小→总电阻减小→总电流增大→R3分压增大→并联部分分压减小→R2支路电流减小。再通过总电流和支路电流关系判断R1支路变化。

最低验收：学习者能指出“某电阻减小，所有电流都增大”错在哪里；去掉公共串联电阻R3后，能说明为什么R2支路的结论改变。

停止位置：不讲任意网络节点法、基尔霍夫方程组通解、真实电源内阻、电子迁移率。上述题是自拟教学结构，不能冒充S25-69原电路。

## 扩范围的唯一合格流程

发现可靠广东省考题无法用现有框架解释时，记录：年份/卷别/题号、原图核验情况、缺失的具体知识、为何不是现有模型的变式、最小新增内容。再提出修改建议。禁止凭“常见物理知识”“别省考过”“可能会考”把补漏项升级为长篇主课。

## 可直接复制给讲解模型的指令

> 请先读《00_范围调研与证据边界》《01_物理知识框架_v1》和本任务书。本轮只展开【知识点编号或问题包】。先用少量问题判断我是否已有基础，再针对真正的缺口讲解。必须说明研究对象、适用条件、变化链和失效边界；用符合直觉且可验证的模型解释，不只给口诀。带图真题先读取原图，不能推测未见图形；自拟或改编题明确标注。深度以框架为上限，能解释典型题及关键条件变式后停止，不递归扩成整套物理课程。最后记录已掌握点、未解决点和错误类型，不自动生成庞大新计划。
