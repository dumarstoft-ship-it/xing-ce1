## 这套材料包含什么

物理负责受力、运动、能量、压强浮力、热、电路、光声等基本模型；化学负责物质语言、反应守恒、溶液、酸碱、燃烧与物质性质；生物负责细胞遗传、代谢、植物、调节、微生物和生态；新增领域负责地图等高线、地球运动日照、气压风、锋面雪线、板块、水循环海洋，以及少量基础天文补漏。

四套框架共有216个检查项，它们是文字索引，不是216个相互独立的必考题型，更不是216节长课。物化生分别建议17、12、13个问题包，新领域9包；问题包也不是必须逐一排课。框架内的M01—M05是全科共用检查，不另加五章。

不另立科技时政百科、完整区域地理、专业医学、竞赛或高考压轴体系。陌生背景首先利用题给信息，确有可靠广东题源要求时再补最小知识。

## 三条使用原则

**范围靠题源约束。**T为已读公开文字，S或旧T*为线索，B为必要前置/基本变式，R为短补漏。T不是已核原图或答案的标记；R不能在讲解时偷偷改称历年高频。未查到也不能断言历年没考。

**讲解按缺口，不按页数。**每轮选一个实际问题，查最小前置；已会的跳过，卡住的解释过程和条件。能说明典型情况、处理关键条件变化、识别常见误说，就停止堆题。

**边界不是随意删难点。**已有题面依据的基础圆周、家系、有丝分裂计数等保留；但不因此增加所属整章的全部计算和专业细节。高质量是把需要的道理讲清楚，而不是加入更多名词。

## 跨科内容只讲一次

| 内容 | 主讲与调用方式 |
|---|---|
| 热、压强、密度、相变 | 物理讲基础，地理增加高度、位置、环流与天气 |
| 溶液浓度、气体溶解 | 化学讲基础，生物增加膜与生命过程，地理增加海水情境 |
| 酶、保存、施肥 | 化学解释物质/反应，生物解释代谢/水分，不重复两套长课 |
| 蒸腾、水循环 | 生物讲植物，地理讲流域与大气循环 |
| 图表、实验、守恒、证据 | 共用M01—05，回查P00、C07、B00/B10等编号 |

学习者已明确高中未选化学，因此化学保留语言重建的最短路径；不能据此擅自推断生物或地理也从零起步。

## 给后续讲解模型的统一入口

> 先读本README、12号校对记录、目标学科的范围文件和任务书，再读取当前框架。本轮只解决【编号或具体问题】。检查最小前置，已会跳过；讲清研究对象、真实过程、适用条件和结论边界。分开题给事实、需要认识的事实与可迁移的推理。用一个真正改变条件的变式验收，达标即停。原题图必须实际读取；没有图就另用明确标注的自拟模型，不猜原题答案。跨科内容调用已有编号，不重复整章。不要擅自扩展为完整高中课程，也不要把记录变成复杂操作系统。

## 这次校对的重点

静摩擦不只存在于静止或平衡情形；压力不能因字母p而误认压强；非线性伏安图不能套直线斜率规则；溶解要看是否伴随反应；气体溶解需明确目标气体分压；生物中的减数分裂产物、气体交换和遗传变化传递要限定模型。

生物任务书原来“配子数目减半”已改为动物模型中“配子的染色体条数相对相应体细胞减半”，防止把配子个数与染色体数目混淆。2023北墙日照的公开题面未限定正午，新增框架不把它写成无条件纬度口诀。具体差异和来源见12号记录。
