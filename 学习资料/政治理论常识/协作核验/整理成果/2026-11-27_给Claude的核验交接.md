## 旧资料怎么处理

| 原表述或可能被误写的说法 | 处理意见 |
| --- | --- |
| “县级以上林业主管部门一律应当编制林业发展规划” | 这是旧森林法口径。2026-11-06以后按 E-LAW-02；LAW-008 原有的“森林法继续保留”结论仍有依据。 |
| “据十五五纲要，生物制造归入……” | GD-004 的谨慎结论已获两份同名层级规划互证。题面要进一步写出“国家”或“广东省”。见 E-DB-01。 |
| “未直接核到2027年” | 可用省委《决定》确定2027年阶段目标。若要引用2026年行动方案的逐字条款或落款日，应另取正式文件。见 E-GD-01。 |
| “广东1月批准纲要，适用3月公布的国家发展规划法” | 批准机关可以核对，但两件事的时间方向不能倒置。现行一般程序与具体历史事件分开设问。见 E-DB-07。 |
| JSON 来源 TPL5DEC 的发布日期空缺 | 原链接的工信部转载页明确标注2026-11-01 18:23，新华社同日公开全文。全会通过日另为10-29。见 E-PT-05。 |
| “活动已结束，政绩观教育工作也随之结束” | 核对学习教育的具体阶段和常态要求，以 E-PT-04 记载的总结、后续要求为依据。 |
| “依法足额结算就是报销全部医药费” | 医疗保障法新文本限定基金应付部分。该法和检察公益诉讼法均于2027-01-01施行；在11月的题中只能按已公布新文本或立法状态来问。见 E-LAW-03、06。 |

## 低成本补充

- **十件实事。** 前五项的五张卡按救助、长护险、县中、生育、新就业形态保障展开；后五项用 E-DB-06 查对象和指标。一次练习选一至两项即可。把年度部署、地方落实数据、省级实施细则分别命名。
- **地方实例。** 两业协同专题询问可以复用 P4-07 的人大监督职能，深圳APEC可以练一次“会议成果／中方倡议”的主体和动作。原稿将会后细节列为补充，这次没有依据提高其命中概率。见 E-DB-03、04。
- **候选规范。** 新近公布但未施行的文本，宜先做版本辨析。对四项省级法规案，只可使用原卡已证实的立法动作。区域整体用海论证已完成的特定“标准海”项目则有正式文件可依。见 E-YF-02、03、04及 E-GD-09。

新知识点的 K 编号只供本次交接。决定采用后再映射到正式 records，每题保留相应文件、时点与 E 编号。上述六组均未记录用户实际作答或掌握情况。
