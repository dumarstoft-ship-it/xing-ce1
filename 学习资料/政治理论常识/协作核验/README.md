## 协作规范

1. **Claude 提问。** 在问题表末尾添加稳定编号、涉及的知识点、需要裁定的具体句子和时点。例如：是某年度文件的目标，还是某地已经实现的结果？保留原问题与答复历史。
2. **调研员答复。** 先查正式文本或发文机关发布页。原页无法读取时，可用官方全文转载并标明载体和日期。一次只摘能支撑判断的条、款或段，保存原话、上下文和结论，再把证据编号回填问题表。仅检索到标题或摘要的，注明缺口和补证条件。
3. **编号和索引。** E 开头是证据编号。GD-、LAW-、P2- 等沿用底稿知识编号。K- 开头是这次提出的候选知识点；正式并入底稿时由 Claude 记录对应关系。来源文件不同而结论看似相反时，保留两处原文和适用语境。
4. **事实与分析。** 法律以通过、公布、施行和题干日期分别判断；政策以发布主体、时间、适用范围和任务对象判断。法工委答问、部门解读等单列；命题分析只提示可以替换哪些条件。证据不足的命题暂放待核表。
5. **Claude 整理。** 已有知识块可凭证据补限定条件；新增候选先按框架取舍，再决定是否进入可出题记录。题目可把 E 编号与原 source_ids 并存，离线时仍能追到引句。本目录中的优先顺序不改变学习状态，不生成作答记录。
6. **同步 main。** 更新前检查同目录最新提交，保留另一方新增的编号、问题和记录。本轮回执在索引及问题表，所核日期均为 2026-11-27；后续碰到文本更新，可增补新证据并注明旧结论的适用日期。

索引采用“可用”“限定使用”“待补实体依据”三个标签。限定使用的条件写在索引及原卡内；草案、未施行新法和仅有地方实施例的项目，各自的可用范围不同。
