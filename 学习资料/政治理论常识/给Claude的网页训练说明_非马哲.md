# 给 Claude 的网页训练说明：非马哲政治理论与广东常识

请使用我提供的《非马哲政治理论与广东常识训练底稿_2026-11-27.md》和同名 JSON，制作一个可交互训练网页。知识范围已经限定，不要再扩展成全教材。

## 目标

把已讲但容易在相邻概念、主体、条件、时间、层级上失分的知识练稳。用户有申论和理解基础，优先新情境、纠错与近似选项辨析，少做机械全文填空。不包含马哲概念辨析，不加入泛科技工程清单。

## 采用的数据

- Markdown 是完整可读底稿，包含研究取舍、133个知识块、理解解释、错误对照和来源。
- JSON 与Markdown同源生成，包含 133 条records、24 条本轮新增、优先级、模块、source_ids、related_ids、学习状态和生成规则。
- correct承载已核实知识；why承载理解解释，其中的机制分析不能自动变成唯一历史原因或政策动机答案。
- 研究判断只决定练习优先级，不是押题保证。

## 页面需要做到

1. 默认提供“本轮法律与广东新增”“全阶段A档核心”“按模块练”“错题重练”四个入口；B档可选，C档默认关闭。
2. 不直接把知识卡背面当题目。先从同一关系改编出不同场景；每题关联知识编号和依据。
3. 每组建议12—20题，可调。题型以判断并纠错、情境单选、多选逐项、会议/著作配对排序为主。
4. 作答后再展示答案、每项错因、适用条件、来源及对应知识卡。不要提前把答案藏在题目标题或颜色中。
5. 记录独立作答、是否能解释、延后回忆三个不同维度；所有内容初始化未测试。“讲过”不代表“掌握”。可支持进度保存、导入和导出。
6. 错题重练更换场景和选项顺序，不能只让人记住原题答案字母。
7. 对有争议、缺条件或来源状态不完整的题，进入待审区，不给用户强行判错。

## 特别防错

- 范围以本文件records为准；排除马哲原理辨析、经典马政经全套、泛科技与桥梁航天工程清单。H18只允许出作品索引题。
- 只用exam_eligible=true条目的correct构造有唯一标准答案的题；why是理解解释，其中的分析不自动成为唯一历史原因或政治动机。
- R1—R8和prediction_rationale是学习投入判断，不是已知命题事实，不得生成“哪个一定会考”的知识题或命中率承诺。
- 法律题写明适用地域、版本和必要日期；分别识别立法计划、草案、审议、通过、公布、施行。不得用转载日期冒充法律生效日。
- 存在跨文本措辞差异时明确文件名与年份。P2-08、P2-16、GD-004、GD-011特别禁止脱离来源设唯一答案。
- 新增题要换材料和设问，不复刻已经做过的GD2024—2026原题；真题、改编、自编必须区分，仓库参考答案不是官方答案。
- 每题必须保存knowledge_ids、source_ids、标准答案、正确理由和逐项错因。错项必须指出被替换的主体、条件、阶段、层级、动作或关系。
- 错误选项可从contrasts改写，但不能让全部错误都靠“所有、只要、必然”等绝对词泄题；句长、答案位置和措辞风格也应均衡。
- 单选必须唯一；“最符合”比较题干侧重点，不意味着其他选项本身一定错误。多选逐项判断，不能只给一串答案字母。
- 不得把“初次违法”自动写成“必须不罚”，不得把“封存”写成删除或免罚，不得把“不执行拘留”写成无违法责任。
- 不得把法典放到普通法律之上；不得把行政法和行政法规混为一类；不得把全部法律形式画成没有例外的一条直线。
- 不得把党的领导与国家机关法定职责合并；人大、政府、政协、法院、检察院、监委须按权限和动作辨析。
- 初始化所有知识点为未测试；material_provided和prior_lecture_explained不代表已掌握。只有用户实际作答后才更新记录。
- 训练尽量使用情境单选、多选、判断并纠错、会议/著作配对与排序；少量精确名称题即可，不将全文挖空作为主训练。
- 默认A档优先，B档按错误补充，C档和兴趣解释默认关闭。选择全部范围时再纳入相应记录，不自动扩展外部教材。
- 若某题离开补充假设无法唯一作答，先修题或标记待审，不能让模型用常识猜测填成标准答案。

## 交付前检查

- 单选恰好一个正确项，多选逐项有依据；解释与答案标记一致。
- 编号与来源可追溯；法律和政策版本明确；没有把计划/草案当生效法律。
- 没有通过绝对词、长短句、正确项总在固定位置等规律泄题。
- P2-08教科人才、GD-004与P2-16产业分类、GD-011平台定位，必须遵守文件语境规则。
- H18仅为作品索引，不能据其标题引入整套马哲题。
- 网页加载后无已掌握项、无示例占位题混入正式练习。

视觉形式和实现方式由你设计；学习内容与答案边界以底稿为准。
