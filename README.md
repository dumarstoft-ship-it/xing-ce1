## 资料完整性

- 国考 PDF 按年份与卷别可配成 45 套真题及答案；另保留 2000 年真题的 Word 版本。
- 广东资料覆盖 2004—2026 年：2004—2012 年仅有答案解析文件；2013—2025 年现有真题均有对应答案解析；2026 年仅有真题，尚无答案解析。
- 部分资料的文件名已注明缺题或网友回忆版，请以文件内内容为准。
- 模考库1080条均无配套源答案；每季收录31—90题，含66—70题科学推理。可直接使用[科学推理90题汇总](模考/2026下半年广东卷_16-33季_AI可读/科学推理_90题.md)。原文件名与哈希是来源记录，不代表原PDF已入库。
- 题库记录数不等同跨库去重后的独立题数，也不等同用户未做过的题数。详细核验见[题源盘点](广东行测18套模拟/题源入口与缺口.md)。

HTML 学习资料可下载后用浏览器打开。
